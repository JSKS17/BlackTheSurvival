# 실험체 필살기 도트 애니메이션 원본·갤러리

기존 니아 1종과 새로 만든 90종, 총 91명의 승인된 R 연출을 모았습니다. **v1.0.0부터 플레이어와 상대 실험체의 직접 R 사용에 모두 적용합니다.** 카드 확대 표시 뒤 손패와 분리된 전투 중앙에서 재생합니다. [런타임 적용·자산·검증 절차](../../docs/ULTIMATE_ANIMATIONS.md)를 참고하세요.

이 폴더는 제작 이력을 보관합니다. 프롬프트·manifest·과거 검증 자료의 `game_integrated: false`, `unintegrated_art_prototype`, “게임 미적용”은 **해당 이미지를 제작·검토하던 시점의 상태**입니다. 승인 원본의 해시와 이력을 보존하기 위해 그 기록을 덮어쓰지 않았습니다. 현재 적용본은 `Assets/Resources/Lumia/UltimateAnimations/`에 원본 atlas PNG를 바이트 그대로 복사하며, [런타임 자산 감사](../../docs/runtime-ultimate-assets.json)에서 확인합니다. 과거 갤러리 검사 통과 기록은 현재 Windows 플레이어 검증 결과와 구분합니다.

게임 적용 전 마지막 아트 수정은 2026-10-14의 **마르티나·띠아·다르코·나딘 최초 프롬프트 재생성**입니다. [갤러리](http://127.0.0.1:61624/index.html?revision=runtime1-20261014#martina)와 [당시 재제작·검증 기록](ORIGINAL_PROMPT_REGEN_20261014.md)을 참고하세요. 기존 128px 실험체 스프라이트와 처음 승인한 니아 R 시트만 생성 입력에 사용했습니다. 당시 갤러리 91명·1,140개 프레임 표시 검사를 통과했고, 나머지 87명의 682개 파일과 게임 폴더는 변경하지 않았습니다.

앞선 **다섯 명의 부분 보정과 검증 수치는 이전 시점의 기록**입니다. [해당 기록](POLISH_NOTES_20261014.md) 중 가넷의 머리색 한정 보정은 유지하며, 나머지 네 명의 보정 시트는 이번 새 생성본으로 교체합니다. 가넷은 내장 도구 편집의 머리 RGB만 원본에 합성해 다른 픽셀과 알파를 보존했습니다.

그에 앞서 아야·비형 등 13명을 **2등신과 큰 도트**로 다시 제작했습니다. 처음 승인한 니아 원본의 픽셀 밀도와 머리의 3~4단계 명암 면을 참고하고, 실험체별 공식 전신 원화를 얼굴·복장·무기의 기준으로 사용했습니다. 아래 13종의 제작·검증 수치는 [앞선 단계의 기록](REDRAW_NOTES_20261014.md)이며, 이번 네 명의 새 제작본 검사와 구분합니다.

## 보는 방법

이 폴더의 **`index.html`**을 Chrome 또는 Edge에서 여세요. 설치나 서버, 인터넷 연결 없이 재생됩니다. 압축 파일을 받았다면 전체를 먼저 풀어야 합니다. GitHub 소스 화면에서는 HTML이 실행되지 않습니다. 배포 ZIP은 업로드 당시의 시안이므로 최신 로컬 수정본과 버전이 다를 수 있습니다.

- 실험체 이름, 영문 ID, R 이름으로 검색할 수 있습니다.
- 일시 정지, 이전·다음 프레임, 0.5·1·1.5배 속도를 지원합니다.
- 각 실험체의 GIF, 투명 WebP, 전체 시트를 별도로 열 수 있습니다.
- 니아를 제외한 파일은 `Subjects/실험체ID/`에 있습니다. `prompt.txt`는 실제 생성 지시문이며 `manifest.json`에 참고 자료의 역할·해시·공식 출처·동작과 보정 이력이 있습니다.
- 13종의 `atlas.png`는 프레임을 분리한 재생용 시트입니다. `generated-sheet.png`는 보통 생성 원본이지만, 최신 가넷은 머리 RGB만 한정 합성한 결과입니다. 가넷의 실제 도구 출력은 `hair-color-tool-output.png`로 따로 보존합니다. `official-reference.png`는 해당 캐릭터의 실제 공식 전신 원화입니다.

## 앞선 13종 제작 기준

[2등신 스타일 기준](Style/chibi2-reference.png)은 비율과 큰 픽셀의 표현을, 처음 승인한 [니아 첫 프레임](Nia/frames/frame-00.png)은 362×362 이미지에 대한 픽셀 크기와 밀도를 참고합니다. 머리는 큰 밝은 면·중간톤·깊은 그림자와 연결된 짙은 윤곽으로 구분하고, 개별 눈매·홍채와 작은 입이 읽히게 했습니다. 공식 전신 13명의 [정체성 분석](ORIGINAL_IDENTITY_NOTES_20261014.md)은 생성된 인게임 도트와 구분합니다.

앞선 13종 재제작은 내장 `image_gen.imagegen`을 사용했습니다. 폐기한 이전 시트를 새 제작의 스타일 기준으로 사용하지 않았고, 리오 참고 이미지는 최종 생성 입력에서 제외했습니다. 큰 픽셀군을 목표로 했지만 일부 무기·옷에는 더 가는 윤곽이 남습니다. 전체가 균일한 논리 픽셀 격자라는 보장은 아닙니다.

원작 R의 핵심 동작을 12프레임으로 해석했습니다. 비형은 도약→공중 거대화→거대 상태 망치 내려치기→지면 충격파→원래 크기 회수를 보여 줍니다. 변신형·강화형 R에는 활성화와 대표 후속 행동을 함께 담았습니다. 원작의 실제 지속 시간이나 모든 모션을 재현하는 자료는 아닙니다.

12프레임·8fps·1.5초 반복입니다. 앞선 재제작 단계에서는 생성 PNG의 원본 바이트와 RGBA를 보존하고, 겹치지 않는 영역 추출·정수 좌표 이동·투명 패딩으로 재생 자료를 조립했습니다. 리사이즈하지 않았으며 셀마다 최소 24px 투명 여백과 외곽 잘림 없음을 확인했습니다. 일반 접지 프레임은 발 위치를 맞추고, 비형의 공중 장면과 변신·가림 장면은 그 동작을 유지했습니다. 갤러리의 장면 표시 영역도 유지합니다. 이번 가넷의 머리색 한정 합성은 [별도 보존 검사](Subjects/garnet/hair-color-proof.json)로 구분합니다.

앞선 13명 재제작의 [갤러리 브라우저 검증](../../docs/validation-chibi2-20261014/gallery-browser-validation.json)은 91명·1,140개 프레임 표시·12개 기능 검사에 통과했고 7개 스크린샷을 보존했습니다. [HTTP 자산 검사](../../docs/validation-chibi2-20261014/http-assets.json)는 65개 파일의 로컬 바이트 일치를, [HTTP 프레임 복귀 검사](../../docs/validation-chibi2-20261014/http-browser.json)는 당시 수정한 13명의 1→8→1프레임 전환 후 첫 화면 일치를 확인했습니다. [발 위치와 원본 보존 검토](../../docs/validation-chibi2-20261014/ground-review.json)도 보관했습니다. [이전 니아 스타일 검증](../../docs/validation-nia-style-20261014/)은 더 앞선 제작본의 기록입니다. 그 단계에서는 니아를 포함한 기존 78명의 576개 추적 파일과 게임 폴더를 변경하지 않았습니다.

이전 다섯 명 보정의 [브라우저 검사](../../docs/validation-polish5-20261014/gallery-browser-validation.json)는 91명·1,140개 프레임 표시·12개 기능 검사를 통과했습니다. [HTTP 자산 검사](../../docs/validation-polish5-20261014/http-assets.json)의 25개 파일이 로컬 바이트와 일치하고, [프레임 복귀 검사](../../docs/validation-polish5-20261014/http-browser.json)에서 다섯 명의 첫 화면이 돌아왔을 때 동일했습니다. [설치본 감사](../../docs/validation-polish5-20261014/asset-scope-audit.json)는 나머지 86명의 664개 파일과 게임 폴더의 변경 0건을 확인했습니다.

앞선 재제작에서는 [약 134MB](../../docs/storage-cleanup-chibi2-staging-20261014.json), 이번 보정에서는 [61,476,814바이트(약 61MB)](../../docs/storage-cleanup-polish5-staging-20261014.json)의 임시 파일을 각각 정리했습니다. 최종 제작 자료와 검증 기록은 보존했습니다.
