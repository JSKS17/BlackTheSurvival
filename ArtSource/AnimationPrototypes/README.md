# 실험체 필살기 도트 애니메이션 시안

기존 니아 1종과 새로 만든 90종, 총 91명의 R 연출을 모았습니다. **게임에는 적용하지 않았습니다.**

## 보는 방법

압축 파일을 모두 풀고 이 폴더의 **`index.html`**을 Chrome 또는 Edge에서 여세요. 설치나 서버, 인터넷 연결 없이 재생됩니다. GitHub 소스 화면에서는 HTML이 실행되지 않으므로 배포 ZIP을 내려받아 여는 것이 편합니다.

- 실험체 이름, 영문 ID, R 이름으로 검색할 수 있습니다.
- 일시 정지, 이전·다음 프레임, 0.5·1·1.5배 속도를 지원합니다.
- 각 실험체의 GIF, 투명 WebP, 전체 원본 시트를 별도로 열 수 있습니다.
- 니아를 제외한 파일은 `Subjects/실험체ID/`에 있습니다. `prompt.txt`는 생성에 사용한 정확한 프롬프트이며 `manifest.json`에 참고 이미지·공식 스킬 출처·동작 설명이 있습니다.

## 제작 기준

니아 시안의 큰 머리 비율, 읽히는 눈과 입, 작은 몸과 제한된 색 단계의 도트 표현을 유지했습니다. 얼굴·복장·무기는 각 실험체의 참고 이미지를 따르고, 원작 R의 핵심 동작을 12프레임의 독자적인 애니메이션으로 해석했습니다. 모든 캐릭터에 같은 얼굴이나 같은 공격 모션을 적용하지 않았습니다.

12프레임, 8fps, 1.5초 반복입니다. 원작의 실제 스킬 지속 시간을 재현하거나 게임 규칙을 바꾸는 자료는 아닙니다. 변신형·강화형 R에는 변신/강화와 그 이후 대표 행동을 함께 담았습니다.

새 원본은 내장 `image_gen.imagegen`으로 실험체마다 개별 제작했습니다. 생성 PNG를 그대로 보존하고, 실제 투명 여백에 맞춰 프레임을 추출한 뒤 투명 패딩과 정수 위치 보정으로 재생 자료를 조립했습니다. 원본 픽셀을 다시 그리거나 리사이즈하지 않았습니다. GIF는 형식의 색상·시간 제약이 있으므로 투명도와 색상을 자세히 볼 때는 WebP 또는 갤러리를 사용하세요.

이 자료는 님블뉴런이 개발한 IP ‘이터널 리턴’을 기반으로 한 비공식 팬 게임의 아트 시안입니다. 관련 IP의 모든 저작권은 님블뉴런에 귀속됩니다.
