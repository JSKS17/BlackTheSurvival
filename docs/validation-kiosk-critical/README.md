# v0.1.2 검증 기록

이번 업데이트는 키오스크 구매 제한, 실제 지도 연결 기반 인접 판정, 영구 최대 코스트 성장, 일반 공격 치명타, 원작 장비 및 옵션 검색을 구현한다.

- 게임 규칙: **20,073개 검증 / 49개 시나리오 통과**. `KioskCoreTests.log`에 저장 호환, 구매 API 우회 방지, 인접 판정, 코스트 성장, 플레이어·적 치명타의 적용 범위·난수 보존 검사를 포함한다.
- 설명: **16,786개 검증 통과**. 카드 392종, 패시브 91종, 룬 16종, 장비 51종과 최대 코스트 조우 5종을 검사한다.
- 시스템 아트: 아이콘 **78개**와 기존 도트 스프라이트 **92개**의 크기·투명도·픽셀 격자·원본 생성 기록·해시 검증을 통과했다. [아트 기록](../art-system/map-critical-README.md)에 개별 생성 출처와 교정을 보관한다.
- Windows 개발 빌드: 실제 게임 화면 **70개**와 카드 요약 **4,704개** 배치를 검사한다. `native-screens.json`, `preview-layout.json`, `native-ui/`와 `ui-player.log`에 결과를 보관한다.
- Windows 배포: 개발·배포 빌드 로그, 설치 전후 실행 파일 해시, 정상 시작 로그 및 개인 이어하기 저장 보존 결과를 보관한다. 배포 ZIP은 설치된 런타임의 모든 파일과 CRC·SHA-256을 비교한다.

최대 코스트는 5로 시작하고 레벨 상승으로 증가하지 않는다. 보스 승리마다 1 증가하며, 니아·바바라·아디나·이바·펠릭스 조우의 한 선택지에서도 영구적으로 1 증가한다. 이전 저장은 이미 이긴 보스의 보너스를 한 번만 복원하며, 진행 중인 턴의 현재 코스트와 난수 상태를 유지한다. 카드 보상 예산의 기존 레벨 성장 규칙은 유지했다.

치명타는 기본 확률 0%, 장비별 5~6%, 합산 상한 30%다. 실제 일반 공격 카드가 적중했을 때만 본체 피해를 1.5배로 계산하고 소수점은 버린다. 추가 피해와 다른 카드에는 적용하지 않는다. 피해 예측은 난수를 소모하지 않는 일반 적중 기준이며, 치명타 확률을 별도로 안내한다. 상태이상 발동 알림이 실제 공격의 '막힘' 표시와 겹치는 연출 오류도 수정했다.

자동 플레이는 같은 seed 1~40을 평가했다. 이전 정책은 구매할 수 없는 만년 스프를 계속 구매하고 새 영구 코스트 보상을 평가하지 않아 **1승 / 39패 / 정체 0회**였다. 실제 판매 음식·모닥불 조리·공개 조우 보상·현재 사용 가능한 카드를 고려하도록 정책을 수정한 뒤 한 차례 평가한 결과는 **2승 / 38패 / 정체 0회**였다. 두 로그를 모두 보관했다. 이 단순 정책의 성공률은 사람의 승률을 의미하지 않으며, 새 성장 방식의 난도가 이전보다 높다는 결과도 함께 기록한다. 이 평가를 위해 적 체력이나 경제 수치를 바꾸지 않았다.

개인 저장과 GitHub 인증 정보는 배포 ZIP 및 소스에 포함하지 않는다. 전체 커밋 SHA와 GitHub 업로드 검증의 임시 기록은 무시되는 `Temp/`에 보관하여 검증 파일과 커밋의 순환 참조를 피한다.
