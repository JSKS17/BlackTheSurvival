# Classic 55명 스킬 정체성

`Assets/Scripts/Lumia/SkillIdentityClassic.cs`는 `ClassicRoster.cs`의 55명, Q/W/E/R **220장**에 각각 프로필을 등록한다. 카드 ID, 이름, 아이콘 경로, 원래 카드의 쿨다운은 유지한다.

v0.1.9의 무료 재사용·강화 자원 소비·조건부 할인 보완은 [기술 연계 조건](CONDITIONAL_RECASTS.md)에 기록한다. 이 문서의 고유 효과에 더해 해당 조건이 적용된다.

근거는 이미 저장한 [reference-skills.json](art-chibi/reference-skills.json)의 `subject_id`, `slot`, `original_name`, **전체 tooltip**이다. 이 파일의 아이콘 URL에는 `12.5.0`이 포함되어 있다. 아래 내용은 이 스냅샷을 턴제로 해석한 것이며, 현재 서비스 중인 원작의 수치나 최신 동작을 검증했다는 뜻이 아니다. 원문 T는 해당 실험체의 자원·연계 맥락을 이해하기 위한 근거로 사용했다. 별도의 패시브 구현 범위와 구분한다.

## 공통 규칙

- 모든 자원은 카드 주인별로 격리되며 한 전투에서 유지된다. 기본 상한은 1~4다. 다른 주인의 동명 자원은 공유하지 않는다.
- 조건과 비례 보너스는 **카드 사용 직전**의 상태를 읽는다. 이번 카드로 얻은 자원은 다음 카드부터 조건을 만족한다. 자원 증가·소비의 실행 순서로 같은 카드의 보너스를 부풀리지 않는다.
- 설치 피해, 출혈·화상, 지속 회복은 2~3회로 제한한다. 지연 피해의 `delay=1`은 현재 시전자 턴 종료에, `delay=2`는 다음 시전자 턴 종료에 발동한다. 설치물은 원래 카드 ID를 보존하여 해당 이펙트를 사용한다.
- 강화 기본 공격은 다음 기본 공격에 적용된다. 할인은 지정된 카드의 다음 사용 1회에만 적용된다. 새 할인은 무한히 중첩되지 않는다.
- 원래의 평면적인 중독과 전투 내내 쌓이는 힘은 이 프로필에서 제거했다. 피해는 `CardPresentation`의 기존 코스트 배율 계산 **이후** 명시적인 단발 값으로 덮어쓴다. 기존 방어·회복은 기본적으로 70%로 줄이고, 지속 회복으로 옮긴 카드는 즉발 회복을 추가로 낮춘다. 즉발 다단 공격을 지연 타격으로 분리한 카드에는 예전 다단 수를 함께 남기지 않는다.
- 거리, 벽 좌표, 다수의 적, 아군 대상, 설치물의 개별 HP, 실시간 게이지는 현재 단일 적 전투에서 표현할 수 있는 준비 자원과 유한 효과로 바꿨다. 아래의 한계가 명시된 부분은 원작 그대로의 재현을 주장하지 않는다.

## 확인 범위

이 파일은 55명 모두의 Q/W/E/R을 빠짐없이 명시하며, 각 카드가 적어도 하나의 고유 상태 또는 후속 효과를 사용한다. 컴파일, 전체 데이터 검증, 시뮬레이션과 실제 화면 확인은 상위 작업에서 이 프로필을 공유 엔진에 연결한 뒤 수행한다. 이 문서 작성 시점에 그런 실행 검증이 통과했다고 기록하지 않는다.
