# 효과 설명과 요약 표시

카드 392종, 패시브 91종, 룬 16종, 장비 47종의 설명은 실제 게임 효과 데이터에서 만듭니다. 작은 카드와 상세 화면의 **요약** 탭은 `DescriptionSummary.CardPreview`의 같은 짧은 문자열을 사용합니다. 작은 카드에는 내부 스크롤을 붙이지 않습니다.

## 짧은 카드 미리보기

- 즉시 피해·방어·회복과 기술을 구분하는 핵심 변신·자원 연계·설치 효과를 먼저 설명합니다. 추가 효과와 세부 적용 규칙은 **전체 설명** 탭에서 확인합니다.
- 문장 중간을 자르거나 말줄임표로 가리지 않습니다. 효과의 우선순위에 따라 최대 두 문단의 완결 문장을 선택합니다. 고정 글자 크기 11에서 가장 좁은 카드 본문 144px를 기준으로 약 다섯 줄 안에 들어가도록 분량을 제한합니다. 번들 `Galmuri11.ttf`의 실제 글자 폭과 줄바꿈 여유를 반영하며, 화면 검증에서는 실제 Unity 글꼴의 높이도 검사합니다.
- 대표 예시: 니아 W는 `피해 10을 줍니다. 블록을 모두 소모해 블록당 피해 4를 더하고 다음 Q 코스트를 1 줄입니다.`처럼 피해와 블록·할인 연계를 함께 설명합니다. 상세 전체에는 블록 상한, 적중 조건, 추가 상태이상과 할인 중첩 규칙도 남깁니다.
- 호출자가 넘긴 전투 중 현재 피해·방어·회복 수치로 즉시 효과를 표시합니다. 복잡한 카드에서 부가 회복이나 보호막이 핵심 연계를 가릴 정도로 길면 주된 즉시 행동과 핵심 연계를 우선 표시하며, 전체 설명에는 모든 수치가 표시됩니다.

## 상태와 자원

- 이렘의 고양이, 리오의 장궁 자세, 실비아의 바이크 탑승처럼 활성·비활성만 의미 있는 값은 **상태**로 설명하고 필드에서도 상태로 표시합니다. 이렘 R의 미리보기는 `고양이 상태로 진입하거나 해제합니다.`이며, 전체 설명은 두 분기를 각각 설명합니다.
- 대상에게 붙는 표식은 `적에게 예고장 표식 상태를 부여합니다.`, 준비 효과는 `가드 준비 상태를 활성화합니다.`, 변신은 `고양이 상태로 진입합니다.`처럼 실제 의미를 구분합니다. 조건에도 숫자 1 대신 `고양이 상태이면`, `적이 중상 상태이면`을 사용합니다.
- 아케이드 블록·배터리처럼 수치가 누적되는 값은 자원으로 유지합니다. 최대치가 1이어도 책갈피·비둘기·체스말·수정처럼 실제 설치물이나 물건인 값은 자동으로 상태로 바꾸지 않습니다.

## 전체 설명과 기타 능력 설명

- 피해·방어·회복 등 즉시 효과를 먼저 표시합니다. 동일한 발동 조건에 속한 효과는 조건을 반복하지 않고 함께 표시합니다.
- 실험체의 소개 문구와 정량 효과를 이중으로 설명하지 않습니다. 같은 문장도 중복해서 표시하지 않습니다.
- 자원은 수치로 설명합니다. `아케이드 블록을 1 증가시킵니다(최대 3)`, `수정을 1로 만듭니다`, `블록 × 4(최대 12)`, `모두 소모합니다`처럼 증가·설정·배율·소모를 구분합니다. 카드 장수와 공격 횟수의 단위는 유지합니다.
- 전체 카드 설명에는 발동 조건, 피해 배율과 상한, 지속 턴, 무료 연계, 소멸과 모든 부가 효과를 남깁니다. 패시브·룬·장비의 효과 정리에도 쿨다운과 턴별·전투별 발동 한도를 유지합니다.
- 상세 전체 설명에는 상태이상의 실제 동작, 자원의 공유 범위와 전투 종료 시 초기화, 중첩 규칙, 여러 패시브·룬·장비를 함께 사용할 때의 합산 한도를 추가합니다.
- 장비 요약에는 능력치와 특수 효과, 제어 저항·피해 유예, 무기 장착 시 D 카드 지급을 함께 표시합니다. 알렉스의 패시브는 무기마다 추가 D 카드를 얻는 규칙도 표시합니다.

공개 API는 `DescriptionSummary.CardPreview`(짧은 카드 미리보기·요약 탭), `Card`(모든 정량 효과의 정리), `Passive`, `Rune`, `Gear`, `Trait`입니다. 원문 상세 설명은 `CardPresentation.Describe`와 `Rules`, `TraitPresentation.Describe`로 제공합니다.

검증 명령: `./Tools/RunDescriptionAudit.ps1`.

독립 검사는 카드 392종 모두의 미리보기 분량, 완결 문장, 말줄임 없음, 즉시 피해와 핵심 효과 표시를 확인합니다. 전투 중 수치가 두 자리로 커지는 경우도 함께 검사합니다. 전체 효과 정리는 비어 있지 않은 설명, 반복 줄, 수치형 자원 표현, 상태형 조건, 주요 효과·지속시간·발동 한도·장비 외부 규칙을 확인합니다. 상태를 숫자로 증가시키거나 배율 자원으로 설명하는 문구가 남지 않았는지도 검사합니다. 동일한 가산 규칙이 문장 중복 제거로 숨겨지지 않는지도 확인합니다. 같은 값을 설정하는 규칙처럼 여러 번 적용해도 결과가 같은 중복은 문장 한 번으로 표시합니다. 현재 검사 결과는 `Tools/RunDescriptionAudit.ps1`의 로그와 최신 검증 기록에서 확인할 수 있습니다.

이번 수정의 독립 설명 검사 **16,400개 항목**을 통과했습니다. 실제 실행 파일에서도 카드 392종을 손패·인벤토리·도감·초기 선택·보상·상세 카드의 여섯 가지 크기와 기본/두 자리 수치로 측정한 **4,704개 조합 모두에서 본문 넘침이 0**임을 확인했습니다. 글자 크기는 11로 유지하며 카드 안의 스크롤을 사용하지 않습니다.

전체 실제 미리보기와 효과 정리는 [DESCRIPTION_SUMMARIES.md](DESCRIPTION_SUMMARIES.md)에 기록했습니다.
