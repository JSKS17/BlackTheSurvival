# 효과 설명과 요약 표시

카드 392종, 패시브 91종, 룬 16종, 장비 47종의 요약은 실제 게임 효과 데이터에서 만듭니다. 미리보기와 상세 화면의 요약은 `DescriptionSummary`의 같은 결과를 사용합니다.

- 피해·방어·회복 등 즉시 효과를 먼저 표시합니다. 동일한 발동 조건에 속한 효과는 조건을 반복하지 않고 함께 표시합니다.
- 실험체의 소개 문구와 정량 효과를 이중으로 설명하지 않습니다. 같은 문장도 중복해서 표시하지 않습니다.
- 자원은 수치로 설명합니다. `아케이드 블록을 1 증가시킵니다(최대 3)`, `수정을 1로 만듭니다`, `블록 × 4(최대 12)`, `모두 소모합니다`처럼 증가·설정·배율·소모를 구분합니다. 카드 장수와 공격 횟수의 단위는 유지합니다.
- 발동 조건, 피해 배율과 상한, 지속 턴, 쿨다운, 턴별·전투별 발동 한도, 무료 연계, 소멸은 요약에도 남깁니다. 복잡한 기술은 효과를 빼는 대신 요약이 더 길어질 수 있습니다.
- 상세 전체 설명에는 상태이상의 실제 동작, 자원의 공유 범위와 전투 종료 시 초기화, 중첩 규칙, 여러 패시브·룬·장비를 함께 사용할 때의 합산 한도를 추가합니다.
- 장비 요약에는 능력치와 특수 효과, 제어 저항·피해 유예, 무기 장착 시 D 카드 지급을 함께 표시합니다. 알렉스의 패시브는 무기마다 추가 D 카드를 얻는 규칙도 표시합니다.

공개 API는 `DescriptionSummary.Card`, `Passive`, `Rune`, `Gear`, `Trait`입니다. 전투의 카드 요약은 호출자가 전달한 현재 피해·방어·회복 수치를 사용합니다. 원문 상세 설명은 `CardPresentation.Describe`와 `Rules`, `TraitPresentation.Describe`로 제공합니다.

검증 명령: `./Tools/RunDescriptionAudit.ps1`.

최종 독립 검사: **8,441개 항목 통과**. 모든 항목의 비어 있지 않은 요약·상세 설명, 반복 줄, 수치형 자원 표현, 주요 효과·상태이상·조건·지속시간·발동 한도·장비 외부 규칙을 확인했습니다. 동일한 가산 규칙이 문장 중복 제거로 숨겨지지 않는지도 확인했습니다. 같은 값을 설정하는 규칙처럼 여러 번 적용해도 결과가 같은 중복은 문장 한 번으로 표시합니다.

전체 실제 요약은 [DESCRIPTION_SUMMARIES.md](DESCRIPTION_SUMMARIES.md)에 기록했습니다.
