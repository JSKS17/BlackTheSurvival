# 레어 조우 보상

v1.0.6은 레어 조우를 추가 크레딧 대신 덱과 능력을 직접 바꾸는 사건으로 구성한다. 스킨 테마 줄거리 91종은 유지하고, 실험체마다 세 행동을 제공한다.

## 해금과 등장

실험체 관측, Q·W·E·R 직접 사용, 고유 실험의 세 과제를 완료한 뒤 관측 데이터 **500**으로 보고서를 완성한다. 이미 완성한 보고서는 유지한다. 새로 완성한 보고서는 다음 새 원정부터 후보에 참여한다.

해금한 실험체의 일반 후보가 레어 후보로 변환될 확률은 1막 **12%**, 2막 **18%**, 3막 이후 **25%**다. 무한 모드에서도 전체 막 번호를 세며, 새 3막 주기로 돌아와도 확률은 25%로 유지한다.

한 화면에 최대 하나, 한 막에 한 번만 레어 후보가 표시된다. 실제 제시된 세 후보에 레어가 포함되어야 출현을 소진한다. 후보를 보았지만 다른 실험체를 선택한 경우에도 같은 막에서 다시 나타나지 않는다. 실험체별 레어 사건은 원정마다 한 번 완료할 수 있다. 약속 후속 조우의 80% 우선권은 유지한다.

## 세 행동의 구성

첫 행동에서는 해당 실험체의 전용 `++` 기술 카드 한 장을 구매한다. 두 번째는 실험체의 패시브 또는 R 카드이며, 세 번째에는 아래의 덱 정리·보조 룬·일반 카드 복제·무작위 F 중 하나를 배치한다. 원래의 일괄 크레딧 30 보너스는 제거한다.

| 종류 | 선택 결과 |
|---|---|
| 레어 강화 카드 구매 | 원본 코스트가 C일 때 `120 + 20 × C` 크레딧을 지불하고 해당 실험체의 `++` 카드 한 장을 얻는다. |
| 실험체 패시브 | 해당 실험체의 패시브를 얻는다. 빈 슬롯이 없으면 보유 패시브 중 교체할 대상을 선택한다. 같은 패시브를 중복 획득하지 않는다. |
| 원하는 카드 최대 2장 제거 | 무기 카드를 제외한 덱 사본 중 0~2장을 골라 제거한다. 덱에는 최소 5장을 남긴다. |
| 실험체 R | 해당 실험체의 일반 R 카드 한 장을 얻는다. |
| 나머지 보조 룬 | 현재 메인 룬 계열의 미보유 보조 룬을 전부 얻는다. 중복 발동하지 않으며 원정 중 유지한다. |
| 일반 카드 사본 2장 | 보유한 미강화 카드 중 원본 코스트가 1 이하인 한 장을 골라, 그 카드의 일반 사본 두 장을 덱에 추가한다. 조건을 충족하면 기본 공격·D·F도 선택할 수 있다. |
| 무작위 F | 전술 스킬 풀에서 무작위 F 카드 한 장을 얻는다. |

가격을 낼 수 없거나, 패시브와 보조 룬을 이미 보유했거나, 유효한 카드가 없으면 이유를 표시한다. 보상 없이 지나갈 수 있으며, 카드 제거·복제 후속 화면에서도 확정 전 대상을 변경하거나 건너뛸 수 있다.

## 레어 강화 카드

레어 `++`는 일반 `+` 강화와 별개의 사본 효과다. 카드 이름의 `++`와 레어 강화 배지로 구분하며, 같은 종류의 다른 카드나 이후 획득하는 일반 카드에 전파하지 않는다. 일반 강화 화면에서는 만들 수 없다.

기존 피해·방어·회복과 일부 조건부 효과를 강화하고, 원본 코스트가 3 이상이면 1 줄인다. 이진 상태·자원 상한·무료 연계 조건과 횟수·예약 시점·소멸 규칙은 유지한다. 상태 전환만 가진 기술에도 중첩되지 않는 제한된 방호 효과를 제공한다. 구매 상세·손패·덱·사용 전 정보·전투 기록은 해당 사본의 실제 수치와 설명을 사용한다.

## 저장과 연출

일반 조우 신호가 먼저 보인 뒤 픽셀 빛과 함께 스킨 도트와 레어 제목으로 바뀐다. 후보와 변환 여부는 저장하므로 화면을 닫거나 불러와도 다시 추첨하지 않는다. 연출을 건너뛰어도 보상이나 출현 횟수는 변하지 않는다.

카드 제거·복제·패시브 교체 도중의 저장도 이어갈 수 있다. 유효한 보상 행동을 선택할 때 완료를 기록해 중복 결제·복제·보상 지급을 막는다. 추가 보조 룬과 `++` 사본은 이번 원정 저장에 보존되며, 이미 해금한 보고서와 이전 강화 효과는 보존한다.
