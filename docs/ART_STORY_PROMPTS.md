# 스토리 컷신 아트와 생성 프롬프트

프롤로그 4컷·노말 엔딩 4컷·하드 엔딩 4컷, 총 12장의 독립 배경을 built-in `image_gen`으로 제작했습니다. CLI/API fallback과 외부 이미지 후처리는 사용하지 않았습니다. 선택한 생성 PNG를 바이트 그대로 프로젝트에 복사했습니다.

모든 이미지에는 Unity에서 나중에 표시할 내레이션·니아 대사를 직접 그리지 않았습니다. 이미지의 모니터·문서·플랫폼은 그림과 추상 도형으로 표현하며 읽을 수 있는 문자, 대사, UI, 서명과 워터마크를 포함하지 않습니다. 대본은 아래 제작 문맥 기록이며 이미지 내부 텍스트가 아닙니다.

## 참조와 스타일

- `Assets/Resources/Lumia/Lobby.png`: 아글라이아 연구소의 시안·자홍 조명, 니아 기본 복장·게임광 분위기.
- `Assets/Resources/Lumia/PortraitsReference/hana.png`: 하나의 짧은 갈색 머리·금색 장식·갈색 눈·흰 연구복·청록/검정/금색 복장.
- `Assets/Resources/Lumia/PortraitsReference/nia.png`: 니아의 보라 머리·반쯤 뜬 눈·분홍 헤드셋·보라/분홍 후디·검정 하의.
- 첫 선정 컷 `prologue_1.png`를 이후 장면의 동일 치비 얼굴·픽셀 스타일 참조로 사용했습니다. 노말·하드에는 `prologue_4`의 최초 생성본도 하나의 고해상도 얼굴·복장 참조로 사용했습니다. 해당 참조는 클립보드 글자 제거 교정 이전 버전입니다.

큼직한 머리·짧은 팔다리, 인물별 눈매와 표정을 유지하면서 큰 연구소와 루미아 섬 배경을 구성했습니다. 상단 내레이션과 오른쪽 아래 대사 상자의 핵심 인물 가림을 피하도록 얼굴을 중앙·왼쪽에 배치했습니다. 게임 내 기존 전투 스프라이트는 변경하지 않았습니다.

## 출력과 검증

- 경로: `Assets/Resources/Lumia/Story/`의 아래 12장과 각각의 `.meta`.
- 11장은 1672×941, `prologue_4`는 built-in 교정 출력인 1671×941입니다. 모두 약 16:9이며 캔버스를 리샘플링하지 않았습니다. Unity `ScaleToFit`에서 같은 컷신 영역을 사용합니다.
- 12장 모두 불투명 PNG이며 최종 생성 원본과 바이트가 같습니다.
- 이미지 메타: Point 필터, 밉맵 끄기, 무압축, NPOT 리사이즈 없음, 최대 4096, 독립 GUID.
- 직접 시각 검토: 하나·니아 얼굴/의상 일관성, 니아 재등장·여러 니아 허세·꿈에서 깨기·무한 도전 제안의 장면 구분, 대사 안전 영역을 확인했습니다. 실제 Unity 오버레이 검증은 별도의 게임 화면 검증에 기록합니다.
- `prologue_2`: 하나가 예정 컷보다 앞서 등장한 최초 출력에서 하나만 제거했습니다.
