# v1.0.6 레어 조우 검증

레어 조우의 보상 7종, 개별 `++` 강화 사본, 막별 조건부 등장 확률과 출현 한도, 변환 연출, 보고서 완성 비용 500을 검증한다.

## 게임 규칙

[집중 검사](rare-focused-tests.log) **17,480개 assertion**, [전체 게임 검사](core-tests.log) **135,815개 assertion**이 통과했다. [컴파일 바이너리·핵심 소스 SHA-256과 결과](core-tests-summary.json)를 보존한다.

- 91명·273개 선택지의 실제 획득·결제·완료와 중복 지급 차단을 검사했다.
- 일반·+·++ 사본의 실제 수치, 원본 불변, 저장·무료 연계·회수·소멸을 검사했다.
- 띠아의 붓색·아디나의 별자리 순환과 데비&마를렌의 양쪽 색상 조건, 요약 수치를 검사했다.
- 제거 대상의 개별 선택·최대 2장·최소 덱 5장·무기 제외, 복제 조건과 결과 사본 두 장을 검사했다.
- 추가 보조 룬의 전투 트리거·Modifier·지속 상태·중복 방지와 패시브 교체를 검사했다.
- 막당 실제 후보 출현 1회, 한 화면 1개, 약속 우선권, 무한 모드의 전체 막 번호, 구 저장과 대기 중 선택을 검사했다.
- 막별 300회 샘플에서 레어가 포함된 화면은 96/120/163개였다. 이는 세 후보 중 하나라도 레어인 화면 수이며, 실험체 후보별 12/18/25%와 다른 분모다.
- 보고서 비용 499/500 경계와 이미 완성한 보고서 보존을 검사했다.

## 실제 Windows 화면

[24개 네이티브 화면과 동작 검사](native-ui/coverage.json)와 [17개 화면의 시각 검토](visual-review.json)를 통과했다. 변환 전·중·후와 재로드, ++ 구매 상세·손패·덱, 제거·복제 선택과 취소·확정, 보조 룬의 위·아래 목록, 패시브 교체, 500/499 비용, 모든 보상이 불가능한 경우의 퇴장을 확인했다. 개인 원정·연구 저장 네 파일의 전후 해시가 동일했다.

시각 검토 후 패시브 교체 화면의 부제목 한 문장만 ‘실험체의 고유 능력을 익힙니다’로 바꿨다. 수치·규칙·배치는 동일하며 최종 배포 빌드에 이 문구를 반영한다.

## 빌드와 저장 공간

[배포 빌드](release-build.json), [실행 검사](release-startup.json), [ZIP 내용과 체크섬](windows-package.json)에 최종 결과를 기록한다.
