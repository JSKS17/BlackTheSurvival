# Black The Survival v1.0.0

91명의 실험체별 R 도트 애니메이션을 게임에 적용한 정식 버전입니다.

## 궁극기 연출

- 플레이어와 상대 실험체가 R을 사용할 때 해당 실험체의 전용 애니메이션을 재생합니다.
- 사용한 카드를 먼저 보여준 뒤 전투 화면에 애니메이션을 띄워 손패·카드 설명과 겹치지 않도록 했습니다. 전투가 끝나는 R도 연출을 마친 뒤 결과 화면으로 넘어갑니다.
- 환경 설정의 **움직임 최소화**를 켜면 흔들림과 이동을 줄이고 궁극기를 정지 프레임으로 표시합니다.

## 가넷 R — 처형식

- 기본 피해를 **8**, 턴 종료 지연 피해를 **8**로 낮췄습니다.
- 첫 사용이 적중하면 카드를 회수하고 **같은 턴 무료 재사용 1회**를 얻습니다. 남은 코스트가 0이어도 사용할 수 있습니다.
- **철처녀 표식이 남은 적의 체력이 재사용 직전에 최대 체력의 20% 이하**일 때, 재사용이 적중하면 방어도를 무시하고 처형합니다. Q·E로 표식을 소모하면 처형되지 않으며, 보스와 상대 가넷도 같은 규칙을 사용합니다.
- 재사용 후 카드는 소멸합니다. 첫 사용이 빗나가거나 무료 재사용을 남기고 턴을 끝내도 소멸합니다. 기존 치명상 방지 효과는 유지됩니다.
- 카드 사용 전 정보와 전투 기록에서 처형 조건과 결과를 확인할 수 있습니다.

## 실행 및 저장

**BlackTheSurvival-v1.0.0-Windows-x64.zip 전체를 한 폴더에 압축 해제한 뒤 BlackTheSurvival.exe를 실행하세요.** 실행 파일과 함께 들어 있는 데이터 폴더·파일이 필요합니다.

기존 개인 저장 데이터와 연구 기록은 유지됩니다. 저장 파일 이름·경로와 버전 형식은 바꾸지 않았습니다.
