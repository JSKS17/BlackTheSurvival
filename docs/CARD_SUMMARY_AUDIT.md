# 전체 카드 요약 감사

## 범위와 기준

실제 `GameDatabase`를 초기화해 등록 카드 **392개**(기본 2, 실험체 Q·W·E·R 364, 무기 D 23, 전술 F 3)를 모두 덤프했다. 별도 `WildlifeMechanics`에 있는 동물 전용 기술 2개도 추가하여 **총 394개 고유 카드 ID**를 대조했다. 기술 카드만 골라 검사하거나, 앞부분 실험체만 표본 검사한 결과가 아니다.

원천 자료는 카드 기본 수치·강화 전 정의, 1,108개 `SkillRule`, 289개 상태이상 규칙, 무료 연계 대상·조건·턴 시점, 필중, 대상 선택·충전·예견·소멸·X·체력 계수, 니나의 별도 체력과 생존 보호이다. 모든 원천 규칙은 개별 인덱스·계수·상한·기간·지연·조건 두 개·직전 기술·적중 여부까지 보존했다.

요약은 상세 설명을 그대로 복제하는 것이 아니다. 부차 계수는 상세에서 확인하도록 압축할 수 있지만, 카드 선택을 바꾸는 **효과군과 그 종속 조건**은 남겨야 한다. 특히 생성과 소모, 상태 전환과 수치 자원, 즉시 효과와 다음 기본 공격·턴 종료 설치 효과, 이번 턴과 다음 자기 턴의 무료 연계, 여러 대상과 대안 선택을 서로 바꾸면 안 된다.

## 누락을 찾는 방법

1. 전 카드의 실제 정의와 기존 요약·상세 문장을 함께 저장한다.
2. 모든 원천 규칙을 효과군으로 분류한다. 같은 효과군의 부차 수치는 압축할 수 있어도 반격·부활·소환·회복·할인처럼 다른 행동은 삭제하지 않는다.
3. 독립 검사기는 효과군·상태명·무료 연계·소멸·필중·엔진 특수 기믹의 누락 신호를 전 카드에서 추출한다. 키워드 검사는 판정 보조이며 동의어·통합 문장 때문에 나오는 신호는 실제 문장과 조건을 다시 읽어 판정한다.
4. `CardSummaryMechanics`와 별개로 원천 `SkillRule`·상태·엔진 경로를 확인해 수치 생략과 효과 삭제를 구분한다. 구현 함수가 출력했다는 사실만으로 의미 보존을 통과시키지 않는다.
5. 압축된 최종 요약을 같은 394개 ID에 다시 적용하고, 원천 정의가 요약을 생성하는 동안 변하지 않는지도 확인한다.

6. 전용 압축 문장 22개를 별도로 추출하여, 현재 기본 카드가 그 경로를 사용하지 않더라도 실제 즉시 공격·방어·회복·회피·드로우와 상태이상 시점을 확인한다. `피해 분담`·`다음 기본 공격`·`소환 공격`이라는 단어만으로 즉시 직접 공격이 보존됐다고 판정하지 않는다.

기존 요약에서는 즉시 수치 우선·최대 두 부분·폭 66/약 5줄 제한으로 뒤의 핵심 행동이 제외됐다. 독립 검사에서 327개에 검토 신호가 발생했다. 이 수치는 확정 버그 수가 아니며, 아래의 실제 전후 사례와 최종 재감사로 검증한다.

## 중요한 반례

- **수아 W:** 자신 보호와 적 공격은 택일이다. 적 분기는 필중이다. 자신 보호 뒤에 조건 없이 실명을 붙이면 두 효과가 함께 적용되는 것처럼 보인다.
- **가넷 R:** 첫 공격은 일반 판정이다. 표식이 남은 적에게 이번 턴 무료 재사용할 때만 필중하며, 처형은 재사용 **전** 적 체력 20% 이하 조건을 확인한다. 첫 사용 실패·재사용·턴 종료의 소멸 규칙도 유지한다.
- **실비아 E:** 바이크 상태에서만 필중한다. 무조건 필중으로 단순화하지 않는다.
- **캐시 Q:** 사용 전 상처 2 이상이라는 내부 판정은 이번 적중으로 최대치 3에 도달해 중상을 만드는 연계 조건이다. 단순히 적중하면 언제나 재사용하는 카드로 쓰지 않는다.
- **클로에 R:** 2턴 피해 분담과 1턴 생존 보호를 구분한다. 보호 중 피해 분담 뒤에도 니나가 살아 있어야 주인의 체력 1을 유지하며, 같은 타격으로 니나가 소멸하면 보호도 끝난다. 무조건 무적·치명타 방지·군중 제어 면역으로 설명하지 않는다.
- **키아라 W:** 사용 전 방어도를 기준으로 직접 피해를 더한다. 이번 W로 얻는 새 방어도를 같은 W의 피해에 다시 넣거나 기존 방어도를 소모한다고 쓰지 않는다.
- **톤파 D:** 지속 피해 반사나 피해 비례 반사가 아니라 직접 공격의 각 적중에 고정 반격이다. 턴당 1회 제한이 없으며 다른 반격 카드의 제한은 유지한다.
- **로지 Q·W·E / 바냐 E / 슈린 E:** 강화뿐 아니라 기존 설치 효과를 회수·종료하는 행동도 실제 규칙에 있다. `clear_effect`를 생략하면 남은 설치 효과가 중복되는 것으로 오해할 수 있다.
- **소모의 인과관계:** 에이든 E의 암페어 소모는 과전하 전환 조건이며 볼트 표식 피해의 비용이 아니다. 윌리엄 E의 공 회수·소모는 마운드 방어와 독립이다. 테오도르·블레어의 표식 해제를 무관한 회복·방어 전체의 비용으로 붙이지 않는다. 같은 자원이나 같은 조건 가드로 연결된 효과만 소비와 강화의 인과문으로 묶는다.
- **상태 갱신과 토글:** 코렐라인 Q·E는 같은 적중 조건에서 표식 해제 후 부여를 순서대로 실행해 최종적으로 표식을 갱신한다. `state_on`과 `state_off`가 모두 있다는 이유만으로 진입·해제 토글로 설명하지 않는다. 실제 `state_toggle` 또는 서로 보완적인 전환 조건을 확인한다.
- **사용 전 스냅샷:** 자원 조건은 카드 사용 전 상태로 판정한다. 실비아의 하차 조건은 사용 전 연료 0이며 이번 공격으로 0이 되었다는 이유만으로 즉시 하차하는 조건이 아니다. 엘레나도 사용 전 냉기 기준을 이번 카드의 증가 후 수치와 혼동하지 않는다.
- **적중 조건과 지연 효과:** 엘레나 Q의 냉기 생성은 적중 조건이지만 고드름 설치는 무조건이다. 아르다 W의 즉시 정수 회복·소모를 나중의 입방체 적중 조건에 붙이지 않는다. 아이작 E의 방어도 파괴는 검거가 준비된 E의 적중이며 아무 카드의 다음 공격이 아니다.
- **즉시 행동과 예약 공격:** 니아 R의 직접 공격·방어·적중 기절과 턴 종료 게임월드 공격을 구분한다. 캐시 Q의 다음 기본 공격 강화와 클로에 R의 니나 협공은 각각의 직접 공격을 대체하지 않는다. 엘레나 W는 공격·방어·회피를 모두 제공한다. 리오 R의 자세별 추가 효과는 상시 직접 공격에 더해지는 효과이며, 바바라 R의 카드 적중 제어를 소환 적중 제어로 바꾸지 않는다.
- **동물 전용 기술:** 멧돼지의 4, 곰의 5는 절대 피해가 아니라 각 동물 기본 공격에 더하는 수치이다. 2·3턴 주기, 제어로 중단되는 조건과 멧돼지의 실패 후 좌절을 보존한다.
- **확률:** 현재 `SkillRule`에는 별도 효과 발동 확률 필드가 없다. 명중·회피는 실제 회피율과 `AccuracyMechanics` 판정을 따르고, 기본 공격 치명타는 장비·실행 모드의 확률과 배율을 따른다. 카드 요약에 임의의 스킬 발동 확률이나 쿨다운을 만들지 않는다.

## 최종 검증 상태

- 최종 원천 덤프의 고유 카드 **394개 전체**를 다시 대조했다. 원천 조건·대상·소모·설치·연계·소멸과 주요 반례에 대한 독립 검사 **1,795/1,795개**가 통과했다.
- 효과군 검토 신호가 남은 **9개 카드**는 실제 문장을 다시 읽어 판정했다. `바꾸다`라는 설정 동사, `중상`·`표식`이라는 상태명, `방어를 얻다`와 조건부 피해 표현이 검사기의 제한된 동의어 목록 밖에 있던 경우이다. 남은 의미 오류로 판정한 항목은 없다.
- 미리보기 계산에서 최장 **8줄**, 최대 가중 폭 **100.35**이며, 8줄·폭 108을 초과한 카드는 **0개**이다. 이 계산은 의미·문장 길이 검증이며, 실제 게임 화면의 시각 검증은 빌드 검증과 함께 별도로 수행한다.
- 강화 전 원천 카드 수치와 중첩 규칙의 전체 재귀 비교에서 허용된 변경은 **이바 R의 X 계수 6→8, 쇼우 R의 X 계수 7→9**뿐이다. 클로에 R의 니나 생존 보호는 별도 엔진 경로이며 카드 정의 비교와 별도로 확인했다.
- 추출 전후 **99개 런타임 소스의 SHA-256**이 일치해, 검사 도중 원천이 변경되지 않았음을 확인했다. 변경 전 비교에는 v1.0.8 원본 덤프를 사용했다.
- 전용 압축 문장 **22개 전체**를 실제 비공개 함수에서 추출했다. 각 즉시 행동과 **22개 상태이상 규칙의 시점·조건**을 원천과 대조했고, 별도 직접 행동·시점 검사 **61/61개**도 통과했다. 기본 카드에서 선택되지 않는 fallback 문장도 포함한다.
- 일반 요약기의 소비와 강화는 조건이 같다는 이유만으로 인과관계로 연결하지 않는다. 자원 소모, 상태 해제, 상태 갱신은 각각 원천 조건에 따라 남기고, 핵심 연계 카드의 압축 문장은 별도 반례로 검사했다.

## 재현 자료

작업용 대용량 덤프와 실행 파일은 Git에 넣지 않고 `Build/CardSummary109Verification/`에 보존한다.

- `CardSummaryDump.cs`, `Dump.ps1`, `DumpAfter.ps1`: 실제 데이터베이스 초기화와 전 카드 추출.
- `cards-baseline-original.json`: 변경 전 요약과 정의를 보존한 원본.
- `cards-before.json`, `semantic-ledger-before.json`: 원천 규칙·조건·상태·설명 전체 덤프.
- `catalog-coverage-before.json`: 고유 ID·종류·규칙 수·소스 해시.
- `semantic-signals-before.json`, `semantic-signal-counts-before.json`: 전 카드의 효과군 누락 검토 신호.
- `audit_catalog.py`, `audit_signals.py`: 원천 분류와 독립 신호 검사.
- `cards-after-final.json`, `semantic-signals-after.json`, `manual-semantic-review-final.json`: 최종 요약 덤프·효과군 신호와 독립 수동 판정.
- `critical_cases.py`, `critical-cases.json`: 전체 기본 효과·연계·특수 조건·소모 인과 반례의 독립 검사.
- `compare_card_data.py`, `mechanical-data-diff.json`: 전체 카드 정의의 재귀 비교와 허용된 수치 변경 확인.
- `source-correspondence.json`: 덤프·검사에 사용한 런타임 소스 전체의 해시.
- `template_effect_matrix.py`, `template-effect-matrix.json`, `template_semantic_review.py`, `template-semantic-review.json`: 전용 압축 문장 전체와 실제 즉시 행동·상태 시점의 독립 대조 원장.
- `consume-condition-review.md`, `unrelated-consume-candidates.json`, `state-off-candidates.json`: 자원 소비·상태 해제·갱신의 인과관계 후보 추출과 독립 검토.
