# 카드 사용 전 정보와 전투 기록

v0.1.25. 손패 오른쪽 위 `?`에서 현재 상태를 기준으로 사용 전 정보를 열고, 확인 창에서 해당 손패 사본을 사용할 수 있다. 보관 표시와 `?`가 겹치지 않도록 배치했다. 정보 창과 전투 기록을 보는 동안 상대의 자동 행동은 정지한다.

미리보기는 모든 공개 저장 필드를 복제한 별도 엔진에서 기존 코스트·피해·상태 제한·연계 조건·보스 판정 함수를 조회한다. 실제 원정의 난수·코스트·무료 사용권·필드·연구·대기 중 연출을 바꾸지 않는다. 기본 코스트, 상태 가산, 할인, 남은 무료 사용권, 부족한 코스트와 상태로 인한 사용 제한을 구분한다. 직접 피해는 일반 적중을 가정한 값이며 방어도·회피·치명타·피격 패시브·설치물·후속 효과의 불확실성을 명시한다. 수치/직전 기술 조건은 현재 값과 필요한 값을 함께 보여주고 적중·예약 효과는 발동을 확정하지 않는다.

보스의 이동 금지·디버프 금지·강한 직접 공격 제한 등은 실제 카드 분류와 대응 규칙을 참조한다. 피해 결과에 따라 달라지는 위반은 가능성으로 표시한다. 정보 창에서 사용을 누르면 원래 `PlayCard` 흐름으로 처리하며, 연습 전투에서는 해당 학습 단계가 허용한 카드만 사용할 수 있다.

원정에 `combatHistory`와 일련번호를 저장한다. 카드 사용 시작에는 지불 코스트, 결과에는 실제 체력 피해·방어 흡수·회피·치명타·회복을 기록한다. 양측 행동, 상태 효과, 패시브·룬·장비·증강·보스 효과, 전투와 턴 시작/종료를 기록하고 최대 240개로 제한한다. 현재/마지막 전투 또는 원정 전체, 양측/하나/상대, 전체/카드/효과별로 거를 수 있다. 원정 종료 화면에서도 마지막 전투를 확인할 수 있다. 이전 저장에는 빈 목록을 보충하며 이전 행동을 추측해서 생성하지 않는다.

순수 규칙 검증은 392장×양측의 미리보기 무변경 검사, 사용 제한·무료 사용·조건·보스 판정, 실제 양측 로그·패시브/상태·방어 흡수·저장 복원·기록 상한을 포함한다. 실제 화면과 JSON 저장 검증은 [v0.1.25 검증](validation-presentation/README.md)에 기록한다.
