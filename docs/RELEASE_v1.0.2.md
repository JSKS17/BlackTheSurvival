# Black The Survival v1.0.2

- 프롤로그 두 번째 컷의 니아가 기존 무표정을 유지하면서 양쪽 눈과 입이 더 자연스럽게 보이도록 얼굴을 다시 그렸습니다. 이미지 크기와 포즈는 유지했습니다.
- 늑대·멧돼지·곰·닭을 원작 외형과 실험용 장구를 참고한 새 도트로 교체했습니다.
- 멧돼지의 **돌진**, 곰의 **지면 강타**를 동물 전용 기술로 추가했습니다. 다음 행동을 확인하고 회피나 강한 제어기로 대응할 수 있습니다. 플레이어의 카드 보상·도감·덱에는 등장하지 않습니다.
- **변이 동물**이 2막에서는 8%, 3막에서는 14% 확률로 등장합니다. 체력은20%, 공격력은15% 높고, 기존에 오브젝트를 주던 늑대·곰은 드롭 확률이5%p 높습니다. 1막에는 등장하지 않습니다.
- 변이 여부는 구역에 고정되어 지도 확인·이어하기로 달라지지 않습니다. 닭·들개·멧돼지는 계속 오브젝트를 주지 않으며, 기본공격 카드3%와 고기50%의 기존 보상 확률도 유지합니다.
