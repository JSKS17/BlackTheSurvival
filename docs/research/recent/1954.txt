 패치노트 
 

 
 2년 전 
 

 
 2024.06.05 - 1.23 패치노트

 
 
 1.23 업데이트는 6월 5일 수요일 오전 11시부터 오후 3시까지, 약 4시간의 정기 점검을 통해 적용됩니다. 
 
 신규 실험체 - 다르코
 방망이를 사용하는 새로운 실험체 다르코 가 루미아 섬에 등장합니다. 
 다르코 는 출시 후 2주일 간 A-coin 9,900개 에 판매되며, 6월 11일(화)까지 랭크 대전에서 선택할 수 없습니다. 
 “이제 돈 좀 벌어볼까.“  
 
 
 
 
 압류 (P) 
 다르코의 기본 공격이 대상의 방어력을 3초 동안 4/7/10% 훔칩니다. 
 쿨다운: 8초 

 


 
 고리대금 (Q) 
 다르코가 2초 동안 적 실험체를 향해 이동할 때 이동 속도가 15% 증가합니다. 
 다르코의 다음 기본 공격은 20/40/60/80/100(+공격력의 40%)(+대상 최대 체력의 5%) 의 추가 스킬 피해를 입히고 5초 동안 표식을 남깁니다. 
 표식이 남은 대상에게 이 스킬을 사용하면 피해량이 10/20/30/40/50% 증가합니다. 
 쿨다운: 3초 

 스태미나 소모량: 40 

 


 
 수금 (W) 
 다르코가 50/75/100/125/150(+공격력의 40%) 의 피해를 흡수하는 보호막을 획득하며 1초 동안 근처 적 실험체들의 이동 속도를 20/22.5/25/27.5/30% 감소시킵니다. 적중한 적 실험체 하나 당 최대 체력의 6% 의 보호막을 추가로 획득하고  3초  동안 공격력을 1/2/3/4/5 훔칩니다. 
 효과 범위: 원형 4m 

 최대 적중 가능한 적 실험체 수:  4 

 보호막 유지 시간: 3초 

 쿨다운: 10초 

 스태미나 소모량: 80 

 


 
 추심 (E) 
 다르코가 돌진 후 지면을 내리찍어 적들에게 60/115/170/225/280(+공격력의 85%) 의 스킬 피해를 입히고 0.5초 동안 공중에 띄웁니다. 
 피해 범위: 원형 반지름 2.2m 

 이동 거리: 4m 

 이동 속도: 15m/s 

 쿨다운: 14/13/12/11/10초 

 스태미나 소모량: 80 

 


 
 강제집행 (R) 
 다르코가 적 실험체를 붙잡고 제압한 후 끌고 가 바닥에 내리꽂습니다. 
 주변에 있는 적들에게 100/225/350(+공격력의 55%)(+붙잡은 대상 최대 체력의 25%) 의 스킬 피해를 입히고, 0.5초 동안   이동 속도를 80% 감소시킵니다. 
 사거리: 2.5m 

 제압 지속 시간: 1초 

 제압 이동 거리: 6m 

 쿨다운: 90/75/60초 

 스태미나 소모량: 100 

 


 
 신규 스킨 및 이모티콘
 6월 11일(화) 해변가 키아라 희귀 스킨이 출시됩니다.  
 “여름은 싫지만... 어쩔 수 없지...”  
 
 
 다르코 어서오세요 고객님~, 돈갚아, 할짝, 자주보자고  이모티콘이 출시됩니다. 
 
 전투 메이드 토큰 종료 안내
 6월 5일 (수) 점검 이후 전투 메이드 토큰이 종료되어 모두 소멸될 예정입니다. 

 잔여 전투 메이드 토큰은 소멸되기 전에 교환소에서 아래 2가지 상품으로 교환할 수 있습니다. 
 전투 메이드 토큰 3개 → 체인지 토큰 2개 

 전투 메이드 토큰 1개 → A-Coin X 150 

 
 ※ 전투메이드 토큰 종료 후 소멸된 토큰에 대해서는 더 이상 도움을 드릴 수 없습니다. 
 
 시스템
 게임 준비 단계 루트 특성 편집 기능 
 
 기상 효과에 따라 일부 특성의 효용이 달라질 수 있습니다. 게임 준비 단계에서 세부 특성을 보다 쉽게 수정할 수 있게 하여, 숙련된 플레이어가 기상 효과와 팀 조합에 맞게 특성을 보다 편리하게 수정할 수 있게 합니다. 
 이제 게임 준비 단계에서 루트를 선택하면, 루트의 특성도 편집할 수 있습니다. 

 단, 게임 준비 단계에서 편집한 특성은 루트의 서버 정보를 변경하지 않고, 해당 게임에서만 적용됩니다. 

 
 기상 효과 
 안개가 조건부 재등장하게 되었습니다. 
 서브 기상 - 안개가 일반 대전, 사용자 설정 대전, AI 대전에 확률적으로 등장합니다. 
 랭크 대전에는 등장하지 않습니다. 

 
 
 비가 올 때 스태미나 재생 효과를 부여하여, 세부 특성에 변화를 줄 여지를 만듭니다. 
 메인 기상 - 비 일 때, 스태미나 재생 +100% (신규) 

 
 벼락에 맞으면 아프지만, 좋은 점도 있습니다. 전류가 신체 내 VF 에너지를 활성화 해 잠시 동안 이동 속도가 빨라집니다. 
 벼락에 피격 시 5초 동안 이동 속도가 15% 증가합니다. (신규) 
 연속으로 벼락을 맞을 시 효과가 중첩되지 않고 지속 시간이 갱신됩니다. 

 
 
 음료 모닥불 제작 
 이제 모닥불에서 상위 등급 음료를 쉽게 제작할 수 있게 됩니다. 
 일반 등급 음료를 모닥불로 가져가면 상위 등급 음료를 제작할 수 있습니다. (음료 항목 참고) 

 그 외에도 스태미나 수급을 위한 선택지를 추가합니다. 
 기상 - 비의 스태미나 재생 효과 추가 

 일부 장비에 스태미나 재생 효과 추가 

 
 남은 생존 팀 수 비공개 처리 
 특정 시점부터 남은 생존자 수뿐만 아니라 생존 팀 수도 공개하지 않도록 하여, 게임 후반부에서 남은 팀 수를 기반으로 한 다른 팀의 전략적 상황 예측을 어렵게 합니다. 
 적용 시점: 남은 생존 팀 수가 3팀 이하이거나 6일차 낮이 되었을 때 

 
 승전보 
 금지 구역이나 임시 안전지대 페이즈 전투에서 빈사 상태인 적을 시간 내에 처리하기 어려운 문제가 있어, 승전보의 금지 구역 카운트 회복 시점을 변경합니다. 
 승전보의 금지 구역 카운트 회복 시점: 적 사망 시 → 적 빈사 시 

 
 부활 비용 증가 
 팀원 크레딧을 사용할 수 있게 되면서 평균 부활 횟수가 늘고 임시 안전지대 페이즈에 생존 팀이 많아졌습니다. 팀원 부활 비용을 높여 부활을 조금 더 어렵게 합니다. 
 팀원 부활 비용 200 → 250 크레딧 

 
 팀 초대 및 친구 UI 개선 
 팀 초대 메시지가 이제 ESC로 취소되지 않으며, 수락(1)과 거절(2) 단축키를 새로 배정합니다. 

 초대 메시지에 푸쉬 애니메이션이 적용됩니다. 

 2개 이상의 초대가 쌓였을 때, 초대 수를 보여줍니다. 

 
 친구 초대와 팀 초대가 모두 왔을 때 둘 다 표시해줍니다. 

 
 친구 상태 중 “리플레이 보는 중” 상태가 추가됩니다.

 스킬 레벨업 안내 연출이 어색하게 출력되는 문제 수정 

 게임 준비 단계에서 특성 추가 및 수정 시 루트에 설정된 특성이 제거되는 문제 수정 

 키오스크 부활 시 소음 핑이 출력되지 않는 문제 수정 

 신속 아이템 스킬을 지닌 일부 무기 아이템이 미스릴 방패의 신속 아이템 스킬보다 우선 순위가 낮게 지정된 문제 수정 

 환경 오브젝트 모래광대버섯의 모래 연막 중앙 위치에 은신 상태가 적용되지 않는 문제 수정 

 연못의 특정 위치에서 인게임 시작 시 실험체가 반투명 상태로 출력되는 문제 수정 

 탐색 가이드 원격 호출 사용 옵션 On 설정 시 목표 경로 지정이 불가능한 문제 수정 

 사용자 설정 게임에서 팀 전멸 후 관전 시 사운드가 On 상태로 변경되는 문제 수정 

 낮은 빈도로 리플레이 대상 정보 UI에서 다른 실험체의 아이템이 출력되는 문제 수정 

 일부 감시 카메라 스킨 피격 지점이 하단으로 적용되어 있는 문제 수정 

 전체 관전에서 승리 연출 이후 패배 연출이 출력되는 문제 수정 

 관전 및 리플레이에서 대상 정보 UI 내 초월 아이콘 툴팁이 출력되지 않는 문제 수정 

 리플레이 타임라인에 브리핑룸 시간이 포함되는 문제 수정 

 키오스크를 연속으로 상호작용 시 효과음이 출력되지 않는 문제 수정 

 
 실험체 및 무기 개선 사항 
 마르티나  일시정지 - 방송 중(W) 상세 툴팁에서 스킬 피해량과 레벨별 스킬 피해량 일치하지 않는 문제 수정 

 알론소  바운싱 실드(W) 사용 중 서브 기상 효과 - 벼락 피해가 적용되지 않는 문제 수정 

 특정 상황에서 카티야  저격총 무기 스킬 저격(D) 사용 시 정밀 조준(R) 인디케이터가 출력되는 문제 수정 

 
 로비 개선 사항 
 듀오와 만나지 않기 옵션 On 상태일 때 사전구성팀과 매칭되는 문제 수정 

 특정 상황에서 팀원이 결과 확인 중 상태로 출력되며 매칭 시작이 불가능한 문제 수정 

 중국어 번체 환경에서 로비 및 개인 상점 일부 언어가 현재 설정 중인 언어로 출력되지 않는 문제 수정 

 로비 채팅 사용 안함 옵션이 방송 모드 항목으로 이동합니다. 

 상품 구매 시 A-Coin이 부족할 때 A-Coin 구매 팝업이 노출됩니다. 

 실험체 상세 페이지에서 체험 해보기로 연습 모드 진입 시 일부 진입 기능이 정상적으로 동작하지 않는 문제 수정 

 개인 상점의 할인 상품 구매 팝업 내 가격과 실제 구매 가격이 다르게 표시되는 문제 수정 

 이벤트 NP 잔여 기간 표시가 일부만 노출되는 문제 수정 

 고급/희귀 스킨 보급권을 10회 개봉 시 에러 팝업이 출력되는 문제 수정 

 인게임에서 옵션 > 게임 > 로비 채팅 사용 안 함 설정 시 귓속말이 차단되지 않는 문제 수정 

 특정 상황에 루트 제작 시 제작 가능 장비 목록이 잘못 출력되는 문제 수정
