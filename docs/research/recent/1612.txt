 패치노트 
 

 
 2년 전 
 

 
 2023.12.07 - 1.10 패치노트

 
 
 1.10 업데이트는 12월 7일 목요일 오전 11시부터 오후 3시까지, 약 4시간의 정기 점검을 통해 적용됩니다. 
 
 신규 실험체 - 츠바메
 암기를 사용하는 새로운 실험체 츠바메 가 루미아 섬에 등장합니다. 
 츠바메 는 출시 후 2주일 간 A-coin 9,900개 에 판매되며, 12월 12일(화)까지 랭크 대전에서 선택할 수 없습니다. 
 “그 의뢰, 받아들이죠.”  
 
 
 
 히구루마류 암살술 (P) 
 츠바메는 기본 공격 사거리가 4.5 으로 고정되며 기본 공격으로 치명타가 발동하지 않는 대신 치명타 확률 1% 마다 0.4 , 치명타 피해 증가량 1% 마다 0.8 만큼 공격력이 증가합니다. 
 바꿔치기술 : 츠바메가 안개의 술 과 오의 - 생사 각인 사용시 자신의 위치에 나무토막을 남깁니다. 나무토막은 5초 동안 지속됩니다. 
 바꿔치기술 쿨다운:  20초 

 히구루마류 암살술 은 1레벨로 고정 되며 더 이상 레벨업 할 수 없습니다. 
 


 
 수리검 전개 (Q) 
 차륜수리검 3개를 지정한 위치로 투척합니다. 수리검은 경로의 끝에 도착하면 회전하며 적중한 적에게 70/110/150/190/230(+공격력의 90%) 의 스킬 피해를 입히고 이동 속도를 1초 동안  40% 느려지게 합니다. 
 표식이 있는 적 대상에게는 표식을 1중첩 추가합니다. 
 범위: 각 투사체당 반경 0.87m 

 사거리: 2 ~ 5m 

 쿨다운: 6/5.5/5/4.5/4초 

 스태미나 소모량: 30/35/40/45/50 

 


 
 제비걸음 (W) 
 츠바메가 간결한 보법으로 더 빠르게 움직여 이동 속도가 60/65/70/75/80% 증가했다가 1.6/1.7/1.8/1.9/2초 에 걸쳐 점점 감소하며 3초 동안 다음 기본 공격  2회 의 공격 속도가 30/35/40/45/50% 증가합니다. 
 쿨다운: 11/10/9/8/7초 

 스태미나 소모량:  100/80/60/40/20 

 


 
 안개의 술 (E) 
 지속 효과 : 바꿔치기술 의 쿨다운이 1/2/3/4/5초 감소합니다. 
 츠바메가 지정한 방향으로 공중회전하며 은신합니다. 은신은 0.7초 동안 유지되며 공중회전하는 동안 지정 불가 상태가 됩니다. 
 안개의 술 로 인한 은신 중에 제비걸음 을 사용하면 은신을 해제하지 않고 발동합니다. 
 이동 거리: 2.5m 

 쿨다운: 24/21/18/15/12초 

 스태미나 소모량: 100/90/80/70/60 

 


 
 오의 - 생사 각인 (R) 
 지속 효과 : 츠바메는 기본 공격에 적중한 적에게 6초 동안 지속되는 표식을 새깁니다. 표식은 최대 3회 중첩되며, 최대 중첩 상태인 대상은 츠바메에게 시야를 공유합니다. 
 표식이 최대 중첩인 적 대상이 사거리 내에 있으면 사용 가능합니다. 해당 적 대상에게 빠르게 이동하며 새겨진 표식을 베어 25/50/75/100/125(+공격력의 70%)(+대상 최대 체력의 2/2.5/3/3.5/4%(+공격력 1당 0.05%)) 의 스킬 피해를 입히고 피해량의 75% 만큼 회복합니다. 적 실험체에게 피해를 입히면 제비걸음 의 쿨다운이 50% , 바꿔치기술 의 쿨다운이 30% 감소하고 6초 동안 각인된 전투 감각 이 깨어납니다. 각인된 전투 감각 은 최대 3회 중첩되며, 중첩마다 오의 - 생사 각인 의 피해량이 33% 증가합니다. 
 나무토막 을 대상으로 지정하여 사용하면 나무토막 의 위치로 빠르게 이동하며 자리를 바꿉니다. 
 사거리:  5m 

 쿨다운: 0.5초 
 쿨다운 감소 능력치의 영향을 받지 않습니다. 

 
 스태미나 소모량: 50 

 오의 - 생사 각인 은 츠바메가  4/7/10/13/16레벨 이 될 때 학습 가능하며, 최대 5레벨까지 레벨업 할 수 있습니다.

 “듀오와 만나지 않기” 옵션이 현재 개발중으로 추후 추가될 예정입니다 
 
 핑 시스템 2차 개선 
 지난 프리 시즌 업데이트에 이어 핑 기능이 조금 더 추가됩니다. 
 부활 불가, 루트킷 구매 불가 등 사용 불가 상태를 핑하면, 사용 불가능한 이유를 팀원들에게 시스템 채팅으로 알려줍니다. 

 타 플레이어의 빈 장비 슬롯을 핑하면, 빈 슬롯을 발견했다고 팀원들에게 시스템 채팅으로 알려줍니다. 

 야생동물 등장 마크에 핑하면, ' 야생동물 리스폰까지 남은 시간 ' 시스템 채팅이 출력됩니다. 

 제작 가능한 장비를 핑하면, 해당 아이템을 제작 가능한 상태 라고 팀원들에게 시스템 채팅으로 알려주어 교전 시작을 자제하도록 권장할 수 있습니다. 

 인벤토리의 아이템을 핑할 때, 인벤토리에 보유한 같은 아이템의 수량 합계를 알려줍니다. (예: 쇠사슬 2개일 때 쇠사슬 하나를 핑하더라도 2개로 알려줌) 

 스킬에 핑을 사용할 때 효과음이 추가됩니다. 

 핑으로 인한 시스템 채팅의 컬러 코드가 개선됩니다. 

 
 게임 플레이 관련 옵션 서버 저장으로 변경 
 PC방을 비롯해 접속 환경이 바뀌더라도 게임 플레이에 필수적인 옵션들이 바뀌지 않도록 일부 옵션들을 서버 저장 방식으로 변경합니다. 
 입력 메뉴 (캐릭터 별 시전 방식, 스킬 키, 추가 단축키 등)

 방송 모드 메뉴 일부 (친구 요청 받지 않기 옵션만) 

 오퍼레이터 메뉴 

 
 체력바 위 실험체 이름 표시 옵션 
 실험체 이름에 익숙하지 않은 플레이어들을 위해, 체력바 위에 플레이어 이름 대신 실험체 이름으로 표시할 수 있는 옵션이 제공됩니다. 
 
 
 치명타 피해량 배율 증가 
 치명타율을 중심으로 한 빌드는 초반에는 지나치게 약하지만, 전설 장비를 갖추면서 매우 강력해지기 때문에 전설 장비를 몰아주는 플레이가 많이 나옵니다. 기본 치명타 피해를 늘려 주고, 전설 장비 위력을 약화시켜서 치명타 빌드의 파워 커브를 완화합니다. 
 기본 치명타 피해량 배율 160% → 165% 

 
 그 외 개선 사항 
 게임 시작 크레딧 지급 시점이 좀 더 빨라져서, 시작 루프 캡슐이 열리기 전에 전술 스킬을 레벨업 할 수 있게 됩니다. 

 이동 중 다른 실험체와 충돌 시 밀림 현상이 개선됩니다.

 버그 수정 및 개선 사항
 미스릴 200점 랭크 포인트 이상 현상 수정 안내 
 미스릴 티어 6200점을 기준으로 “강등”이 적용되는 문제가 발생했습니다. 
 원인: 글로벌 서버들의 이터니티 기준 자동 적용을 위한 로직이 적용 되는 과정에 문제가 발생했습니다. 

 현상: 6200점을 기준으로 한 차례 강등 방어가 발동하고, 한 번 더 마이너스 점수를 받으면 50점이 차감 

 점수 계산 공식은 강등을 적용하지 않도록 수정되어 업데이트 이후 정상 처리 됩니다. 

 단, 강등 연출은 추가 수정이 필요하여 다음 업데이트인 1.11 업데이트에 진행될 예정입니다. 즉, 점수는 정상 처리 되지만, 6200점 밑으로 떨어질 때 연출만 등장하게 됩니다. (잔존 버그) 

 점수 보전: 1.9 업데이트 기간 동안 6200점에서 강등을 경험한 모든 케이스에 대해, 강등 방어 및 50점 차감 적용을 되돌리고, 실제 받았어야 할 점수로 변경 적용 합니다. 이 변경은 정기 점검 시간 동안 진행될 예정입니다. 

 점수 보전으로 인해 점수가 오르는 경우도 있지만, 강등 방어를 많이 받은 경우 현 점수에서 차감되는 경우도 있습니다.

 랭크 결과 화면에서 다른 플레이어의 정보 보기 진입 후 시즌 목록 버튼 클릭 시 결과 화면으로 돌아오는 문제 수정 

 전략맵 선택 단계에서 우측에 위치한 팀원의 특성 및 전술 스킬 아이콘에 마우스 오버 시 툴팁이 화면을 벗어나는 문제 수정
