 패치노트 
 

 
 1개월 전 
 

 
 2026.08.20 - 12.2 패치노트

 
 
 12.2 업데이트는 8월 20일 목요일 오전 11시부터 오후 3시까지, 약 4시간의 정기 점검을 통해 적용됩니다. 
 
 신규 실험체 - 루치아
 저격총을 사용하는 새로운 실험체 루치아 가 루미아 섬에 등장합니다. 
 루치아 는 출시 후 2주일 간 A-coin 9,900개 에 판매되며, 8월 25일(화)까지 랭크 대전에서 선택할 수 없습니다. 
 
 “총사의 예로 여쭙지요. 소녀의 여정에 함께하시겠어요?” 
 
 
 
 
 영애의 소양 (P) 
 루치아가 적에게 스킬 적중 시 4 초간 수정 을 남깁니다. 루치아의 기본 공격은 수정 을 제거해 20/60/100(+스킬 증폭의 55%) 의 추가 스킬 피해를 입히고 루치아의 이동 속도가 0.75 초 동안 10/20/30% 증가합니다. 
 수정이 남은 적에게 기본 공격 시 공격 속도가 60% 증가합니다. 
 


 
 화려한 낭만 / 찬란한 낭만 (Q) 
 루치아가 지정한 방향으로 수정 탄환을 발사해 처음 적중한 적에게 70/105/140/175/210(+스킬 증폭의 75%) 의 스킬 피해를 입힙니다. 
 찬란한 낭만: 루치아가 지정한 방향으로 빛줄기를 발사해 범위 내 모든 적에게 80/115/150/185/220(+스킬 증폭의 80%) 의 스킬 피해를 입히고 이동 속도를 1초 동안 40%  감소시킵니다. 
 화려한 낭만 
 사거리: 7m 

 투사체 폭: 1.2m 

 투사체 속도: 20m/s 

 
 찬란한 낭만 피해 범위: 8m * 1.2m 

 쿨다운: 5/4.5/4/3.5/3초 

 


 
 일제 사격! (W) 
 루치아가 머스킷을 소환하여 근처 4 명의 적에게 사격을 가해 60/80/100/120/140(+스킬 증폭의 45%) 의 스킬 피해를 입힙니다. 
 이미 사격에 적중당한 적에게는  20% 의 피해를 입힙니다. 
 사거리: 6.3m 

 쿨다운: 8/7.5/7/6.5/6초 

 


 
 무엄하시네요! (E) 
 지속 효과 : 루치아가 수정 을 제거하면 무엄하시네요! 의 쿨다운이 15% 감소합니다. 
 루치아가 지정한 방향으로 이동합니다. 이후 4초 동안 찬란한 낭만 이 활성화되며 화려한 낭만  대신 사용할 수 있습니다. 
 이동 거리: 3m 

 이동 시간: 0.35초  

 쿨다운: 14/13/12/11/10초 

 


 
 총사의 예법 (R) 
 루치아가 지정한 방향으로 강력한 사격을 가하여 적에게 140/230/320(+스킬 증폭의 80%) 의 스킬 피해를 입힙니다. 
 수정 이 있는 적에게 적중 시 수정 을 제거하고 재부여하며 0.6초 동안 기절시킵니다. 
 피해 범위: 10m * 2m 

 쿨다운: 70/60/50초 

 


 
 신규 스킨 및 이모티콘
 키치 러브 가넷 (희귀)  스킨이 출시됩니다. 
 “우리의 사랑은 지독할 만큼 달콤할 거야.”   
 
 
 
 8월 25일(화) 모란 뒤의 그림자 쇼이치 (희귀)  스킨이 출시됩니다. 
 “하하, 정말이지 쉬는 법을 모르는 고용주들이로군요.” 
 
 
 
 루치아 좋은 승부였답니다, 알겠어요, 무엄하시네요!, 용서치 않겠어요!  이모티콘이 출시됩니다. 
 
 
 루치아 이모티콘 패키지 
 신규 루치아 이모티콘 4종을 할인된 가격으로 구매할 수 있는 기간 패키지가 출시됩니다. 
 판매 가격: 800NP → 480 NP 

 구성품: 루치아 이모티콘 4종, XP 부스트 (1일) 

 판매 기간: 8월 20일 (목) 점검 후 ~ 9월 3일 (목) 점검 전까지 

 ※ 기본 보유하고 있는 상품에 따라 구매 가격이 변경됩니다. ※ 구매 즉시 사용되는 부스트가 포함된 상품은 청약철회가 불가합니다. 
 
 시즌 12 프리미엄/베이직 토큰 북 안내 
 시즌 12 토큰 북은 미션을 통해 세일링 토큰을 획득할 수 있는 프리미엄/베이직 퀘스트 북으로 구성되어 있습니다. 
 판매 및 이용 기간 : 2026년 8월 20일 (목) 점검 후 ~ 2026년 10월 1일 (목) 점검 전까지 

 시즌 12 프리미엄 토큰 북 
 판매 가격: 1,500 NP 

 상세 구성: 15레벨 퀘스트 북, 세일링 토큰 최대 75개 획득 가능 

 
 시즌 12 베이직 토큰 북 
 판매 가격: 10,000 A-Coin 

 상세 구성: 10레벨 퀘스트 북, 세일링 토큰 최대 25개 획득 가능 

 
 ※ 상세 퀘스트 내용은 인게임 퀘스트 북 메뉴에서 확인하실 수 있습니다. ※ 미션을 완료했으나 보상을 수령하지 않은 경우, 점검 후 우편함으로 자동 지급되며 2주 이내 접속 시 수령 가능합니다. 
 
 시스템
 이스포츠 스케쥴러 
 로비에서 이터널 리턴 공식 대회 일정을 확인할 수 있는 이스포츠 스케쥴러 가 추가됩니다. 로비 상단 메뉴에서 진입할 수 있습니다. 
 대회 개요 탭에서 KEL, Masters 등 시즌 중 진행되는 대회 진행 방식을 확인할 수 있습니다. 

 대회 개요 탭 우측으로는 현재 가장 가까운 혹은 진행 중인 대회 일정이 노출됩니다. 

 대회 일정 탭에 진입 시, 대회 개요 탭 우측으로 노출되는 가장 가까운 혹은 진행 중인 대회가 보여집니다. 

 대회 일정 탭 내에선 마우스 스크롤을 통해 등록된 대회 일정 전반을 확인할 수 있습니다. 
 좌에서 우로, 날짜·시간순으로 정렬되며, 참가 팀과 순위를 확인할 수 있습니다. 

 
 진행 중인 대회는 각 방송 플랫폼 아이콘을 클릭해 바로 방송으로 이동할 수 있으며, 진행 예정 대회는 시작까지 남은 시간이 표시됩니다. 

 
 
 사용자 설정 대전 - 설정 코드 
 사용자 설정 대전의 게임 설정을 코드로 공유할 수 있는 설정 코드 기능이 추가됩니다. 매번 옵션을 하나씩 맞추지 않아도, 코드 입력만으로 동일한 설정을 즉시 적용할 수 있습니다. 
 게임 설정 화면의 [설정 코드] 버튼에서 코드를 생성하거나 입력할 수 있습니다. 

 게임 설정과 날씨 설정이 코드에 포함됩니다. 캐릭터 밴 설정은 포함되지 않습니다. 

 코드는 생성한 게임 모드(스쿼드/론울프/코발트 프로토콜)에서만 불러올 수 있습니다. 

 이후 업데이트로 옵션이 추가되거나 삭제되어도 이전 코드를 불러올 수 있으며, 누락된 옵션은 기본값으로 적용됩니다. 

 
 
 연습모드 개선 
 연습모드를 더 편하게 이용할 수 있도록 조작과 편의 기능이 개선됩니다. 
 
 기능 단축키 추가 
 매번 마우스로 버튼을 클릭하지 않아도 연습모드 기능을 사용할 수 있도록 고정 단축키가 추가됩니다. 

 각 기능 버튼에 마우스오버를 하면 단축키를 확인하실 수 있습니다. 

 
 ※ 연습모드 기능 단축키 변경은 별도로 지원하지 않습니다. 
 고정 단축키가 개인 설정한 다른 기능 단축키와 중복되는 경우, 두 입력을 모두 실행합니다.  
 
 커서 위치로 즉시 이동 
 Ctrl+Alt+우클릭으로 마우스 커서 지점에 즉시 이동할 수 있습니다. 

 이동할 수 없는 지형을 선택하면 가장 가까운 지점으로 이동합니다. 

 
 편의성 개선 
 훈련 메뉴의 연습모드/AI 대전 슬롯에서 마우스를 올렸을 때만 표시되던 모드 선택 버튼이 항상 표시되도록 변경됩니다. 

 다인 연습모드 대기실 입장 시 채팅 채널이 대기실 채널로 자동 선택됩니다. 

 '다인 연습모드 전체 채팅 사용' 옵션을 대기실에서 바로 켜고 끌 수 있습니다. 

 
 빌드업 재료 강조 표기 
 후반 아이템 제작에 필요한 빌드업 재료를 한눈에 알아볼 수 있도록 강조 표기 기능이 추가됩니다. 
 시작 아이템 완성에 필요한 개수를 초과해 필요한 여분의 재료를 파란색 라벨로 강조 표기합니다. 아래와 같은 아이템에 모두 적용됩니다.

 AI 상대 대전에서 AI 봇이 빈사 상태일 때 상황에 따라 분열 폭발 또는 자가제세동을 사용하고, 소생할 수 있는 아군이 가까이 있으면 자가제세동을 멈추고 소생을 기다리도록 개선 

 AI 상대 대전에서 AI 봇이 사망 시 부활 제한 시간을 모두 기다리지 않고, 부활이 가능해지는 즉시 팀 리더 근처에서 부활하도록 개선 

 핑 도배 제한 중 추가 핑 시도 시 안내 문구에 남은 제한 시간 표기 추가 

 인게임에 노출되던 토너먼트 마스터즈 배너 제거 

 임시 안전지대 외부에서 사망할 경우 실제 등수와 다르게 적용되는 문제 수정 

 금지 구역 복원 시 상대 팀이 보안콘솔을 점령해도 CCTV 시야가 유지되는 문제 수정 

 폭발 선인장 특성이 기본 공격 및 개별 스킬 피해 이외의 피해로도 발동되는 문제 수정 

 감시 카메라 스킨 착용 시 피격 판정과 피격 이펙트가 정상 적용되지 않는 문제 수정 

 게임 현황 UI에서 탈출 가능 시간 표기가 출력되지 않는 문제 수정 

 그래픽 옵션에 따라 크로노 스피어 범위가 명확하게 출력되지 않는 문제 수정 

 힐링 스프레이 이펙트가 선명하게 출력되지 않는 문제 수정 

 생명의 나무 내부 불빛이 강하게 출력되는 문제 수정 

 밤 시간대에 일부 건물 지붕의 빛 반사가 과도하게 출력되는 문제 수정 

 특정 상황에서 카메라 스킨이 적용되지 않는 문제 수정 

 플레어건 R 발동 효과음이 출력되지 않는 문제 수정 

 비 날씨에서 안내 로봇 LUMI의 우산이 선명하지 않게 출력되는 문제 수정 

 연습 모드에서 더미의 기능 설정 버튼이 카메라 이동에 따라 위치가 변경되는 문제 수정 

 리플레이 타임라인 이동 시 휴식 애니메이션이 비정상적으로 출력되는 문제 수정 

 튜토리얼 2장 부케팔로스 제작 미션 진행 중 하이퍼루프 위치에서 아이템 제작 시 다음 미션 진행이 불가능한 문제 수정 

 코발트 프로토콜 카트로즈 인퓨전 스킬 이펙트가 출력되지 않는 문제 수정 

 코발트 프로토콜 전술 스킬 힘껏펀치에 에어본 상태가 적용되지 않는 문제 수정 

 코발트 프로토콜 상단 지역 자율 방어 터렛의 기본 방향이 위쪽으로 향하고 있는 문제 수정 

 
 실험체 및 무기 개선 사항 
 일부 무기 스킬 미리보기 영상이 실제 스킬 효과와 일치하지 않는 문제 수정 

 투척 무기 스킬 연막(D) 피아식별 이펙트 지속시간이 짧게 적용되는 문제 수정 

 일부 실험체 설치물이 벽 뒤에 위치 시 실루엣이 출력되지 않는 문제 수정 

 가넷 빈사 시 보이스가 중복 출력되는 문제 수정 

 다니엘 걸작(R) 스킬 이펙트가 전장의 안개에서 노출되는 문제 수정 

 레니 로비 애니메이션에서 일부 이펙트가 어색한 위치에 출력되는 문제 수정 

 잭 오 리 다이린 스킨 착용 중 춤 감정 표현 사용 시 이펙트가 잘못 출력되는 문제 수정 

 낮은 빈도로 비앙카 순환(E) 이펙트가 차징 완료 상태로 출력되는 문제 수정 

 영겁의 푸른 망령 비앙카 스킨 착용 중 빈사 및 사망 상태일 때 관에 투명 처리가 적용되지 않는 문제 수정 

 비앙카 일부 스킨 착용 중 사망 상태 진입 시 관 애니메이션이 잘못 출력되는 문제 수정 

 프리즌 키퍼 비앙카 스킨 착용 중 특정 상황에서 진조의 군림(R) 스킬 이펙트가 잘못 출력되는 문제 수정 

 아르다 샤마쉬의 법전(RQ) 적중 시 고대의 정수 생성 위치가 잘못된 문제 수정 

 특정 상황에서 요한 기본 공격 시 랜턴 이펙트 위치가 어긋나는 문제 수정 

 유민 기본 스킨 승리 연출에서 망토와 구름이 겹쳐서 출력되는 문제 수정 

 사관후보생 일레븐 스킨 착용 중 힘내자고!(P) 일레븐 버거가 전장의 안개에서 노출되는 문제 수정 

 캐시 동맥절제술(Q) 쿨다운 감소량이 외과 전문의(P) 스킬 레벨을 기준으로 적용되는 문제 수정 

 코렐라인 로비 애니메이션 중 사운드 위치가 잘못 설정된 문제 수정 

 키아라 낙인(P) 최대 중첩 이펙트가 잘못 출력되는 문제 수정 

 타지아 등 뒤에 유리 칼날 개수가 갱신되지 않는 문제 수정 

 노블 에이스 바니 헤이즈 스킨 착용 중 엑셀러레이션 로켓(RQ) 스킬 사용 시 이펙트가 잘못 출력되는 문제 수정 

 헤이즈 엑셀러레이션 로켓(RQ) 스킬 사용 시 이펙트가 잘못 출력되는 문제 수정
