 패치노트 
 

 
 2년 전 
 

 
 2024.07.18 - 1.26 패치노트

 
 
 1.26 업데이트는 7월 18일 목요일 오전 11시부터 오후 4시까지, 약 5시간의 정기 점검을 통해 적용됩니다. 
 
 신규 실험체 - 르노어
 기타를 사용하는 새로운 실험체 르노어 가 루미아 섬에 등장합니다. 
 르노어 는 출시 후 2주일 간 A-Coin 9,900개 에 판매되며, 7월 23일(화)까지 랭크 대전에서 선택할 수 없습니다. 
 “네 선율을... 들려주겠니?“   
 
 
 
 고통의 선율 (P) 
 지속 효과: 르노어는 쿨다운 감소 스탯과 비명 중첩이 아첼레란도 수치로 치환되며, 아첼레란도 수치에 따라 별도의 쿨다운 감소가 적용됩니다. 고통의 선율: 체력이 50% 보다 낮은 실험체에게 스킬로 피해를 입히면 10/30/50(+스킬 증폭의 20%)(+비명 중첩당 피해량 2) 의 스킬 피해를 추가로 입히고 비명 중첩을 얻습니다. 동일한 적 실험체에게는 12/10/8초 마다 효과가 적용됩니다. 트릴: 르노어가 세 번째 기본 스킬을 사용할 때마다 해당 스킬이 강화됩니다. 
 쿨다운 감소 스탯 1% 당 1 , 비명 중첩 1당 1.5 의  아첼레란도  수치로 치환됩니다. 아첼레란도 수치 70 이상부터는 비명 중첩이 아첼레란도 수치로 치환되지 않습니다. 
 


 
 스타카토 (Q) 
 르노어가 5 번의 연주로 파동을 발사해 처음으로 맞힌 적 주변에 개당 60/82/104/126/148(+스킬 증폭의 60%) 의 스킬 피해를 입힙니다. 강화 효과: 피해량이 50%  증가합니다. 
 동일한 적에게 연속적으로 파동을 맞힐 경우 피해량이 50% 감소합니다. 
 투사체 사거리: 8.3m 

 투사체 충돌 범위: 반경 0.75m 

 투사체 속도: 22m/s 

 적중 시 피해 범위: 반경 0.75m 

 쿨다운: 7/6.5/6/5.5/5초 

 스태미나 소모량: 40/50/60/70/80 

 


 
 피네 (W) 
 르노어가 2.5 초 동안 50/65/80/95/110(+스킬 증폭의 35%) 의 피해를 흡수하는 보호막을 얻으며 주변의 적들에게 80/110/140/170/200(+스킬 증폭의 55%) 의 스킬 피해를 입히고 0.27 초 동안 속박합니다. 강화 효과:  보호막량이 30%  증가하고 2 초 동안 르노어의 이동 속도가 20%  증가합니다. 
 이 스킬의 속박은 대상의 이동을 중단 시킵니다. 
 범위: 반경 4m 

 쿨다운: 15/14.5/14/13.5/13초 

 스태미나 소모량: 50/60/70/80/90 

 


 
 달 세뇨 (E) 
 르노어가 범위의 적에게 70/110/150/190/230(+스킬 증폭의 65%) 의 스킬 피해를 입히고, 적을 중앙으로 끌어당깁니다. 강화 효과: 1.25 초 동안 중앙으로 끌어당겨진 적의 이동속도가 60%  감소합니다. 감소된 이동 속도는 지속 시간에 걸쳐 회복됩니다. 
 사거리: 7m 

 범위: 2.3m * 6m 

 쿨다운: 17/16/15/14/13초 

 스태미나 소모량: 50/60/70/80/90 

 


 
 고뇌의 광시곡 (R) 
 르노어가 환상적인 연주를 하며 적중한 적에게 3 초 동안 남는 파동을 날립니다. 적중한 파동은 크기가 점점 커지면서 범위 내의 모든 적에게 0.25 초 마다 10/15/20(+스킬 증폭의 3%) 의 스킬 피해를 입히고, 이동 속도 4%  감소를 중첩 시킵니다. (최대 12 중첩) 지속 시간이 끝나면 범위 내의 모든 적에게 150/225/300(+스킬 증폭의 70%) 의 스킬 피해를 입히고, 1.3/1.4/1.5 초 동안 정신 이상 상태에 빠트려 근처 대상을 기본 공격 하도록 합니다. 
 정신 이상 상태에 빠진 적은 조작을 할 수 없는 상태에 빠지며 공격 속도가 200% 증가하고, 자신의 아군을 우선적으로 공격합니다. 
 투사체 사거리: 12m 

 투사체 충돌 범위:  반경 0.8m 

 투사체 속도: 11m/s 

 파동 범위: 원형 2m ~ 4m 

 쿨다운:  80/70/60초 

 스태미나 소모량: 100/125/150

 에이든  뇌격(Q) 사용 직후 다른 방향의 적에게 기본 공격 시 뇌격(Q) 이펙트 위치가 어색하게 출력되는 문제 수정 

 에키온  과부화 상태에서 사망 후 부활 시 VF의수 이펙트가 출력되지 않는 문제 수정 

 중국어 간체 및 번체 환경에서 일레븐  자~집중!(W) 레벨업 툴팁에 일부 항목이 영어로 출력되는 문제 수정 

 특정 상황에서 칼라  회수(W) 스킬이 발동되지 않은 상태에서 쿨다운이 적용되는 문제 수정 

 칼라  관통 작살(Q) 사용 직후 회수(W) 사용 시 작살 위치가 비정상적으로 출력되는 문제 수정 

 특정 상황에 클로에  기본 공격 사거리 표시가 니나 기준으로 출력되는 문제 수정 

 헤이즈 로 터미네이트/ 클러치 달성 시 대사가 출력되지 않는 문제 수정 

 
 로비 개선 사항 
 실험체 중계 어나운스 상품의 경우 실험체 아이콘으로 표시 

 게임 준비 단계에서 루트에 설정된 전술 스킬 변경 후 특성 변경 시 루트에 설정된 전술 스킬로 변경되는 문제 수정 

 프로필, 이모티콘, 제작소 등 아이템 수량이 많아 지연이 발생하는 메뉴 진입 시 로딩 인디케이터 표시 

 신규 유저에게 출석부를 시즌 탭 보다 먼저 보여주도록 변경 

 계정 레벨업에 따른 경험치 및 기타 보상 일부 조정 

 랭크 티어 정보 화면에서 이전 시즌 확인 시 랭크 포인트와 게이지가 일치하지 않는 문제 수정 

 귓속말 탭에 알림과 닫기 버튼이 동시에 출력되는 문제 수정 

 전략 > 루트 페이지에서 가져온 루트 상세 보기 시 첫 번째 확인한 루트의 전술 스킬이 활성화 상태로 표시되는 문제 수정 

 설정된 해상도 및 화면 비율에 따라 마우스 오버 시 출력되는 툴팁의 표시 위치 기준이 다른 문제 수정 

 맵 색상 커스텀에 일부 옵션 명칭이 기능과 다르게 출력되는 문제 수정 

 로비 스크린에 우클릭 시 랜덤 재생 제외 체크가 로비 스크린 아이템 정보 팝업과 겹치는 문제 수정 

 사용자 설정 대전에서 프로필 아이콘이 실험체 이미지로 출력되는 문제 수정 

 게임 결과 화면에서 일부 실험체 이름이 한글로 출력되는 문제 수정 

 EP가 변경 된 ER 패스 최대 레벨에 맞게 지급 되도록 변경 

 NP가 음수일 때 ER 패스 활성화가 안되는 문제 수정
