 [수정] 2025.07.24 - 8.2 패치노트

 
 
 8.2 업데이트는 7월 24일 목요일 오전 11시부터 오후 3시까지, 약 4시간의 정기 점검을 통해 적용됩니다. 
 
 신규 실험체 - 슈린
 레이피어를 사용하는 새로운 실험체 슈린 이 루미아 섬에 등장합니다. 
 슈린 은 출시 후 2주일 간 A-coin 9,900개 에 판매되며, 7월 29일(화)까지 랭크 대전에서 선택할 수 없습니다. 
 
 “이 검으로, 길을 열어드리죠.“   
 
 
 역할군: 전사 / 암살자 
 
 
 결심응진 (P) 
 슈린의 기본 공격 및 기본 스킬 적중 시, [유운잔영검] 중첩을 획득합니다. 3 중첩 시 다음 기본 공격이 강화되어, 대상에게 어검을 날려 20/40/60(+공격력의 30/40/50%) 의 추가 스킬 피해를 입히고, [비검잔위] 와 [비섬보] 의 쿨다운이 2초 감소하며 20/40/60(+공격력의 50%) 의 체력을 회복합니다. 야생동물 상대로는 회복 효과가 60% 로 감소합니다. 
 


 
 비검잔위 (Q) 
 슈린이 어검을 날려 경로 상의 적에게 60/70/80/90/100(+공격력의 60%) 의 스킬 피해를 입힙니다. 지정 위치에 도착하면 2초 동안 회전하며, 범위 내 적에게 0.4초 마다 40/50/60/70/80(+공격력의 40%) 의 스킬 피해를 입힙니다. 회전하는 어검에 닿으면 어검을 회수하면서 [비섬보] 의 쿨다운을 70% 돌려받습니다. 회수한 어검은 2.5초 동안 슈린 주변을 회전하며 범위 내 적에게 0.5초 마다 30/35/40/45/50(+공격력의 35%) 의 스킬 피해를 입힙니다. 
 어검 투척 사거리:  3.5m ~ 5.5m 

 어검 범위: 원형 반경 1.65m 

 회전 공격 범위:  원형 반경 2.65m 

 쿨다운:  12/11/10/9/8초 

 스태미나 소모량: 10/20/30/40/50 

 


 
 무진검결 (W) 
 슈린이 어검으로 자신을 감싸 0.75초 동안 모든 방해 면역 상태가 되며 받는 모든 피해를 막아냅니다. 이후 지정한 방향으로 어검을 날려 처음 적중한 적 실험체에게 50/70/90/110/130(+공격력의 90%) 의 스킬 피해를 입히고 1초 동안 이동 속도를 50% 감소시킵니다. 이동 불가 효과를 막아냈을 경우, [유운잔영검] 3 중첩을 획득하며 100/130/160/190/220(+공격력의 100%) 의 스킬 피해를 입히고 이동 속도 감소 대신 1초 동안 기절시킵니다. 
 실험체를 제외한 대상은 관통합니다. 
 공격 범위: 사다리꼴 밑변 3m * 윗변 0.8m * 길이 6m 

 쿨다운: 20/18.5/17/16.5/15초 

 스태미나 소모량: 20/30/40/50/60 

 


 
 비섬보 (E) 
 슈린이 지정한 방향으로 돌진하며 경로 상 적에게 60/70/80/90/100(+공격력의 55%) 의 스킬 피해를 입히고 1초 동안 이동 속도를 30% 감소시킵니다. 이후, 돌진했던 경로를 따라 어검이 떨어지며 범위 내 적에게 60/90/120/150/180(+공격력의 70%) 의 스킬 피해를 입힙니다. 
 돌진 거리: 4m 

 돌진 범위(폭): 1.2m 

 돌진 시간: 0.3초 

 어검 낙하 범위: 4.2m * 2m 

 쿨다운: 14/13.5/13/12.5/12초 

 스태미나 소모량: 10/20/30/40/50 

 


 
 만검귀종 (R) 
 슈린이 영역을 펼치며 100/175/250(+공격력의 70%) 의 스킬 피해를 입힙니다. 영역은 7초 동안 유지됩니다. 영역 내에 위치한 적에게 슈린이 개별 피해를 입힐 때마다, 대상에게 어검이 떨어져 10/20/30(+공격력의 10/15/20%) 의 추가 스킬 피해를 입힙니다. 5번째 로 떨어지는 어검은 강화되어 대상에게 떨어져 주변에 20/40/60(+공격력의 15/25/35%) 의 추가 스킬 피해를 입히며 0.5초 동안 이동 속도를 30% 감소시킵니다. 
 [비섬보] 를 사용한 후, 도착 지점이 영역 밖일 경우 외곽의 어검이 슈린에게 돌아오며 경로 상 적들에게 100/200/300(+공격력의 85%)의 스킬 피해를 입히고, 두 번째 적중부터는 피해량이 80% 감소됩니다. 
 [비섬보]의 도착 위치가 영역과 20m 이내인 경우에만 어검이 회수됩니다. 
 영역 범위:  원형 반경 5m 

 쿨다운: 80/70/60초 

 스태미나 소모량: 140

 시스템
 스킬 일반 시전 별도 단축키 설정 기능 추가 
 주로 스킬 즉시 시전(퀵 캐스트)을 사용하지만 특정 상황에만 일반 시전을 사용하고 싶은 경우, 이제 일반 시전 단축키를 등록해 사용할 수 있습니다. 
 ‘일반 시전’ 단축키 가 추가됩니다. 이 단축키는 즉시 시전 설정을 켠 상태에서도 반드시 일반 시전으로만 사용됩니다. 
 단축키 기본값은 할당되어 있지 않습니다. 

 사용을 원하시는 경우, [설정 → 입력] 탭에서 직접 할당해서 사용 가능합니다. 

 
 
 
 수직 발사 장치(VLS) 확장맵(M) 자동 활성화 기능 
 VLS를 사용할 때, 이동 가능 지점을 한 눈에 보고 싶다는 피드백에 따라, 맵을 자동 활성화하는 기능이 추가됩니다. 
 VLS 사용을 시작하면 확장맵(M)이 자동으로 활성화됩니다. 

 VLS 발사 후에도 맵이 유지되며, 단축키(M)를 이용해 맵을 다시 끌 수 있습니다. 

 
 이 기능은 옵션으로 제공되며, 디폴트 켜짐 상태입니다. 
 [설정 → 게임] 에서 해당 기능의 On / Off를 체크할 수 있습니다. 
 
 ​ 게임 현황(Tab) 내 위클라인 박사 버프 표시 
 이제 게임 현황(Tab)을 통해, 위클라인 박사를 처치한 팀을 직관적으로 알아볼 수 있게 됩니다. 
 위클라인 박사를 처치한 팀 은 버프가 지속되는 동안 게임 현황(Tab)의 스코어보드에서 특별한 강조 효과가 표시 됩니다. 

 
 
 그 외 관전 UI 개선 
 그 외에도 관전 UI 에서 플레이어 상황을 한 눈에 알아볼 수 있도록 새로운 기능들이 추가됩니다. 
 위클라인 박사 버프 표시 
 관전 UI에도 위의 위클라인 박사 버프가 강조 표시 됩니다.

 보안 콘솔 및 CCTV 점거 정보 표시 
 이제, 관전 상태에서 Alt 키를 눌러 정보 오버레이를 확인하면, 각 보안 콘솔을 점거한 팀의 이름과 고유 색상을 확인할 수 있습니다. 

 관전 상태에서 CCTV의 범위는 점거한 팀의 색상으로 표시됩니다. (단축키 F11) 

 
 
   
 플레이어 주요 행동 아이콘 표시 
 관전 상태에서 플레이어 목록에 각 플레이어의 현재 행동을 나타내는 아이콘이 새롭게 표시됩니다. 

 플레어건 및 VLS 사용, 균열, 연구실 입장, 루미와 상호 작용 및 교전이 아이콘으로 표시되어, 각 플레이어의 현재 상황을 빠르게 파악할 수 있습니다.

 MMR 고정 처리 
 일반 대전에서 지나치게 높은 티어의 플레이어와 매칭되는 문제를 개선하고자, 정규 시즌 달성 티어에 따라 MMR이 일정 구간 이하로 감소하지 않게끔 개선됩니다. 
 MMR 고정 처리는 일반 대전과 코발트 프로토콜 모드에 적용됩니다. 
 
 게임 플레이 개선
 균열 - 차원의 틈 개선 
 2일차 균열 - 차원의 틈에 입장하여 교전할 때, 금지구역 폭발 타이머 소모가 장기적으로 큰 부담이 되는 편입니다. 폭발 타이머를 복구해 줘서 2일차 입장 부담을 완화합니다. 
 전투 연구실에서 전투가 끝나면, 전투 승패와 무관하게 폭발 타이머 가 20초 보다 낮은 경우 20초로 복구 

 
 또한, 차원의 틈 입구에 키오스크를 추가하여, 시작 전에 크레딧을 소진하고 균열 전투를 준비할 수 있도록 합니다. 
 각 팀의 전투 연구실 대기실에 키오스크 가 추가됩니다.

 추천 전술 스킬이 상단에 배치됩니다. 

 메테오 등 일부 강력한 전술 스킬은 팀 재고(1개) 가 적용됩니다. 
 팀 재고 전술 스킬은 팀원 중 랜덤으로 1명에게 등장합니다.

 게임 준비 단계 상대 팀 닉네임 표시

 이제 상대 팀 플레이어가 ‘닉네임 숨기기’ 옵션을 사용하지 않은 경우, 게임 준비 단계에서 해당 플레이어의 닉네임을 확인할 수 있습니다. 

 ‘닉네임 숨기기’ 옵션을 사용한 플레이어는 기존과 같이 “실험체N”으로 표시됩니다.
