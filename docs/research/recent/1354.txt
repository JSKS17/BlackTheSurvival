 패치노트 
 

 
 3년 전 
 

 
 2023.08.17 - 1.2 패치노트

 
 
 1.2 업데이트는 8월 17일 목요일 오전 11시부터 오후 3시까지, 약 4시간의 정기 점검을 통해 적용됩니다. 
 
 신규 실험체 - 아르다
 아르카나를 사용하는 새로운 실험체 아르다 가 루미아 섬에 등장합니다. 
 아르다는 출시 후 2주일 간 A-coin 9,900개 에 판매되며, 8월 22일(화)까지 랭크 대전에서 선택할 수 없습니다. 
 “그럼 조사를 시작하지.“  
 
 
 
 유물 탐구 (P) 
 발굴 통제 : 아르다가 생명의 나무나 운석 채집을 시작하면 자신의 주변에 영역 위의 적을 침묵시키는 영역을 생성합니다. 이 영역은 채집이 진행되는 동안 지속됩니다. 
 고고학적 분석 : 아르다가 사용하는 유물이 적에게 피해를 입히면 아르다는 고대의 정수 를 얻습니다. 고대의 정수 가 5/4/3 회 중첩되면 랜턴이 신비로운 힘을 방출하여 아르다와 주변의 아군의 체력을 50/100/150(+스킬 증폭의 20%) 회복시킵니다. 
   


 
 샤마쉬의 두루마리 (Q) 
 지정한 방향으로 샤마쉬의 두루마리를 전개합니다. 샤마쉬의 두루마리에 충돌한 적은 50/90/130/170/210(+스킬 증폭의 70%) 의 스킬 피해를 입습니다. 
 범위:  7.5m * 1.4m 

 투사체 속도: 12m/s 

 쿨다운: 7/6.5/6/5.5/5초 

 스태미나 소모량: 50/55/60/65/70 

 


 
 바빌론의 입방체 (W) 
 지정한 지점에 바빌론의 입방체를 소환합니다. 바빌론의 입방체는 영역 내의 적에게 10/30/50/70/90(+스킬 증폭의 20%) 의 스킬 피해를 입히고 0.3초 동안 이동 속도를 50% 느리게 합니다. 1초 뒤 바빌론의 입방체는 사라지며 주변 영역에 50/80/110/140/170(+스킬 증폭의 60%) 의 스킬 피해를 입히고 1초 동안 기절시킵니다. 
 사거리: 6m 

 범위: 정사각형 4m * 4m 

 쿨다운: 1 4/13/12/11/10초 

 스태미나 소모량: 90/100/110/120/130 

 


 
 님루드의 비석 (E) 
 지정한 위치에 님루드의 비석을 떨어뜨려, 범위 내의 적에게 40/70/100/130/160(+스킬 증폭의 30%) 의 스킬 피해를 입히고 밀어냅니다. 
 사거리: 8m 

 범위:  원형 반경 2m 

 쿨다운: 16/15/14/13/12초 

 스태미나 소모량: 80 

 


 
 잠들어있는 힘 (R) 
 아르다가 유물에 잠들어 있는 기원을 해독해 원래의 능력을 복원합니다. 12 초 동안 다음으로 사용하는 일반 스킬을 강화합니다. 
 쿨다운: 30/24/18초 

 스태미나 소모량: 160/120/80 

 

 
 샤마쉬의 법전 (R-Q) 
 지정한 방향으로 샤마쉬의 법전을 전개합니다. 샤마쉬의 법전은 충돌한 적에게 50/90/130/170/210(+스킬 증폭의 70%) 의 스킬 피해를 입히고 주문 영역을 남겨, 0.5초 후 지나간 경로의 적에게 160/240/320(+스킬 증폭의 80%) 의 스킬 피해를 입힙니다. 
 잠들어있는 힘 의 쿨다운의 30%를 돌려받습니다. 
 범위:  7.5m * 3.2m 

 투사체 속도: 12m/s 

 


 
 바빌론의 주사위 (R-W) 
 지정한 지점에 바빌론의 주사위를 소환합니다. 주사위는 경계선에 장벽을 펼치고, 닿는 적을 0.8/1/1.2초 동안 속박합니다. 장벽은 시계 방향 순서대로 파괴되면서 적에게 100/140/180(+스킬 증폭의 40%) 의 스킬 피해를 입히고, 주사위 영역 내의 적에게는 10/30/50/70/90(+스킬 증폭의 20%) 의 스킬 피해를 입히고 이동 속도를 0.3초 동안 50% 느리게 합니다. 모든 장벽이 파괴되면 바빌론의 주사위는 사라지며 영역 내의 적에게 50/80/110/140/170(+스킬 증폭의 60%) 의 스킬 피해를 입히고 1초 동안 기절시킵니다. 
 


 
 님루드의 문 (R-E) 
 사용 거리가 4/5/6m 증가하며 지정한 위치와 자신의 위치에 님루드의 비석을 떨어뜨려, 적에게 40/70/100/130/160(+스킬 증폭의 30%) 의 스킬 피해를 입힙니다. 이후, 두 비석은 신비로운 힘으로 연결되어 아군이 1회  이동할 수 있는 차원문이 8초 동안 유지됩니다.

 주요 패치 의도
 실험체 관련 조정은 통계에 주로 기반합니다. 다만 앞서 해보기 때와는 달라지는 부분들이 많아서 전체적인 통계 체계를 재조정 중 입니다. 
 앞서 해보기 때는 TOP1000을 기준으로 두었습니다. 하지만 조합에 따른 변수가 늘면서 상위권 통계 기준 범위를 1000등 보다 더 늘리고, 통계 수집 기간도 늘리고자 합니다. 짧은 기간 통계에 의존하는 핫픽스는 치명적인 수준일때에 진행될 수 있습니다. 

 랭크 대전의 하위권 비중이 매우 커지면서, 하위권에서 지나치게 강력할 경우 에도 패치에 반영하도록 합니다. 

 랭크 점수 체계의 변화로 평균 랭크 점수 획득량 이 약간의 보정치만 제거하면 킬과 순위를 직접 반영하게 되어, 이전과 달리 통계의 기준 중 하나가 될 수 있습니다. 

 포지션에 대한 고려 가 필요해졌습니다. 예를 들어 특정 포지션의 강력한 실험체를 하향하더라도, 해당 포지션의 대안이 없다면 지표가 잘 변화하지 않는 경우도 있었습니다. 다만 사전에 포지션을 지정하는 게임이 아니기 때문에, 포지션 조합은 통계적으로 완전히 관리되긴 어렵고, 너무 극단적인 형태가 되지 않는 선에서 다양한 포지션이 공존하는 것을 목표로 합니다. 

 승률이나 랭크 점수 획득량은 비교적 보편적인 기준이지만, 평균 킬이나 주는 피해량, 받는 피해량과 같은 세부 지표는 포지션에 따라 차이가 큰 편 입니다. 이런 지표들은 포지션 내 비교에 중점을 두고 있습니다. 

 통계 기준 체계는 시즌 중에 공지될 예정입니다. 

 
 정규 시즌 시작 후 첫 업데이트의 핵심 목표는 다양한 실험체의 출현 입니다. 
 정식 오픈 이후 상위권과 하위권 모두에서 잘 채택되지 않는 실험체가 게임에 등장하는 비율을 늘리고자 합니다. 

 지난 1.1 업데이트에서 29개의 실험체가 순수 상향되었고, 그 중 루크, 바냐, 헤이즈, 현우 등 눈에 띄게 플레이어가 늘어난 사례가 일부 있었지만, 랭크 시즌이 시작되면서 게임 플레이가 고도화 됨에 따라 잘 등장하지 못하는 실험체가 여전히 많이 있습니다. 

 1.2 업데이트에서는 더 많은 실험체가 순수 상향되며, 상향 폭도 조금 더 큰 경우가 많습니다. 

 통계적으로 지나치게 강력한 모습을 보이는 실험체를 하향하고, 상하위권 어디에서도 잘 활용되지 못하는 실험체를 상향하는 게 전체적인 목표입니다. 다만, 현재는 후자의 케이스가 많아서 상향 범위가 훨씬 많습니다. 

 여러 무기를 가진 실험체의 사용 빈도가 낮은 무기에 대해서도 보완하고자 합니다. 하지만, 하나의 무기가 잘 활용되고 있다면 다른 무기를 숙련도 효과로만 해결하기에는 한계가 있으므로, 스킬 개선을 비롯해 보다 점진적인 대응을 고려하고자 합니다.

 루트 제작 시 아이템 도감 필터 목록이 펼쳐지더라도 화살표 버튼 방향이 전환되지 않는 문제 수정 

 루트 제작 시 이동 속도가 1일 때 소수점 이하 단위로 출력되는 문제 수정 

 AI 대전 전략맵 선택 단계 2페이즈에 AI 팀원의 실험체가 표시되지 않는 문제 수정 

 화면 비율에 따라 영웅 등급 스킨 획득 연출의 대사 위치가 달라지는 문제 수정 

 특정 상황에서 매칭 대기 인원이 24명을 초과하여 표시되는 문제 수정 

 전략 > 특성 탭에서 특성 제작 중 이름이 비어있을 때 커서가 노출되지 않는 문제 수정 

 제작소 > 제작소 탭의 분해 아이템 일괄 추가 팝업 바깥이 블러 처리되지 않는 문제 수정 

 제작소 > 상자 개봉 후 실험체 및 스킨 획득 연출이 출력되기 전에 잠깐 동안 실루엣과 상품 이름이 출력되는 문제 수정 

 제작소 > 박스 탭의 보상 목록 검색 시 일부 실험체 이름으로 검색할 수 없는 문제 수정 

 제작소 > 박스 탭의 보상 목록 검색 후 팝업을 닫고 다시 열었을 시 UI가 겹치는 문제 수정 

 제작소 내 일부 텍스트가 언어 환경을 변경하더라도 내용이 바로 갱신되지 않는 문제 수정 

 일부 언어 환경에서 제작소 > 제작소 탭의 버튼 텍스트가 잘못 출력되는 문제 수정 

 상점 > 추가 상품 > EP 토큰 탭의 바캉스 토큰 상품명에 수량이 출력되지 않는 문제 수정 

 상점 > 추가 상품 하위 탭의 일부 이름이 잘못 출력되는 문제 수정 

 상점 > DLC 및 드롭스 아이콘에 마우스 오버를 하더라도 하이라이트 연출이 출력되지 않는 문제 수정 

 후반 아이템 리스트의 전체 아이템 전환 버튼의 선택 범위가 작게 설정되어 있는 문제 수정 

 언어 환경에 관계없이 선호 실험체 등록 텍스트가 한국어로 출력되는 문제 수정 

 보관함 > 캐릭터 탭에서 보유하지 않은 일부 실험체에 어두운 배경이 출력되는 문제 수정 

 보관함 > 캐릭터 > 스킨 탭에서 스킨을 반복하여 선택 시 일부 실험체의 모델링이 정상 출력되지 않는 문제 수정 

 보관함 > 기타 하위 탭에서 상품 선택 후 저장 시 선택하지 않았던 상품에 선택 하이라이트가 출력되는 문제 수정 

 보관함 > 기타 하위 탭의 일부 상품에 마우스 오버시 툴팁 내용이 UI 밖으로 벗어나는 문제 수정 

 설정 > 사운드 탭에서 비활성화된 사운드 게이지에도 그라데이션이 적용되는 문제 수정 

 설정 > 오퍼레이터의 일부 체크 버튼 색상이 잘못 출력되는 문제 수정 

 프로필 > 프로필 설정 탭의 미보유 상품이 활성화 상태로 표시되는 문제 수정 

 낮은 빈도로 결과 화면에서 무기 스킬 아이콘이 잘못 출력되는 문제 수정 

 언어 설정을 변경하더라도 옵션 팝업 내 일부 항목의 언어 표시가 갱신되지 않는 문제 수정 

 아이콘, 테두리, 배경 상품 획득 시 상품 획득 알림이 출력되지 않는 문제 수정 

 특정 상황에서 스킨 미리보기 진입 시 UI가 정상 출력되지 않는 문제 수정 

 프로필 아이콘이 UI 바깥으로 벗어나는 문제 수정 

 해상도에 따라 결과 화면의 채팅창 및 폰트 크기가 달라지는 문제 수정 

 특정 상황에서 로비 채팅창의 스크롤이 최상단으로 초기화되는 문제 수정 

 일부 화면 비율에서 설정 팝업 바깥의 일부 영역이 블러 처리되지 않는 문제 수정 

 데일리 박스 구매 시 수량 선택 게이지가 최솟값으로 설정된 문제 수정 

 낮은 빈도로 사용자 설정 대전 입장 후 채팅 시도 시 오류 팝업이 출력되는 문제 수정 

 오퍼레이터 시스템 프리셋 변경 버튼 선택 시 설정 팝업의 오퍼레이터 탭이 아닌 화면 탭이 선택되는 문제 수정 

 전술 스킬 아이콘의 상단 테두리 일부가 표시되지 않는 문제 수정
