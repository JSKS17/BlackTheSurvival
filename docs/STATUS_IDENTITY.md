# 원본 상태이상의 턴제 변환

상태의 이름과 적용 기술은 저장된 원본 기술 설명과 개별 실험체의 공식 자료를 대조한다. `StatusIdentity.cs`가 카드별 상태·스택 조건·발동 시점을 정의하고 `StatusMechanics.cs`가 양측의 같은 행동 규칙을 적용한다. 카드 상세 설명에는 조건과 지속 기간을, 필드 상세에는 실제 남은 기간과 행동 제한을 표시한다. 원본 상태 20종이 지정된 카드는 207종이다.

원본은 [초기 실험체 자료](ROSTER_CLASSIC.md), [최근 실험체 자료](ROSTER_RECENT.md), 기존에 보관한 [원본 기술 설명](art-chibi/skill-references/original-skills.json)과 [카드별 참고 기술](art-chibi/reference-skills.json)을 사용한다. 원본의 초 단위 지속 시간과 위치·범위 판정은 이 팬 게임의 단일 적 턴제 규칙에 맞게 변환했다.

| 상태 | 게임에서의 동작 |
|---|---|
| 기절·에어본·넉백 | 다음 자신의 턴에 사용할 코스트가 1 감소한다. |
| 제압·정지 | 다음 자신의 턴에 사용할 코스트가 2 감소한다. |
| 빙결 | 코스트가 2 감소하며 실제 체력 피해를 받으면 해제된다. |
| 수면 | 코스트가 1 감소하며 실제 체력 피해를 받으면 해제된다. |
| 속박 | 이동·돌진·순간 이동을 포함한 카드를 사용할 수 없다. |
| 침묵 | 실험체 Q/W/E/R을 사용할 수 없다. 기본·무기·전술 카드로 대응한다. |
| 무장 해제 | 기본 공격을 사용할 수 없다. |
| 실명 | 공격 명중률이 25% 감소한다. 각 적중마다 대상의 회피와 합산해 판정한다. |
| 둔화·끌어당김 | 이동 카드의 코스트가 1 증가한다. 둘이 동시에 있어도 증가량은 1이다. |
| 공포·매혹 | 공격 피해가 20% 감소한다. |
| 도발·광란 | 실험체 기술 사용이 제한되고 기본·무기·전술 카드로 대응한다. |
| 변이·춤 | 실험체 기술과 기본 공격을 사용할 수 없다. 경계·무기·전술 카드는 사용할 수 있다. |
| 치유 감소 | 회복량이 20% 감소한다. 패시브·룬의 치유 감소와 가장 큰 값만 적용한다. |
| 방어력 감소 | 받는 공격 피해가 10% 증가한다. |
| 공격력 감소 | 공격 피해가 20% 감소한다. 공포·매혹과 중첩되지 않는다. |

하드 제어는 가장 큰 코스트 감소량 하나만 적용하고 최소 1코스트를 남긴다. 현재 기술의 상태는 기본 1턴이며 같은 상태를 다시 부여하면 수치와 기간의 큰 값만 유지한다. 기간은 **영향을 받는 쪽의 턴 종료**에 감소한다. 피해를 주는 출혈·화상·흡수와 설치물은 기존의 원본 이름을 가진 지속 효과를 사용하므로 일반 중독과 중복되지 않는다.

매혹·무장 해제는 규칙 엔진이 지원하지만 현재 보관한 원본 툴팁에 대응하는 지정 카드는 없다. 기존 유키 E의 일반 약화는 원본의 기본 공격 피해 감소에 맞는 공격력 감소로 반영하며 임의로 무장 해제를 추가하지 않는다.

즉시 적중 상태와 지연 상태를 구분한다. 아이솔 Q의 속박은 세므텍스가 터질 때, 르노어 R의 광란은 피날레가 적중할 때 발동한다. 엠마 R은 이전 기술과 남은 설치물에 따라 속박·끌어당김·변이를 구분한다. 엘레나의 빙결과 띠아의 색 조합 제어도 카드 사용 전 누적 상태를 검사한다. 빗나간 공격과 성립하지 않은 조건으로는 상태가 발동하지 않는다.

활성 상태와 대기 중인 상태는 전투 저장에 포함된다. 이전 저장에 이 필드가 없어도 비어 있는 상태로 초기화한다. 전투 중 행동 예고는 상태 해제·정화·코스트 변화까지 복제 상태로 계산하며 실제 난수와 진행을 소비하지 않는다. 새 상태는 전투가 끝나면 함께 초기화된다.
