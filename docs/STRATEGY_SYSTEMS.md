# 덱과 경로를 계획하는 전략 시스템

선택형 카드 강화, 손패 보관, 지도 서비스, 후속 조우의 사용법과 수치입니다. 모두 이번 탈출 원정에 적용되며 새 게임에서는 초기화합니다. 보스 페이즈와 정예 전투는 이번 변경 범위에 포함하지 않습니다.

## 원하는 카드와 강화 방향 선택

실험체 조우에서 `upgrade_card` 행동을 선택하면 강화 대상과 방향을 직접 고르는 화면이 열립니다. 후보 카드를 선택하고 강화 후 효과를 확인한 뒤 **선택한 강화 확정**을 누릅니다. 확정 전에는 다른 후보나 방향으로 바꿀 수 있고 **강화 없이 진행**할 수도 있습니다.

- 덱에 가진 카드 1종을 강화합니다. 같은 ID의 모든 사본과 이후 얻는 같은 카드에 적용됩니다.
- 카드 1종은 한 방향으로 한 번만 강화합니다. 다른 방향을 추가하거나 중첩할 수 없습니다.
- 무기 D 카드, 이미 강화한 카드, 실제로 바뀔 효과가 없는 카드는 후보에서 제외합니다.
- 모든 카드가 두 방향을 갖는 것은 아닙니다. 해당 카드에 적용 가능한 방향만 표시합니다.
- 플레이어 카드의 복사본에 적용하므로 공유 도감의 원본 수치와 상대 실험체의 기술은 바뀌지 않습니다. 자신의 덱·전투·상세 미리보기에는 선택한 강화가 반영됩니다.

| 강화 방향 | 적용 수치 |
|---|---|
| 출력 강화 | 카드의 기본 피해와 방어도를 각각 3, 회복을 2 늘립니다. 해당 항목이 있는 경우에만 적용합니다. |
| 기본 피해·방어·회복이 없는 카드의 출력 강화 | 회피율 5%p, 중독 수치 1, 약화 지속 1턴, 취약 지속 1턴, 강화 가능한 첫 추가 효과의 수치 1 중 카드에 맞는 첫 항목을 적용합니다. 상태 자체를 수치처럼 늘리지 않습니다. |
| 코스트 절약 | 기본 코스트가 2 이상인 카드의 코스트를 1 줄입니다. 강화로 인한 기본 코스트 하한은 1입니다. |
| 니아 Q — 블록 증설 | 사용 시 블록 생성량을 1에서 2로 늘립니다. 블록 최대치는 3입니다. |
| 니아 W — 블록 연산 강화 | 소비하는 블록마다 얻는 추가 피해를 4에서 6으로 늘립니다. |

니아 Q/W에는 출력 강화와 해당 블록 강화가 제시됩니다. 다른 카드에는 출력 강화·코스트 절약 중 적용 가능한 방향이 제시됩니다. 전투 중의 무료 사용권과 할인은 선택한 기본 코스트를 바탕으로 기존 규칙에 따라 적용합니다.

## 손패 한 장을 다음 턴까지 보관

플레이어 턴에 **카드 보관**을 누르고 손패에서 남길 카드 1장을 선택합니다. 같은 사본을 다시 누르면 해제되고 다른 사본을 누르면 대상을 바꿉니다.

| 항목 | 규칙 |
|---|---|
| 사용 한도 | 전투당 2회이며 한 턴에 1장만 보관합니다. |
| 횟수 차감 | 카드가 선택된 상태로 턴을 종료할 때 1회를 사용합니다. 선택·변경·해제만 하면 차감하지 않습니다. |
| 선택한 카드 사용 | 턴 종료 전에 그 사본을 사용하면 예약이 해제됩니다. 사용 횟수는 차감하지 않습니다. |
| 다음 턴 | 보관한 사본을 먼저 손패에 돌려주고 새로 뽑는 카드를 1장 줄입니다. 기본적으로 보관 카드 1장 + 새 카드 4장이 됩니다. |
| 추가 드로우 | 턴 시작 효과와 추가 드로우는 기존대로 적용하되 손패 상한 12장을 지킵니다. |
| 적 턴 | 확정한 보관 대상을 변경할 수 없습니다. |

동일한 카드가 여러 장이면 선택한 사본을 추적합니다. 그 앞의 다른 카드를 사용해 손패 순서가 바뀌어도 보관 대상은 유지됩니다. 남은 횟수는 다음 전투에서 다시 2회가 됩니다.

## 보안 콘솔과 하이퍼루프

두 기능 모두 지도에서 사용합니다. 지도 정보 확인은 실제 전투 난수를 새로 굴리지 않습니다.

| 서비스 | 비용·한도 | 효과·제한 |
|---|---|---|
| 보안 콘솔 | 40크레딧, 막당 1회 | 현재 위치 뒤의 두 단계에서 아직 방문하지 않은 실험체·야생동물의 종류와 키오스크 재고·가격·잠금 여부를 공개합니다. 해당 두 단계에 아직 공개하지 않은 전투 구역이 있을 때 사용할 수 있습니다. |
| 하이퍼루프 | 크레딧 비용 없이 막당 1회 | 현재 위치에서 평소에는 연결되지 않은 **바로 다음 단계**의 구역을 골라 진입합니다. 여러 단계를 건너뛰거나 보스를 생략하지 않습니다. |

보안 콘솔은 공개한 전투 상대를 구역에 저장합니다. 이후 그 구역에 들어가면 확인한 실험체나 동물과 실제로 싸웁니다. 공개 정보를 반복해서 열거나 저장을 불러와도 상대를 다시 뽑지 않습니다. 키오스크에서는 실제 구매 규칙과 같은 목록을 보여 주므로 VF혈액샘플의 두 번째 보스 처치 조건과 현재 가격도 반영됩니다.

하이퍼루프 버튼을 누르면 목적지 선택 상태가 됩니다. 취소하거나 잘못된 목적지를 누르면 사용 횟수를 차감하지 않습니다. 유효한 목적지에 실제로 진입할 때 이번 막의 사용 횟수가 소모됩니다. 현재 위치에서 다음 단계의 모든 구역이 이미 연결되어 있으면 이용할 목적지가 없습니다.

## 약속으로 이어지는 실험체 조우

기본 조우는 91종이며 각 조우에는 행동 3개가 있습니다. 그중 아래 8명의 기존 행동 하나를 약속 선택지로 바꿨습니다. 약속을 수락하면 즉시 보상을 받고 해당 실험체의 후속 조우를 해금합니다. 후속 조우 8종도 각각 행동 3개를 가지므로 전체는 **99개 이야기·297개 행동**입니다.

| 실험체 | 첫 약속의 대가 | 즉시 보상 | 후속 이야기 | 후속 행동의 보상 중 하나 선택 |
|---|---|---|---|---|
| 쇼우 | 고기 1개 | 웰던 스테이크 1개 | 돌려받은 빈 도시락 | 트러플 파스타 1개 / 쇼우 W 식사 시간 / 45크레딧 |
| 레녹스 | 15크레딧 | 연어 1개 | 다시 팽팽해진 낚싯줄 | 피쉬 앤 칩스 1개 / 레녹스 E 휩쓸기 / 선택형 카드 강화 |
| 엠마 | 20크레딧 | 체력 16 회복 | 관객 한 사람을 위한 피날레 | 엠마 R Change★ / 기본 공격 1장 / 무작위 일반 카드 1장 제거 |
| 니아 | 25크레딧 | 니아 W 싱크 포인트 1장 | 둘이 누르는 CONTINUE | 이번 원정의 최대 코스트 +1 / 니아 E 1UP / 선택형 카드 강화 |
| 알렉스 | 20크레딧 | 알렉스 E 펄스 스팅 1장 | 암호문 뒤의 귀환 경로 | 알렉스 Q 코일건 / 선택형 카드 강화 / 50크레딧 |
| 캐시 | 15크레딧 | 체력 20 회복 | 봉합 뒤의 경과 관찰 | 체력 28 회복 / 최대 체력 +4 / 캐시 W 앰퓨테이션 |
| 피오라 | 추가 재료·크레딧 없음 | 선택형 카드 강화 | 같은 간격, 달라진 발끝 | 기본 공격 1장 / 피오라 E 마르셰 & 롱빼 / 최대 체력 +3 |
| 테오도르 | 20크레딧 | 선택형 카드 강화 | 잡음 사이의 같은 신호 | 테오도르 Q 에너지 포 / 체력 24 회복 / 45크레딧 |

표의 카드 보상은 각각 1장입니다. 회복은 최대 체력을 넘지 않습니다. 엠마의 카드 제거는 무기 카드 이외의 무작위 사본을 대상으로 하며 덱에 최소 5장을 남길 수 있을 때만 선택할 수 있습니다. 카드 강화는 대상과 방향을 고르는 위 규칙을 따릅니다.

### 다음 조우의 등장 확률과 미해결 약속

1. 새로 수락한 약속은 **바로 다음 실험체 조우**에서 우선 추첨합니다. 80% 확률로 세 선택지 중 하나에 해당 후속 이야기를 넣습니다. 전투·키오스크·모닥불은 이 추첨을 소모하지 않습니다.
2. 등장하지 않았거나 플레이어가 다른 실험체를 골라도 약속은 사라지지 않습니다.
3. 여러 약속이 남으면 새 약속의 다음 조우 우선권을 먼저 적용하고, 이후에는 미해결 약속의 80% 우선권을 순환합니다. 이번에 우선 추첨한 약속은 목록 뒤로 이동합니다.
4. 우선권이 없는 미해결 후속 이야기도 일반 추첨에 참여합니다. 그 실험체의 기본 조우 자리를 후속 이야기로 대체하므로 세 선택지의 실험체가 중복되지 않습니다.
5. 후속 행동을 선택하면 그 이야기의 보상은 한 번만 받습니다. 완료한 약속은 다시 시작할 수 없습니다. 아직 진행 중인 같은 약속도 중복해서 수락할 수 없습니다.

약속이 여러 개일 때 각각이 동시에 80% 확률을 받는 것은 아닙니다. 지도 하단에는 **다음 80% 우선 추첨 대상**과 남은 약속 수가 표시됩니다. 비용·즉시 보상·후속 이야기의 제목은 첫 행동을 고르기 전에 확인할 수 있습니다. 필요한 크레딧이나 재료가 부족하면 해당 행동을 선택할 수 없습니다.

## 기존 이어하기와 저장 호환

저장 형식 버전 2와 `lumia-vf-loop-v1.json` 파일명을 유지합니다. 이전 저장에 없는 항목은 불러올 때 보완합니다.

| 저장 항목 | 보존·보완 방식 |
|---|---|
| 새 카드 강화 | 카드 ID와 방향을 `cardUpgrades`에 저장합니다. 강화 대상을 기다리는 조우 상태도 복원합니다. 확정 전 후보 선택은 강화 효과를 부여하지 않습니다. |
| 기존 카드 강화 | 이전 `upgrades`의 피해 +3·방어 +3·회복 +2 효과를 유지합니다. 이미 강화한 카드에는 새 방향을 중첩하지 않습니다. |
| 손패 보관 | 예약한 손패 인덱스, 턴 종료 후 보관 사본, 전투 중 사용 횟수를 저장합니다. 이전 전투 저장은 보관 예약 없이 사용 횟수 0으로 보완합니다. |
| 지도 서비스 | 공개 노드와 확정 상대, 콘솔·하이퍼루프를 사용한 막을 저장합니다. 불러오기가 사용 횟수를 돌려주지 않습니다. |
| 후속 조우 | 미해결 약속·다음 우선권·완료한 후속 이야기를 저장합니다. 이미 제시된 조우 선택지와 난수 상태를 보존하므로 불러오기만으로 80% 추첨을 다시 하지 않습니다. |

원정별 강화는 공유 카드 정의를 바꾸지 않습니다. 이전 저장의 지도 길이와 진행 상태도 유지하며 새 기능 때문에 맵을 다시 만들지 않습니다. 자동 화면 검증은 별도 저장 슬롯을 사용합니다.

## 구현과 검증 범위

주요 구현은 `StrategyMechanics.cs`, `EncounterChains.cs`, `EventPresentation.cs`, `GameEngine.cs`, `LumiaGame.cs`에 있습니다. 규칙 검증은 `Tools/StrategySmokeTests.cs`의 다음 시나리오를 전체 코어 테스트와 함께 실행하도록 구성했습니다.

| 대상 | 검증하는 경계 조건 |
|---|---|
| 선택형 강화 | 대상·방향을 기다리는 상태, 중복 사본, 잘못된 대상·방향, 중복 강화 차단, 니아 블록 생성·상한, 코스트 하한, 원본·상대 데이터 유지, 이전 강화와 저장 복원 |
| 손패 보관 | 정확한 사본 추적, 선택 취소와 사용 시 해제, 전투당 2회 한도, 적 턴 제한, 다음 턴 새 드로우 1장 감소, 턴 시작 추가 드로우의 손패 12장 상한, 턴 도중·적 턴 저장 복원 |
| 지도 서비스 | 40크레딧과 막당 한도, 다음 두 단계의 실제 상대 공개, 정보 재열람의 난수 불변, 불러오기 후 실제 전투 일치, 미연결 다음 단계만 이동, 잘못된 목적지·취소·막 변경 |
| 후속 조우 | 91개 기본 조우 보존과 8개 후속 조회, 고정 카드 ID, 비용 미납 차단과 한 번 지불, 500개 시드의 약 80% 등장 표본, 새 약속 우선권과 오래된 약속 순환, 다른 실험체 세 선택지, 비조우 구역 통과, 저장 복원과 중복 보상·재시작 차단 |

개발 빌드의 `-bts-strategy-verify`는 강화 6화면·보관 5화면·지도 서비스 7화면·연계 조우 7화면·도움말 1화면, 총 26화면을 캡처하도록 구성했습니다. 기능 대상을 넘어선 난도 전체 조정이나 장기 플레이 밸런스의 확정을 의미하지 않습니다. 실제 코어 테스트·Windows 화면 검증의 실행 결과는 [VALIDATION.md](VALIDATION.md)에 기록합니다.
