# 전술 스킬 픽셀 아이콘

전술 스킬 F 아이콘 26종과 전술 강화 모듈 1종을 각 원본의 형태·배치·주요 색상을 참고해 새 픽셀 그림으로 제작했다. 스킬은 기존 `nia_q.png`와 같은 불투명한 남색 정사각형 타일이며, 모듈은 기존 시스템 아이템 규격을 따른 투명 아이콘이다.

제작 도구는 **내장 ImageGen**이다. 자산마다 별도 호출을 사용했다. 원본과 스타일 참조를 먼저 `view_image`로 확인했고, 원본은 주제·구도, 니아 Q 아이콘은 도트 스타일만 참고하도록 프롬프트를 분리했다. API 키나 CLI 대체 경로, 색상 양자화, 픽셀 그림의 절차적 대체 제작은 사용하지 않았다.

## 보존과 경로

- `references/{id}.png`: 교체 전 원본 PNG. 원래 해시와 바이트를 보존한다.
- `references/original-icons-manifest.json`: 원본 출처와 SHA-256을 보존한 초기 매니페스트 스냅샷.
- `references/style_nia_q.png`: 기존 도트 스타일 참조.
- `generated/{id}.png`: 내장 ImageGen이 만든 원본 출력. 변경하지 않는다.
- `generation/{id}.json`: 각 최종 프롬프트, 참조 경로, 도구 이름, 생성 도구의 원래 출력 경로.
- `runtime-preview/{id}.png`: 게임에 들어갈 규격으로 최근접 변환한 후보.
- `tactical-pixel-contact-sheet.png`: 각 원본과 최종 도트 아이콘 비교.
- `output-manifest.json`: 27종이 모두 생성·검증된 뒤 기록하는 최종 결과. 원본·생성·런타임의 SHA-256과 Unity GUID, 실제 크기, 알파 및 색상 통계를 각각 분리한다.

## 최종 변환

`python tools/ProcessTacticalPixelArt.py`는 현재까지 생성된 그림의 미리보기만 작성한다. `--finalize`는 27개 모두의 생성 그림·프롬프트 기록·원본 해시가 유효한 경우에만 런타임 PNG를 교체하고 `result: PASS` 매니페스트를 작성한다. 기존 `.meta` 파일과 GUID는 보존한다.

F 아이콘은 `ProcessChibiArt.normalize_icon`과 같은 방식으로 생성 타일 전체를 **96×96 최근접 리사이즈**한다. 모듈은 `ProcessSystemArt.py`와 같은 방식으로 **28×28 최근접 리사이즈 → 투명한 32×32 캔버스에 2픽셀 여백 → 64×64 최근접 확대**한다. 생성 알파를 보존한다. 배경 제거·리페인팅·선명화·보간·색상 양자화를 하지 않는다.

프롬프트의 공통 지시는 원본의 식별 가능한 심볼과 주요 색을 유지하는 16비트 스타일, 굵은 사각 픽셀 클러스터, 계단형 윤곽, 제한된 색상 느낌, 남색 배경, 텍스트·카드 프레임·흐린 광원 배제이다. 전체 프롬프트는 27개의 `generation/*.json`에 기록되어 있다. 실제 파일의 색 수는 별도 통계로 남겨 생성 결과의 수치를 숨기지 않는다.

이터널 리턴의 원본 IP와 전술 스킬·아이템의 권리는 님블뉴런에 귀속된다. 이 그림은 비공식 팬 게임을 위한 도트 재해석이다.
