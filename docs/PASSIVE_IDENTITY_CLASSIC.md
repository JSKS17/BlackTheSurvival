# Classic 55명 전역 패시브 정체성

구현 파일은 `Assets/Scripts/Lumia/PassiveIdentityClassic.cs`, 등록 클래스는 공유 엔진 계약에 맞춘 `TraitIdentityClassic`이다. `ClassicRoster.cs`의 기존 패시브 ID **55개**를 모두 등록한다. 원문 근거는 [reference-skills.json](art-chibi/reference-skills.json)의 각 실험체 `slot=T` 전체 tooltip이다. 저장된 `12.5.0` 자료를 해석했으며 현재 서비스 버전을 다시 검증한 자료는 아니다.

## 적용 범위와 강도

모든 발동 조건은 기본 공격, 모든 스킬, 모든 궁극기, 적중, 피격, 회피, 제압, 보호막, 회복, 턴, 전투 시작/승리 같은 **전역 사건**을 사용한다. 어느 실험체의 카드를 사용했는지 검사하지 않는다. 아이작의 패시브는 하나의 기본 공격을 포함한 모든 기본 공격에 추가 피해를 주고, 세 번째 기본 공격에서는 추가 피해와 회복을 함께 준다. 피오라의 뚜셰도 어떤 실험체의 스킬이든 적중하면 쌓인다.

원래의 1.5배 주인 Q/W/E/R 카드 선택지 가중치는 카드 획득 로직에 그대로 남는다. 이 프로필의 `replaceLegacy=true`는 예전의 단순 힘/중독/고정 회복 **전투 효과만** 대체하며, 카드 획득 선호를 제거하지 않는다.

- 즉발 추가 피해는 보통 2~5, 회복은 2~4, 보호막은 3~4다. 범용 자원은 최대 3~4이며, 자원 비례 보너스도 엔진의 상한을 받는다.
- 지속 피해/회복/지원 공격은 2~3회, 회피 증가는 1~2턴이다. 코스트 회복은 한 번에 1이며 재사용 대기시간과 턴당 횟수 제한을 둔다.
- 자원이 조건인 효과는 그 사건 발생 직전 상태를 읽는다. 바냐와 캐시처럼 **실제 적중 수**가 중요한 패시브는 적중 조건이 붙은 자원을 사용한다. 기본 공격의 주기적 발사는 공격 사용 횟수를 기준으로 하므로 빗나간 발사도 발사 순서에 포함될 수 있다.
- 패시브별 카운터와 자원은 `trait:{passiveId}`로 격리된다. 주인이 다른 카드에도 발동하면서 서로 다른 패시브의 동명 자원은 섞이지 않는다. 스킬 프로필의 주인 전용 상태와도 분리된다.
- 루크의 청소 완료, 쇼우의 체격, 실비아의 지역 탐방, 에키온의 무기 진화, 피올로의 단련은 `persistent=true`로 전투 간 저장한다. 일반 표식과 버프는 새 전투에서 초기화한다.
- 제니의 죽음의 연기는 사용될 때까지 전투 내 유지되는 일회성 생존 효과다. 다음 전투에서 한 번 새로 준비한다. 니아 액티브의 유한 지속시간과는 별도의 패시브 규칙이다.
- 회복이 다시 회복을 부르는 패시브는 재진입 방지와 쿨다운/턴 제한을 전제로 한다. 같은 사건으로 추가 효과가 무한히 연쇄하지 않는다.
