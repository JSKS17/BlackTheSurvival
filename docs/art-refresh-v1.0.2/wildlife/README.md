# 야생동물 도트 수정 (1.0.2)

늑대, 멧돼지, 곰, 닭의 전용 투명 PNG를 `Assets/Resources/Lumia/Wildlife/`에 추가했습니다. 기본 자세는 왼쪽을 향하는 전신이며, 기존 실험체와 맞추어 굵은 사각 도트, 어두운 계단형 외곽선, 단계형 명암을 사용합니다.

`PixelArt.Portrait()`가 이 전용 파일을 우선 불러오고, 높이 80의 논리 도트 격자에 Point 샘플링하여 표시합니다. 원본 PNG는 생성 도구의 출력 그대로 복사했으며 Python이나 다른 래스터 편집 도구로 후처리하지 않았습니다. PNG는 각 1254×1254 RGBA입니다. 미세한 출력 차이는 화면의 80픽셀 논리 격자에서 정리됩니다.

들개를 포함하는 기존 `CharacterAtlas.png`는 변경하지 않았습니다. 전용 PNG가 없는 동물은 기존 아틀라스로 표시됩니다. 변이 표시는 별도의 전투 UI에서 처리하며 기본 동물 디자인을 바꾸지 않습니다.

## 원작 외형 참고

원작 참고 이미지는 런타임 에셋이 아니며 `ArtSource/Release1.0.2/Wildlife/`에 보관합니다. 개발 초기 공식 콘셉트 시트는 식별 가능한 외형을 확인하는 자료로 사용했고, 2023년 공식 게임 플레이 자료로 목걸이/구속구의 인게임 적용을 함께 확인했습니다.

- [이터널 리턴 1.0.0 게임 플레이 (2023)](https://playeternalreturn.com/posts/news/1281?hl=ko-KR): 곰과 늑대 캠프의 인게임 외형.

## 생성과 검증

기본 제공 `image_gen.imagegen`을 사용했습니다. 네 동물을 각각 생성한 후 늑대·멧돼지·곰만 원작 콘셉트 시트를 추가 참고하여 놓친 외형 디테일을 좁게 수정했습니다. [프롬프트 기록](prompts.md)과 [파일별 해시·투명도 기록](manifest.json)을 함께 보관합니다. 아틀라스의 들개 및 승인된 실험체 이미지는 수정 대상이 아닙니다.

`Tools/ValidateWildlifeArt.py`는 원본 PNG, 투명 여백, 해시, Point/비압축 임포트 설정, 아틀라스 보존 여부를 읽기 전용으로 확인합니다. 실제 표시 크기와 도트 가독성은 Windows 플레이어의 야생동물 검증 화면에서 별도로 확인합니다.
