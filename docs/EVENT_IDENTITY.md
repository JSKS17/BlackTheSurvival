# 실험체 조우 재구성

2026-10-09 기준, 등록된 실험체 91명에게 각각 고유 조우 1개와 행동 3개를 작성했다. `EventIdentity.cs`가 활성 조우를 만들고, 카드·패시브의 최종 정의를 구성한 뒤 `EventPresentation.cs`가 정확한 보상 문장을 붙인다. 기존 `event_실험체ID`를 유지해 저장된 지도와 진행 중 조우가 같은 실험체를 가리킨다.

상황과 대사는 이 팬 게임을 위한 창작이다. 공식 스킬의 역할, 인물의 태도, 도구와 동료를 반영하며 공식 설정에 실제로 일어난 사건이라고 제시하지 않는다. 장비 분석·탈출 훈련 등 연구원 하나와의 만남을 매개로 캐릭터별 선택 이유를 만든다.

## 선택의 차이

- 니아는 블록을 쌓는 Q, 블록을 사용하는 W, 빌드를 바꾸는 룬 선택을 제안한다. 셀린은 폭탄 배치와 기폭을 따로 가르친다. 아비게일은 워프와 좌표를 남기는 공격을 각각 선택하게 한다.
- 아야·에스텔·샬럿은 구호와 보호를 먼저 살핀다. 쇼우와 일레븐은 지금 먹는 회복과 나중에 사용할 음식을 구분한다. 음식 보상은 실제 인벤토리에 들어가며 각 음식의 현재 회복량을 표시한다.
- 재키·아이작·르노어·크레이버의 위험한 실습에는 체력 대가가 있다. 라우라·쇼이치·헤이즈·다르코의 거래와 일부 상위 스킬 훈련에는 크레딧 대가가 있다. 결과 문장에 대가와 실제 고정 카드를 함께 표시한다.
- 고가 오브젝트를 무료로 나눠 주던 선택은 거래 또는 위험한 수집으로 바꿨다. 운석 110, 미스릴 130, 포스코어 190, VF 혈액 샘플 300크레딧의 조우 거래를 사용한다. 생명의 나무의 위험한 수집은 체력 12를 소모한다. 조우 거래에 표시된 대가는 고정값이다.
- 조우 크레딧은 30~40, 즉시 회복은 14~20, 최대 체력 증가는 3~4로 정했다. 무료 상위 재료와 큰 현금 지급을 줄이면서 카드·정리·훈련·회복 중 덱과 상태에 맞는 선택을 남겼다.

모든 조우에는 해당 실험체의 고정 Q/W/E/R 카드 선택이 최소 하나 있다. 고정 카드 선택은 총 108개다. 선택 직전에 카드의 실험체 이름·스킬 이름·Q/W/E/R 슬롯·코스트를 표시하고, 아이콘을 눌러 현재 카드의 전체 설명을 열 수 있다. 보상 카드가 별도 문자열이 아닌 실제 `cardId`를 참조하므로 설명과 지급 대상이 일치한다.

크레딧 부족이나 대가를 치른 뒤 체력이 남지 않는 선택은 실행하지 않는다. 제거할 카드나 강화할 카드가 없는 선택도 실행하지 않는다. 보호 장비의 무기 카드가 제거·강화 대상에서 빠지는 기존 규칙은 유지한다.

## 데이터 확인

실제 C# 정의를 초기화해 1,556개 항목을 확인했다. 실험체 91명 전원에 조우가 있고, ID 중복은 없으며, 행동 273개가 정확히 세 개씩 묶인다. 고정 카드 108개는 모두 실제 카드이며 조우 실험체의 스킬에 속한다. 슬롯·코스트·설명이 최종 카드 정의와 일치한다. 음식 8개, 대가가 있는 행동 33개, 오브젝트 참조와 가격, 크레딧 보상 상한도 확인했다. 전체 런타임 C# 컴파일을 통과했다.
