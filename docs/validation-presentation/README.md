# v0.1.25 튜토리얼·스토리·전투 정보 검증

검증일: 2026-10-13. Unity 6000.3.11f1 Windows x64.

새 기능은 니아의 짧은 연습 전투, 로비 대사 무작위 재생, 개발자·문의 표기, 사용 전 정보와 저장되는 전투 기록, 프롤로그/노말/하드 각 4컷이다. 컷신은 별도 텍스트와 자동 줄바꿈 말풍선을 사용한다.

`Tools/RunCoreTests.ps1`: **117개 시나리오·103,775개 단언** 통과. 연습에서 기본 공격·방어·실제 상대 턴·Q 두 번→경계→W→남은 코스트 0에서 할인 Q 사용을 검증했다. 대사 셔플은 매 묶음의 전원 도달과 묶음 경계의 즉시 반복 금지, 게임 난수 격리를 검사했다. 스토리 12개 원문·중간 복원·건너뛰기·완료 중복 방지·기존 저장·모드별 재생·재생 중 상태 격리, 392장×양측 미리보기의 저장 필드 불변, 실제 로그와 상한을 포함한다. [규칙 로그](core-tests.log).

`Tools/VerifyRuntime.ps1`: 전체 런타임 C# 컴파일 통과.

개발 실행의 `-bts-presentation-verify`는 별도 저장 슬롯과 연구 프로필을 사용한다. 개인 원정·연구 파일의 전후 SHA-256을 비교하고, 실제 Unity 글꼴과 1280×720 화면에서 학습 전투·카드 정보·전투 기록·12컷·다시보기 화면을 검사한다. 튜토리얼 중 Save 호출로 원래 디스크/연구가 바뀌지 않는지와 원래 엔진의 정확한 복귀, 실제 JSON의 컷 진행 및 로그 복원을 확인한다.

네이티브 최종 결과: **32개 화면·86개 글꼴 배치** 통과. 12컷 이미지의 존재·Point 필터와 말풍선 높이, 튜토리얼의 정확한 원정 복귀·저장 격리, 사용 전 조회 무변경, 실제 컷 진행/전투 로그 JSON 복원, 개인 저장·연구 파일 보존을 확인했다. [결과 JSON](native-results.json), [검증 로그](native-player.log), [전체 화면](screenshots/).

32개 화면을 직접 시각 검토했다. 컷신 12개와 다시보기 13화면에서 얼굴·내레이션·대사의 가림이나 잘림이 없고, 노말 3컷의 대사를 자연스러운 문장 경계에서 개행했다. 튜토리얼의 하단 배경과 헤더를 통일하고 `?` 전용 버튼의 여백으로 생긴 글리프 잘림을 수정한 뒤 다시 촬영했다. 사용 전 정보·침묵 제한·보스 이동 금지·전투 기록을 확인했다.

배포용 Release 빌드도 `LUMIA BUILD Succeeded / errors=0`를 확인했다. 게임 코드와 12컷 원본은 검증 프로젝트와 일치한다. Unity가 기존 렌더링 설정·아이콘 메타·폰트 설정을 정규화한 항목은 [소스 비교](source-build-audit.json)에 따로 기록했다. 원래 작업 폴더의 해당 설정을 덮어쓰지 않았다. [시작 검증](release-startup.json), [ZIP 검증](archive-validation.json).

자동 규칙 검증은 사람의 재미·밸런스 평가를 대신하지 않는다. v0.1.25는 테스트 릴리스이며 1.0 정식 버전으로 올리지 않는다.
