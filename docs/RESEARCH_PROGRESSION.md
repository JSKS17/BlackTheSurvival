# 관측 데이터와 실험체 연구

이 문서는 원정 종료 정산과 실험체별 연구 보고서의 규칙을 설명한다. 연구는 하나가 반복 원정에서 얻은 기록을 연구소에 남기는 성장 요소다. 준비 지원, 시작 프로토콜, 영구 능력치 상승은 이번 구현 범위에 포함하지 않는다. 새 원정을 시작할 때 선택해야 하는 단계도 추가하지 않는다.

## 원정 종료 정산

승리와 패배 모두 원정에서 실제로 달성한 성과를 관측 데이터로 정산한다. 단순히 구역에 들어가거나 보스 미리보기를 여는 행동은 성과로 세지 않는다. 원정이 끝나기 전 진행 중인 연구는 원정 저장에 보존되고, 영구 연구 기록에는 원정 종료 시 합쳐진다.

| 성과 | 관측 데이터 | 집계 규칙 |
|---|---:|---|
| 구역 완료 | 1 | 원정의 구역 ID당 한 번 |
| 전투 승리 | 1 | 승리한 구역 ID당 한 번 |
| 보스 처치 | 6 | 처치한 보스 구역당 한 번 |
| 보스 공략 성공 | 1 | 같은 보스 구역의 같은 페이즈를 중복 집계하지 않음 |
| 탈출 성공 | 12 | 원정의 최종 승리 정산에 한 번 |
| 첫 실험체 관측 | 2 | 계정 기록에 아직 관측되지 않은 실험체당 한 번 |
| 새 연구 과제 완료 | 3 | 이전 원정까지 완료되지 않았던 과제당 한 번 |
| 첫 보스 연구 | 3 | 계정 기록에 아직 처치하지 않은 보스 실험체당 한 번 |
| 새 실험체 교차 연계 | 3 | 연계 계열·준비한 실험체·활용한 실험체 조합당 한 번 |

구역 완료와 전투 승리, 보스 처치는 서로 다른 성과이므로 함께 정산된다. 교차 연계는 서로 다른 실험체가 준비한 자원을 실제로 활용했을 때 기록한다. 같은 기술을 사용했다는 사실만으로 교차 연계 보상을 주지 않는다.

종료 화면은 이번 원정의 성과별 데이터, 새로 완료한 연구 과제, 실제로 성립한 교차 연계와 보스 공략 성과를 보여 준다. 이미 정산한 원정은 같은 화면을 다시 열거나 저장을 불러와도 데이터를 다시 지급하지 않는다.

## 실험체별 세 연구 과제

현재 실험체 91명 모두 연구 대상이다. 원정 여러 번에 걸쳐 다음 세 과제를 누적한다.

| 과제 | 완료 조건 |
|---|---|
| 실험체 관측 | 실제 전투에서 만나거나, 실험체 조우 후보 중 해당 실험체를 선택한다. 후보 목록과 미리보기는 제외한다. |
| 기술 연구 | 해당 실험체의 Q·W·E·R 네 기술을 직접 사용한다. 무료 연계 사용도 인정한다. |
| 고유 실험 | 해당 실험체의 실제 기술 프로필에 맞는 준비·소비·변신·조건부 효과 등의 실험을 성립시킨다. |

고유 실험은 각 실험체의 기술 효과에서 조건을 읽어 구성한다. 조건이 충족되지 않은 사용이나 실제로 상태가 변하지 않은 사용은 인정하지 않는다. 예를 들어 수치를 최대로 높이는 실험은 이미 최대였던 수치에 기술을 다시 쓰는 행동으로 달성되지 않는다. 해제·소비 실험에는 실제 자원이 줄어드는 결과가 필요하다. 회복 실험에는 실제로 회복한 체력이 필요하다.

니아는 아케이드 블록 3에서 W를 적중시켜 블록을 회수하고 추가 피해를 주는 실험을 한다. 아이작은 착취 패시브를 가진 상태에서 세 번째 기본 공격을 적중시켜 추가 피해와 실제 체력 회복을 모두 발동한다. 아이작의 실험은 특정 실험체의 기본 공격에 한정하지 않는다.

연구소 화면에서 과제별 진행도, 완료 조건, 고유 관측 메모를 확인한다. 이 화면을 읽거나 실험체를 바꾸어 보는 행동은 진행 중인 원정의 난수나 전투 상태를 변경하지 않는다.

## 연구 보고서 완성과 해금

세 과제를 모두 완료하면 관측 데이터 **500**을 사용해 해당 실험체의 보고서를 완성할 수 있다. 데이터가 부족하거나 이미 완성한 보고서는 구매하지 못한다. 완성한 보고서는 계속 열람할 수 있고, 해당 실험체의 새 연구 조우를 해금한다.

추가 조우의 해금은 새로운 이야기와 선택지를 제공한다. 기존 카드·패시브·실험체·일반 조우를 연구 뒤로 잠그지 않는다. 보고서를 완성해도 체력·공격력·최대 사용 코스트·패시브 슬롯이 영구 증가하지 않는다.

보고서의 해금 목록은 새 원정 생성 시 원정에 복사한다. 원정이 시작된 뒤 연구소에서 보고서를 완성해도 해당 원정의 조우 풀이 소급 변경되지 않는다. 다음 새 원정부터 추가 조우가 후보로 참여한다.

## 레어 조우

원정 시작 시 해당 보고서가 해금된 실험체의 일반 조우 후보는 1막 12%, 2막 18%, 3막 이후 25% 확률로 레어 사건 후보로 대체된다. 전체 조우 구역의 출현률이 아니라 실험체 후보별 조건부 확률이며, 최종 세 후보에 레어가 포함된 경우에만 그 막의 출현을 소진한다. 한 화면과 한 막에 레어 후보는 최대 하나다. 다른 사건을 선택해도 같은 막에서 레어 후보가 다시 나타나지 않는다. 무한 모드는 주기를 넘어 전체 막 번호를 세며 4막 이후에도 25%를 유지하고 새 막에서 출현 한도가 새로 열린다.

약속 후속 사건의 다음 조우 80% 우선권을 유지한다. 약속을 기다리는 실험체의 일반·레어 사건은 약속 사건과 경쟁하지 않는다. 실험체별 레어 사건은 원정당 한 번 완료할 수 있으며, 유효한 행동 선택 시 완료 기록을 저장해 재로드 중복 보상을 막는다.

91개 사건의 스킨 테마와 줄거리는 유지한다. 루치아·세레스·크레이버는 팬 창작 사복을 사용한다. 일반 조우 신호를 먼저 표시한 뒤 픽셀 빛과 함께 스킨 도트·레어 제목으로 전환하며, 저장된 최종 후보를 다시 추첨하지 않는다. 연출을 건너뛰어도 보상과 확률은 변하지 않는다.

각 사건은 세 행동을 제공한다. 첫 행동은 해당 실험체의 전용 레어 강화 카드를 구매한다. 두 번째는 해당 실험체 패시브 또는 R을 제공하고, 세 번째에는 아래의 덱 정리·보조 룬·일반 카드 복제·무작위 F를 실험체별로 배치한다. 기존의 일괄 추가 크레딧 30은 제거한다. 선택할 수 없는 행동은 이유를 표시하며 보상 없이 지나갈 수도 있다.

| 보상 종류 | 효과 |
|---|---|
| 레어 강화 카드 구매 | 원본 코스트 기준 `120 + 20 × 코스트` 크레딧을 지불해 해당 실험체의 `++` 카드 1장을 얻는다. 구매 전 실제 효과를 확인한다. 일반 `+`보다 높은 수치와 제한적인 코스트 절약을 제공하며 조건·자원 상한·무료 연계 횟수는 유지한다. |
| 해당 실험체 패시브 | 빈 슬롯에 추가한다. 패시브 3개를 보유했다면 교체할 패시브를 선택한다. 이미 보유한 패시브를 중복 획득하지 않는다. |
| 원하는 카드 최대 2장 제거 | 무기 카드 이외의 덱 사본을 골라 0~2장 제거한다. 덱에는 최소 5장을 남기며 강화된 사본을 구분한다. |
| 해당 실험체 R | 해당 실험체의 일반 R 카드 1장을 덱에 추가한다. |
| 같은 계열의 나머지 보조 룬 | 현재 메인 룬과 같은 계열의 미보유 보조 룬을 전부 얻는다. 중복 발동하지 않으며 이후 메인 룬을 바꿔도 얻은 보조 룬은 이번 원정에서 유지한다. |
| 저비용 일반 카드 복제 | 덱에서 강화되지 않았고 원본 코스트가 1 이하인 카드 한 장을 골라 일반 사본 2장을 추가한다. 조건을 충족하는 기본 공격·기술·D·F도 대상이다. |
| 무작위 F | 전술 스킬 풀에서 무작위 F 카드 1장을 일반 상태로 얻는다. |

레어 `++`는 구매한 사본에만 적용되고 일반 조우 강화로 만들 수 없다. 덱·손패·상세·사용 전 정보·전투 기록과 저장 복원에서 일반, `+`, `++`를 구분한다. 카드 제거·복제와 패시브 교체가 이어지는 도중에도 저장할 수 있으며, 후속 선택을 건너뛰어도 첫 보상 행동을 반복할 수 없다. 이미 완성된 보고서와 이전에 획득한 카드 강화는 업데이트 후 보존한다.

주요 연구 사건의 예시는 다음과 같다.

| 실험체 | 레어 사건 | 선택한 스킨 |
|---|---|---|
| 니아 | 물이 새는 보너스 스테이지 | 니아 (물속성) |
| 아이작 | 군단장의 무장 해제 시간 | 오만의 군단장 아이작 |
| 아이솔 | 후보생의 인원 점검 | 사관후보생 아이솔 |
| 로지 | 체커기 뒤의 정비 구역 | 파이널 랩 로지 |
| 셀린 | 폭발물 취급 주의 쟁반 | 메이드, 때때로 폭발 셀린 |
| 테오도르 | 교관의 빈 사격선 | 사격 교관 테오도르 |
| 블레어 | 포디엄 뒤의 종료 신호 | 포디엄 피니시 블레어 |
| 에키온 | 암흑가의 고장 난 간판 | 암흑가 에키온 |
| 제니 | 백수의 긴급 오디션 | 꿈꾸는 백수 제니 |
| 캐시 | 탈옥 계획의 응급 처치란 | 프리즌 브레이크 캐시 |

실제 보상은 [ResearchEncounters.cs](../Assets/Scripts/Lumia/ResearchEncounters.cs)와 [ResearchRareEncounters.cs](../Assets/Scripts/Lumia/ResearchRareEncounters.cs), 91개 스킨 이야기와 보고서는 [RareSkinStories.cs](../Assets/Scripts/Lumia/RareSkinStories.cs)에 있다. 이 사건은 팬 게임에서 새로 쓴 내용이며 원작의 공식 사건이나 대사를 인용한 것이 아니다.

## 저장과 이전 버전 호환

영구 연구 프로필 `bts-research-v1.json`은 단일 원정 저장과 별개로 보존한다. 새 게임을 시작해 원정 저장을 교체해도 완료한 보고서와 관측 데이터는 남는다. 정산한 원정 ID와 정산 내역을 프로필 장부에 보존해 종료 화면 재진입과 저장 재로드 시 중복 보상을 막는다. 최근 20개 정산 요약도 별도로 보관하지만 중복 정산 방지 장부는 이 개수와 별개다.

저장은 임시 파일을 완전히 쓴 뒤 교체하고 마지막 정상 백업을 유지한다. 원본이 손상되었을 때 정상 백업으로 복원하며, 원본과 백업을 모두 읽을 수 없거나 더 새로운 형식이면 기존 파일을 보존한 채 저장을 보류한다.

정산 파일이 잠겨 있거나 쓰기에 실패한 상태에서 새 원정을 시작하면, 미정산 종료 기록을 원정 ID별 대기 파일에 먼저 보존한다. 다음 실행·연구 기록 열기·새 원정 시작 때 정산을 다시 시도하고, 영구 장부에서 지급을 확인한 파일만 제거한다. 대기 파일까지 보존할 수 없는 경우에는 기존 원정 저장을 덮어쓰지 않는다. 앱을 재시작하고 이어하기 대신 새 게임을 누르는 경우에도 같은 규칙을 적용한다.

이전 버전에서 이미 끝난 원정에는 관측 데이터를 소급 지급하지 않는다. 이전 버전의 진행 중 원정은 기존 전투와 지도 상태를 유지하며 업데이트 이후 실제로 발생한 연구 성과부터 기록한다.

## 구현 연결

- `ResearchProgression`: 원정 관측, 연구 과제, 보고서 비용과 해금, 종료 정산을 관리한다.
- `ResearchStore`: 영구 프로필의 정산 장부, 중복 방지, 원자적 저장과 백업 복원을 관리한다.
- `ResearchEncounters`: 원래 일반 조우와 분리한 추가 사건 목록과 실험체별 관측 메모를 제공한다.
- `GameEngine`: 실제 구역 완료·카드 사용·보스 공략·교차 연계의 결과를 연구에 전달하고 조우 후보를 구성한다.
- `LumiaResearchUI`: 로비 연구소, 보고서 열람, 과제 진행도와 종료 정산을 표시한다.
- `LumiaResearchPersistence`: 원정 저장의 원자 교체·백업 복구와 미정산 원정의 대기 큐를 관리한다.

이 문서는 규칙 설명이다. 실행한 검증과 결과는 해당 버전의 검증 문서에 별도로 기록한다.
