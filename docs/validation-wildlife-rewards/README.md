# v0.1.4 기본 공격·고기 수급 검증

아야·현우·유키·아이작·리오·마커스의 조우에 기본 공격 1장을 무료로 얻는 행동을 추가했다. 각 조우의 세 가지 행동과 고유 기술 보상은 유지한다. 선택 전 카드의 정확한 이름·효과·코스트를 확인할 수 있다.

닭·들개·멧돼지·늑대·곰 승리 시 기본 공격은 3% 확률로 기존 기술 선택지 3장 뒤에 추가된다. 기존 획득 코스트 예산으로 선택하며 선택·취소·확정을 그대로 따른다. 고기는 독립적으로 50% 확률로 1개를 승리 시 가방에 지급한다. 두 보상과 기존 오브젝트는 함께 나올 수 있다. 기존 오브젝트 확률과 실험체·보스 보상은 변경하지 않는다.

- 순수 규칙 검증: **51개 시나리오·56,106개 검증 통과**. 5종 야생동물의 실제 승리 5,000회에서 기본 공격 151회(3.02%), 고기 2,391회(47.82%)를 확인했다. 독립 드롭의 모든 조합과 기존 오브젝트 동시 지급도 검사했다.
- 희귀 기본 공격의 선택·취소·공유 예산·확정, 조우 6곳의 정확히 1장 지급, 보상 및 완료된 저장의 재개, 중복 지급 방지와 이전 저장의 음식 필드 누락을 검사했다. 이전 보상은 다시 추첨하거나 소급 지급하지 않는다.
- 고정된 공개 행동 정책의 40회 전투 시뮬레이션: 탈출 1회·패배 39회·중단 0회. 정책의 진행 검증이며 사람의 체감 난이도 측정은 아니다.
- 설명 감사 **34,874개 검증** 및 Unity 런타임 컴파일 통과. 카드 요약과 디버프 하단 설명의 이전 동작을 유지한다.
- Windows 개발 빌드에서 기존 화면과 새 보상·가방·조우·상세 화면을 합쳐 **85개 화면**을 검사한다. 새 화면 5개를 보관한다. 카드 392종의 4,704개 요약 배치에서 넘침·내부 스크롤이 없는지 확인한다. 음식과 선택 중 보상의 실제 Unity JSON 직렬화도 검사한다.
- 배포 빌드의 소스 해시와 설치 실행 파일 해시를 비교하고 개인 이어하기 저장 보존·시작 창·런타임 오류를 확인한다. 배포 ZIP은 설치된 런타임 전 파일의 CRC·SHA-256을 비교한다. GitHub 업로드 증빙의 임시 기록은 `Temp/`에만 보관한다.
