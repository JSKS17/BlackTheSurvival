# 카드 분류와 표시 기준

카드에는 `이동 · 설치 · 디버프` 중 해당하는 분류를 모두 표시한다. 공격력, 방어도, 코스트에 따라 이 분류가 바뀌지는 않는다. 세 분류가 없는 카드는 기본 공격, 방어, 무기(D), 전술(F), 일반으로 표시한다.

- **이동**: 실제 게임의 `CardDef.movement`를 그대로 사용한다. 속박이면 사용할 수 없고, 둔화 또는 끌어당김이면 코스트가 1 증가한다. 두 상태가 함께 있어도 추가 코스트는 1이다.
- **설치**: 현재 카드 규칙이 실제 전장 물체·지대·소환체를 생성하는지 판정한다. 니아의 블록, 아델라의 체스 말, 셀린의 폭탄, 테오도르의 스크린 같은 필드 자원도 포함한다. 실험체와 규칙 키를 함께 확인하므로 개인 VF, 표식, 자세 전환, 설치물 소비만으로는 설치 분류가 붙지 않는다. 지연 피해나 지속 피해 연산을 사용하더라도 단순 귀환 공격, 회전 공격, 개인 보호막 폭발 등은 설치로 분류하지 않는다. 조건부 설치 카드는 설치 분류를 유지하지만 실제 설치에는 해당 조건이 필요하다.
- **디버프**: `BossMechanics.IsDebuffSkill`을 직접 사용한다. Q/W/E/R/D/F 기술 중 상태이상, 중독·약화·취약, 출혈·화상 규칙이 있는 카드가 대상이다. 조건부 효과, 다음 기본 공격이나 설치물에 예약한 상태이상도 포함한다. 기본 카드는 보스의 디버프 기술 판정에서 제외한다.

상세 설명의 **보스 기믹 판정**은 모든 카드에서 이동 기술과 디버프 기술 해당 여부를 각각 보여준다. 보스의 사용·금지 기믹은 카드를 직접 사용하는 시점에 이 두 실제 판정 기준을 확인한다. 디버프가 현재 조건을 충족하거나 실제로 적중해야만 카드 사용으로 집계되는 방식은 아니다. 분류 표시는 기존 전투 판정을 변경하지 않는다.

현재 카드 테두리와 이름의 색은 **기본 효과** 기준이다. 기본 피해가 있으면 분홍색, 피해 없이 기본 방어도가 있으면 민트색, 나머지는 금색이다. 코스트 숫자는 평소 금색, 할인 시 민트색, 증가 시 분홍색이다. 실험체별 기술 이펙트 색은 이 분류와 별개다.

구현: `CardPresentation.ClassificationLabel` / `ClassificationRules`. 검증: `Tools/CardClassificationSmokeTests.cs`에서 전체 카드의 이동·디버프 분류를 보스의 실제 판정과 대조하고, 설치 생성·소비·개인 자원·지연 공격의 차이와 다중 분류를 확인한다.
