# Black The Survival v1.0.3

- **변이 동물5종의 전용 스프라이트**를 추가했습니다. 원작 변이 닭·들개·멧돼지·늑대·곰의 배색과 외형을 참고해 일반 동물과 시각적으로 구분됩니다.
- 기존 굵은 도트 스타일과 전투에서 보이는 크기를 유지합니다. 전투 본체뿐 아니라 동물 기술의 의도 아이콘·상세·발동 배너와 상대 정보에도 변이 그림을 표시합니다.
- 프롤로그 두 번째 컷 니아의 **양쪽 눈 라인**을 같은 짙은 색으로 수정했습니다. 작은 도트 표시 과정에서 한쪽 검은 라인이 빠지던 원인을 고쳤으며 무표정·포즈·크기를 유지했습니다.
- 일반 동물의 기존 그림, 변이 등장 확률·능력치·보상과 기존 저장은 유지합니다.

**[Windows ZIP 다운로드](https://github.com/JSKS17/BlackTheSurvival/releases/download/v1.0.3/BlackTheSurvival-v1.0.3-Windows-x64.zip)** — 전체를 한 폴더에 압축 해제하고 **BlackTheSurvival.exe**를 실행하세요.

실제 Windows 화면41개와 변이5종의80픽셀 표시·저장 복원 검증을 통과했습니다. 니아의 양쪽 눈 라인도 실제 화면8개 지점에서 같은 짙은 색으로 표시되는 것을 확인했습니다.

[아트와 정확한 프롬프트](https://github.com/JSKS17/BlackTheSurvival/tree/main/docs/art-refresh-v1.0.3), [실제 Windows 검증](https://github.com/JSKS17/BlackTheSurvival/tree/main/docs/validation-v1.0.3)을 공개합니다.
