# 얼굴 픽셀 가독성 보정

기본 92종(하나 포함)과 레어 조우 스킨 91종을 원작의 저장된 일러스트와 대조하고, 실제 사용되는 `PortraitsReference`와 `PortraitsRare` 리소스를 수정했습니다. 전체 이미지를 새 그림으로 교체하지 않고 희미한 눈꺼풀·동공·입술의 개별 픽셀을 다듬습니다. 별도 공통 얼굴 템플릿은 사용하지 않습니다.

니아는 반쯤 감긴 보라색 눈과 풍선껌, 블레어는 처진 옅은 푸른 눈, 세레스는 무거운 수평 눈꺼풀과 엄격한 닫힌 입을 유지합니다. 카티야와 비형에 안경을 추가하지 않습니다. 원작 또는 선택한 스킨에서 안경·선글라스·안대·앞머리·수염·가면에 가려진 부분도 그대로 유지합니다.

캔버스는 기존 **160×160**, 논리 격자는 **80×80의 정확한 2× 확대**입니다. 원본과 모든 알파 바이트가 같고, 검토한 눈·입 픽셀 밖의 색상도 동일합니다. UI의 그림 표시 영역, 포즈·몸체·복장·무기·헤어 외곽·투명 여백과 Unity GUID/import 설정을 바꾸지 않습니다.

## 제작과 재현

사용자의 “픽셀을 수정” 요청에 따라 각 얼굴의 기존 논리 격자에서 좌표와 색상을 지정했습니다. `*-patches.json`은 개별 변경 좌표와 캐릭터별 이유, 원작 참조 경로를 기록합니다. `manifest.json`은 수정 전 Git 커밋과 전후 해시, 허용 픽셀 마스크를 기록합니다. 원래 이미지 생성 원본과 프롬프트는 종전 아트 폴더에 보존하며, 생성 기록의 `faceRefinement`에 이후 보정 단계를 연결했습니다.

세레스의 차가운 눈매와 닫힌 입을 확인할 때 built-in imagegen으로 얼굴 보정 가이드를 만들었습니다. 이 가이드는 기존 스프라이트와 공식 일러스트를 입력으로 사용했으며, 전체 생성 그림으로 런타임 이미지를 교체하지 않았습니다. 최종 리소스에는 원래 격자의 검토한 눈·입 픽셀만 적용했습니다. [가이드 프롬프트와 제작 기록](design-guide.json)을 참고하세요.

```powershell
python Tools/ApplyFaceRefinements.py
python Tools/VerifyFaceRefinements.py
```

적용 도구는 수정 전 Git 객체에서 다시 시작하므로 여러 번 실행해도 대비를 중첩 적용하지 않습니다. 별도 검증 도구는 183종의 크기·격자·알파·수정 마스크 밖 픽셀·메타데이터·생성 원본 보존과 현재 인덱스 해시를 검사합니다. 자동 수치 검증은 닮음이나 가독성을 판정하지 않으며, 그 부분은 원작 참조와 전후 대조표로 직접 검토합니다.
