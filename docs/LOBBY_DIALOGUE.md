# 니아의 로비 대사

확인일: 2026-10-12. 대사는 원작 대사를 옮긴 것이 아니라 이 팬 게임을 위해 새로 썼다.

## 구성과 말투

총 48개이며 게임 팁 36개와 농담·응원 12개를 무작위로 표시한다. 한 대사는 최대 56자다. 실제 로비의 430×136 말풍선 안에서 388×58 대사 영역과 13 크기의 Galmuri 글꼴로 모두 측정했다.

니아가 게임으로 사람과 소통하는 성격을 바탕으로 짧은 반말, 손패·콤보·스테이지 비유, 가벼운 승부욕을 사용한다. 상대를 얕잡아보거나 실패를 조롱하는 표현은 피한다. 원작의 상실 경험은 농담 소재로 삼지 않는다. ‘연구원님’이라는 공식 호칭은 확인하지 못했으므로 이 팬 게임의 동료인 ‘하나’라고 부른다. 이 호칭과 도움을 주는 상황은 팬 게임의 창작 설정이다.

팁은 현재 코드와 맞춰 작성했다. 시작 최대 코스트, 보상 카드 선택, 보관·무료 연계, 무기·패시브, 치명타, 시작 리롤, 모닥불, 상점, 드롭, 필드·설명, 장비, 보스·약속, 연구·레어 조우, 강화, 모드 해금을 다룬다. 노말 탈출로 하드가 열리고 하드 탈출로 무한이 열린다. 하드의 적 체력은 25%, 직접 피해는 10% 증가한다. 무한은 3막 주기마다 강화되며 보스 처치의 최대 코스트 증가는 합계 +6이 상한이고 조우 보너스는 별도다. 이미 노말을 클리어한 옛 저장은 하드가 열리는 이전 규칙을 따른다.

## 순환과 상태 분리

`LobbyDialogue.Lines`는 외부에서 수정할 수 없는 읽기 전용 목록이다. `At(index)`는 음수와 정수 경계값을 안전하게 정규화한다. 실제 UI는 `LobbyDialogueShuffle`의 전용 System.Random으로 Fisher–Yates 셔플한 목록을 사용한다. 모든 대사가 한 번씩 나온 뒤 다시 섞고, 새 묶음의 첫 대사가 직전 대사와 같으면 교환한다. 첫 대사도 무작위다. 기존 `NextIndex`는 목록 조회 호환용이며 UI에서 사용하지 않는다.

이 클래스는 원정, 영구 프로필, 파일 저장, `GameEngine` 및 Unity 난수에 의존하지 않는다. 대사를 읽거나 클릭해도 원정의 난수 상태와 다음 조우가 바뀌지 않는다. 게임 플레이 팁에는 실제 `GameEngine`, `ResearchProgression`, `RareEncounterRules`, `RunModes`의 수치와 해금 규칙을 대조하는 테스트를 둔다. UI 실측은 문자열 길이 검사와 별도로 수행한다.
