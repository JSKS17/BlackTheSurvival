# v0.1.3 디버프 설명 검증

디버프를 부여하는 카드의 전체 설명은 마지막에 `디버프 설명`을 표시한다. 카드 데이터의 직접 중독·약화·취약, 즉시·조건부·다음 일반 공격·설치물 상태이상, 출혈·화상 경로를 검사한다. 같은 디버프를 여러 번 부여하더라도 정의는 한 번만 출력한다. 요약과 디버프를 부여하지 않는 카드에는 정의를 붙이지 않는다.

현재 392장 중 디버프 카드 225장이 출혈·화상과 상태이상 20종을 부여한다. 현재 카드에 직접 중독·약화·취약이 남아 있지 않아 해당 경로는 독립 사례로 검증했다. 현재 데이터에 없는 매혹·무장 해제도 별도 사례로 검사한다. [설명 도감](../DESCRIPTION_SUMMARIES.md)에 카드별 정의를 보관한다.

- 설명 감사 **34,874개 검증 통과**: 종류별 정의 누락·중복, 맨끝 순서, 요약 오염, 조건부·지연·다음 공격 발동을 모든 카드에서 검사했다.
- 설명의 수치가 실제 규칙 API와 일치하는지 검사했다. 군중 제어의 코스트 감소, 실명·치유 감소·피해 배율, 같은 상태의 기간 갱신, 턴 종료의 기간 감소, 출혈·화상의 재부여와 만료를 확인했다.
- 수면·빙결의 해제 문구는 기존 구현이 해제를 처리하는 공격 카드 및 카드 필드 효과의 체력 피해로 범위를 명확히 했다. 전투 처리와 밸런스는 변경하지 않았다.
- 실제 Unity 런타임 컴파일을 통과했다. Windows 개발 빌드는 기존 화면과 새 디버프 하단·요약·디버프 없음·적 카드 화면을 합쳐 **80개 화면**을 검사한다. 카드 요약 **4,704개 배치**에서 넘침과 내부 스크롤이 없는지도 확인한다.
- 개발·배포 빌드 로그와 소스 복사본 해시를 보관한다. 배포 설치는 개인 저장을 보존하고 실행 파일 해시·시작 창·런타임 오류를 확인한다. ZIP은 설치한 런타임 전 파일과 CRC·SHA-256을 비교한다.

이번 변경은 설명 출력에 한정하므로 전투 밸런스 자동 플레이 평가는 다시 실행하지 않았다. 이전 버전의 저장과 배포를 유지한다. 개인 저장과 인증 정보는 소스 및 ZIP에 포함하지 않는다. GitHub 커밋·업로드 검증의 임시 기록은 `Temp/`에만 저장하여 검증 기록과 커밋의 순환 참조를 피한다.
