# 장비와 실험체 로드아웃

장비는 원본의 전설·초월 아이템 47종이며, 무기는 실험체가 사용하는 23개 무기군을 모두 지원한다. 원본의 고유 효과를 턴제 트리거로 바꾸고 수치는 별도로 조정했다. 같은 장비를 두 개 장착해도 기본 능력치는 더해지지만 같은 장비의 고유 효과는 한 번만 발동한다. 서로 다른 장비·패시브·룬이 주는 카드 추가 피해는 기존 공통 상한을 따른다.

## 원본 효과의 변환

| 원본 장비 효과 | 이 게임의 행동 |
|---|---|
| 레바테인의 발화 | 기본 공격 적중 후 2턴 동안 타오르는 고통 피해를 준다. |
| 알타이르·프라가라흐·로이거 차르의 가벼운 발걸음 | 이동 기술 사용으로 수치가 증가하고, 기본 공격으로 추가 피해를 주며 소모한다. 최대 수치에서는 둔화를 부여한다. |
| 저거너트·원더풀 투나잇의 열정 | 기본 공격으로 열정을 증가시키며 완성된 열정은 공격을 강화한다. |
| 타이탄 아머·택티컬 바이저의 전자기 충격 | 세 번째 기본 공격을 강화한다. |
| 큐브 워치의 타임 엣지 | 기본 공격 적중 후 마지막 Q·W·E 카드의 다음 코스트를 1 줄인다. |
| 스카디·여제·만년한파의 한파 | 스킬 적중 시 둔화를 부여한다. |
| 울트라비전·천사의 고리의 의념 | 어느 실험체의 기술이든 사용하면 다음 기본 공격을 강화한다. |
| 생사부의 저주·둠스데이의 파열 | 스킬 적중 후 남긴 효과가 자신의 턴 종료에 폭발한다. |
| 레이더의 포톤 런처 | 세 번째 기본 공격에 추가 피해와 회복을 준다. |
| 아오자이의 유예 | 방어도로 막은 뒤 받는 체력 피해의 20%를 다음 세 번의 자신의 턴 시작에 나누어 받는다. 미룬 피해는 저장되며 방어도를 무시한다. 전투가 끝나면 사라진다. |
| 오토-암즈·헤르메스의 방해 효과 저항 | 제어 효과로 감소하는 최대 코스트를 1 완화한다. 여러 저항 장비의 완화는 합계 1까지 적용한다. 침묵·속박 같은 카드 사용 제한을 제거하지는 않는다. |
| 치유 감소 | 원작에 치유 감소가 있는 장비는 적중 후 같은 상태이상을 부여한다. 다른 치유 감소와 더하지 않고 가장 높은 효과를 적용한다. |

그 밖의 장비는 원본의 생명력 흡수, 연장 총열, 후속타, 재생의 일격, 예열, 충전 등을 따른다. 정확한 수치는 `GearDef.mechanics`에 있으며 장비 상세 창에서 자동 생성한다. 원본의 이동 거리는 이동 카드 사용으로, 초 단위 재사용 제한은 턴 단위 제한으로 변환했다. 한 명의 적과 싸우는 구조에 따라 광역 효과의 대상 수는 늘리지 않는다.

## 무기 D 지급과 알렉스

무기를 장착하면 해당 무기군의 D 카드 1장이 덱에 자동으로 들어간다. 무기를 두 개 장착하면 카드도 두 장이다. 장비 교체 시 지급 기록 weaponGrantedCards에 있는 수만 제거한 뒤 새 장비 카드를 지급한다. 보상·이벤트·기존 저장으로 얻은 D 카드의 수는 유지된다. 이전 저장은 기존 장착 무기가 지급한 수만 한 번 추정해 기록하며, 무기가 없던 저장의 D 카드는 전부 보존한다.

알렉스의 잠입 패시브가 있으면 각 무기마다 다른 무기군의 D 카드 1장을 추가로 받는다. 알렉스의 원본 무기군인 톤파·양손검·암기·권총 중 현재 장착 무기군을 제외하고 장착 순서에 따라 선택한다. 같은 무기 두 개도 각각 추가 카드를 받는다. 패시브를 다른 것으로 교체하면 추가 카드만 사라지고 장착 무기의 기본 지급은 유지된다. 이 선택은 난수를 소모하지 않으며 저장 후에도 같다.

## 적 실험체

모든 적은 레벨에 따라 열리는 자신의 Q·W·E·R과 기본 공격 3장, 경계 1장, 원본 무기군의 D 1장, 전투마다 배정되는 F 1장을 사용한다. F 배정은 저장되며 행동 예고를 반복해서 열어도 바뀌지 않는다. D·F는 처음부터 사용할 수 있으며 초반에는 원형 피해·방어·회복의 55%에서 시작해 레벨 10에 100%에 도달한다. 카드 코스트는 그대로이므로 초반의 큰 기술에도 기회비용이 있다.

적 자신의 패시브는 기존 공통 트리거 체계로 실제 발동한다. 기본 공격이 추가되므로 아이작의 세 번째 공격 회복, 수아의 기술 후 기본 공격 강화 같은 효과가 적에게도 적용된다. 야생동물은 이 실험체 로드아웃이나 장비를 사용하지 않는다.

| 실험체 레벨 | 일반 실험체 장비 | 보스 장비 |
|---|---:|---:|
| 1–7 | 없음 | 2부위 |
| 8–9 | 무기 1부위 | 2부위 |
| 10–13 | 무기 1부위 | 3부위 |
| 14–15 | 3부위 | 3부위 |
| 16–17 | 3부위 | 5부위 |
| 18–20 | 5부위 | 5부위 |

장비 무기군과 D는 항상 일치한다. 적의 장비는 실제 공격력·방어도·체력·회피와 고유 트리거에 적용되며 상태와 함께 저장한다. 초월 장비는 레벨 17부터 나온다. 이전 저장에서 진행 중이던 적 행동과 카드 더미를 그대로 보존하고 새 전투부터 새 로드아웃을 적용한다.

## 시작 카드와 드롭

새로운 시작 선택지에는 코스트 5 이상 카드가 나오지 않는다. 이미 선택한 카드는 리롤해도 원래 위치와 선택 상태를 유지하고 나머지 세 칸 이상만 다시 뽑는다. 패시브 변경은 같은 저장된 추첨을 다시 가중해 난수 소모 없이 반영한다. 저장 후 리롤 결과도 동일하다. 이전 저장에서 이미 선택한 카드의 코스트가 높아진 경우에는 기존 선택을 보존한다.

오브젝트 드롭은 늑대 35% → 25%, 곰 50% → 35%, 키오스크 주변 실험체 35% → 25%로 줄였다. 드롭 종류의 제한과 보스의 확정 제작 재료 보상은 유지한다.
