# 원작 대표 소품 대조 QA

검토는 생성 원본을 읽고 원작 기본 스킨, 캐릭터별 무기군, `character-props.json`의 대표 소품과 비교하는 방식으로 진행합니다. 생성 이미지와 게임 Assets는 이 검토 작업에서 직접 수정하지 않습니다.

현재 확인한 01~12 시트 중 중요 오류와 해결 상태:

| 시트 | 캐릭터 | 확인한 문제 | 전달·확인 상태 |
|---|---|---|---|
| 02 | 니키 | 발광 기기를 들고 있어 격투 캐릭터의 주먹을 대체함 | 재생성 뒤 주먹·글러브로 바뀐 것을 확인함 |
| 02 | 다니엘 | 재단사의 가위 대신 보라색 마법책을 듦 | 재생성 뒤 열린 은색 가위로 바뀐 것을 확인함 |
| 03 | 라우라 | 채찍 대신 비앙카와 유사한 펼친 양산을 듦 | 재생성 뒤 보라·검정 채찍으로 바뀐 것을 확인함 |
| 03 | 레녹스 | 낚싯줄 채찍이 보이지 않음 | 재생성 뒤 끝에 갈고리가 달린 낚싯줄 채찍을 확인함 |
| 03 | 레온 | 수영·격투 캐릭터가 등에 악기 케이스 같은 물건을 멤 | 재생성 뒤 해당 물건이 사라지고 주먹을 드는 것을 확인함 |
| 03 | 로지 | 쌍권총이 보이지 않음 | 재생성 뒤 양손의 검은 권총을 확인함 |
| 03 | 루크 | 청소용 빗자루 대신 렌치를 듦 | 재생성 뒤 넓은 솔의 빗자루로 바뀐 것을 확인함 |
| 03 | 리오 | 활 대신 카메라·수류탄 같은 물체를 듦 | 재생성 뒤 활과 시위를 확인함 |
| 04 | 마커스 | 도끼·망치 머리가 드러나지 않아 검처럼 읽힐 수 있음 | 재생성 뒤 넓은 은회색 도끼 머리를 확인함 |
| 05 | 아이작 | 등 뒤 검은 막대의 옆 손잡이가 약해 검처럼 읽힐 수 있음 | 원작도 등 뒤 검은 막대 구도이므로 남은 모호함을 낮은 우선순위로 기록함 |
| 07 | 이안 | 단검 대신 책을 듦 | 재생성 뒤 은색 단검과 뒤편 귀신 그림자를 확인함 |
| 12 | 세레스 | 대검 끝이 시트 오른쪽 경계에서 잘림 | 마지막 셀 안에 무기 전체가 들어오도록 수정 요청 전달함 |

05~07의 다른 대표 소품은 중요한 캐릭터 혼동 없이 맞습니다. 쇼이치의 단검, 시셀라의 IV·구체, 아델라의 체스말, 아드리아나의 화염 탱크, 에스텔의 도끼·방패, 에키온의 VF 의수, 윌리엄의 야구공·글러브, 일레븐의 망치, 카밀로의 쌍검, 칼라의 석궁을 확인했습니다.

클로에·니나의 전신 기본 원화는 [공식 Steam 발표](https://store.steampowered.com/news/app/1049590/view/3044989230676877444)에서 추가 확인했습니다. 니나는 회색·베이지 긴 양갈래 머리, 흰·연보라 머리 리본, 흰 프릴 드레스와 연보라 리본, 검은 기계식 칼날 다리를 가진 작은 인형입니다. 클로에는 손가락에 연결한 인형실로 조종합니다. `references/chloe_nina_full.png`와 대표 소품 JSON에 반영했습니다.

08 시트: 캐시의 메스·의료 파우치, 클로에의 손가락 인형실과 기본 니나, 키아라의 검은 레이피어, 타지아의 유리조각, 테오도르의 저격총, 펠릭스의 창, 프리야의 파란 꽃 기타, 피오라의 은색 레이피어를 확인했습니다. 대표 소품의 중요한 혼동이 없습니다.

09 시트: 피올로의 쌍절곤, 하트의 붉은 전기기타, 헤이즈의 대형 총, 데비&마를렌의 파란·빨간 대검, 아르다의 돌 유물·두루마리, 아비게일의 푸른 도끼, 알론소의 자기장 주먹, 레니의 당근 총을 확인했습니다. 두 자매는 한 셀 안에 함께 있으며 서로 다른 색으로 읽힙니다.

10 시트: 츠바메의 수리검, 케네스의 도끼, 카티야의 저격총, 다르코의 방망이, 르노어의 기타, 가넷의 가시 방망이, 유민의 부채, 히스이의 카타나를 확인했습니다. 원작 무기군과 대표 소품에 맞습니다.

11 시트: 유스티나의 기계 석궁, 이슈트반의 긴 창, 슈린의 에너지 레이피어, 헨리의 회중시계와 시곗바늘 투척검, 블레어의 쌍검, 미르카의 사각 망치, 펜리르의 검정·주황 주먹, 코렐라인의 분홍 수정 아르카나와 날개를 확인했습니다. 원작 무기군과 대표 소품에 맞습니다.

12 시트: 비형의 거대 기계 망치, 크레이버의 검정·빨강 권총, 루치아의 은색·보라 장총, 세레스의 검정·금색 거대 대검을 확인했습니다. 소품의 종류는 맞으며, 세레스 검 끝의 잘림을 마지막 교정 항목으로 전달했습니다.
