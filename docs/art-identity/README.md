# 캐릭터별 얼굴 스프라이트

하나와 실험체 91명, 총 92개의 독립적인 160×160 RGBA 스프라이트다. 이전 픽셀몬 참고 스타일과 원본 이터널 리턴 일러스트를 함께 참고하여, 캐릭터별 눈매·눈썹·표정·안경·마스크·연령 차이를 지정했다. 확대에는 최근접 보간을 사용하며 게임에서는 얼굴 정보가 손실되는 80픽셀 축소를 적용하지 않는다.

- [런타임 PNG 및 생성 원본 색인](asset-index.json)

런타임 파일은 `Assets/Resources/Lumia/PortraitsIdentity/`에 있다. 기존 스프라이트는 보존하며 새 스프라이트를 우선 불러온다. QA 이미지는 생성 원본의 자르기·패딩·최근접 확대만 수행한 검토 자료다.
