# 캐릭터 얼굴을 구분하는 도트 스프라이트

새 스프라이트는 `Assets/Resources/Lumia/PortraitsIdentity`에 저장합니다. 이전 `Portraits`와 `PortraitsCoarse`는 원본과 비교용으로 보존합니다. 각 파일은 투명 RGBA 160×160 논리 캔버스이며, 캐릭터의 외곽을 맞춘 뒤 최근접 보간으로 배치합니다. 게임에서는 이 파일을 80픽셀로 다시 축소하지 않습니다.

이전 대화 **모에몬 이미지 문제**에서 모에몬 스프라이트 규칙을 참고한 기록과 64×80 측면 이미지 요청을 찾았습니다. 해당 대화의 실제 이미지는 읽기 결과에 포함되지 않았습니다. 그 개별 측면 구도를 현재의 모든 캐릭터에 적용하지 않고, 휴대용 도트 전투 스프라이트의 선명한 외곽선·색 덩어리·분명한 눈과 표정 표현을 적용했습니다. 현재 게임의 전체 몸, 의상과 대표 소품은 유지합니다.

얼굴은 원작 기본 일러스트를 보고 따로 설계했습니다. `face-designs.json`에 92명의 눈매, 눈동자 색, 눈썹, 입, 표정과 얼굴을 가리는 특징을 기록했습니다. 예를 들어 니아는 반쯤 감은 눈과 풍선껌, 재키는 치켜뜬 붉은 눈과 비대칭 웃음, 수아는 둥근 초록 눈과 따뜻한 미소, 아이작은 눈가 주름과 콧수염·턱수염으로 구분합니다. 알렉스의 선글라스, 마르티나의 안대, 알론소의 가면처럼 의도적으로 얼굴을 가리는 특징도 보존합니다.

생성에는 내장 `image_gen`을 사용하며, 캐릭터마다 원작 이미지를 넣어 독립적으로 한 번씩 호출합니다. `prompts`에는 실제 프롬프트와 얼굴 지시, `generation`에는 참조 URL과 참조·생성·최종 파일 해시를 기록합니다. `generated`에는 생성 원본을 저장합니다. `Tools/PrepareIdentityPortraits.py`는 크롭·최근접 크기 변경·투명 여백·검증 시트 생성만 수행하며 그림이나 얼굴을 직접 수정하지 않습니다.

원작 참고 이미지: `docs/art-chibi/reference-characters.json`과 `docs/art-chibi/references/subjects`. 참조는 님블뉴런 공식 일러스트와 원작 공개 게임 에셋을 포함하며, 구체적인 출처는 각 생성 기록의 `originalSourceUrl`에 남깁니다. 새 스프라이트는 비공식 팬 게임용으로 다시 그린 도트 그림입니다.
