# 스프라이트 검토 기록

최종 상태: **92명 완료, 누락 0, 기술 검사 오류 0**. 최종 전체 몸 시트 8장과 얼굴 확대 시트 8장을 모두 직접 확인했습니다. 생성 원본 해시 중복 0, 최종 리소스 해시 중복 0, 원작 참조·생성 원본·최종 리소스의 해시 불일치 0, 실제 프롬프트 기록 불일치 0입니다. 검사 결과는 `validation.json`에 저장되어 있습니다.

원작 참조 시트 12장을 모두 확인한 뒤, 92명의 얼굴을 `face-designs.json`에 따로 기록했습니다. 한 가지 눈매나 미소를 일괄 적용하지 않고, 원작의 눈꺼풀 기울기·눈동자 색·눈썹·입 모양·얼굴 가림과 연령 표현을 지정했습니다.

첫 시안 네 명과 후속 스프라이트의 확대 시트를 검토했습니다. 니아의 졸린 눈과 풍선껌, 재키의 치켜뜬 눈과 웃음, 수아의 둥근 눈과 따뜻한 표정, 아이작의 주름과 수염이 구분됩니다. 후속 검토에서는 아야의 안경, 현우의 찡그린 눈썹과 코 밴드, 유키의 차분한 눈, 혜진의 무표정, 나딘의 모자 그늘, 나타폰의 한쪽 눈, 니키의 도전적인 표정, 다니엘의 가늘고 냉랭한 눈을 확인했습니다.

`contact-sheets`는 전체 몸·의상·대표 소품을 확인하는 시트이고, `face-sheets`는 같은 최종 PNG의 윗부분을 최근접 보간으로 확대하여 얼굴을 확인하는 시트입니다. 확대 시트 자체는 게임 리소스로 사용하지 않습니다. 생성 원본은 보존하며, 리소스 파일에는 그림 수정이나 얼굴 합성을 적용하지 않았습니다.

기술 검증은 `validation.json`에 현재 진행 상태를 기록합니다. 160×160 RGBA, 실제 투명 픽셀과 완전 불투명 픽셀의 존재, 저장된 파일 해시를 확인합니다. 검사 때마다 누락된 캐릭터도 함께 기록하므로 진행 중인 상태와 완료 상태를 구별할 수 있습니다.

후반 캐릭터의 검토에서는 이렘의 주황/파랑 이색 눈, 카밀로의 남성 얼굴과 물색 눈, 프리야의 피부와 밝은 눈/미소, 피오라의 녹색 눈, 알론소의 기계 가면과 황금 눈, 카티야의 안경과 큰 눈, 다르코의 눈가와 코, 가넷의 날카로운 붉은 눈, 히스이의 크게 열린 입, 코렐라인의 비대칭 머리/눈, 비형의 윙크, 크레이버의 붉은 렌즈, 루치아의 큰 청색 눈, 세레스의 낮게 깔린 눈을 확인했습니다. 클로에는 원작 니나 인형 자료를 추가로 사용했고, 인형이 본체의 얼굴을 가리지 않습니다. 니나 자료의 경로와 해시도 해당 생성 기록에 남겼습니다.

게임에서의 확대/배치 확인은 별도 Unity 실제 화면 검증에서 수행합니다. 스프라이트를 80픽셀로 다시 축소하지 않고 Point 필터로 표시해야 이 검토 시트에서 확보한 얼굴 표현이 유지됩니다.
