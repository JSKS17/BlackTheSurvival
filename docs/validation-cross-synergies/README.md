# v0.1.7 실험체 간 연계 검증

검증 환경: Windows, Unity 6000.3.11f1. 구현 조합과 수치는 [교차 연계 문서](../CROSS_SUBJECT_SYNERGY_PLAN.md)에 기록한다.

- [게임 규칙](core-tests.log): **54개 시나리오·57,676개 단언 통과**. 91명 각각의 단독 Q/W/E/R에서 원래 자원과 효과를 보존하고, 8종 조합은 실제 `PlayCard`로 확인한다. 실제 지불 코스트·무료 소비·준비 만료·생성 및 소비 한도·공유 추가량 상한·양측 분리·미리보기 불변·저장 재개·적 연속 예고와 실제 처리의 일치를 검사한다.
- 설치 조건 불충족과 효과 공간 부족은 준비를 소비하지 않는다. 같은 살아 있는 폭탄을 갱신해도 외부 강화가 누적되지 않으며, 로지 Q/W/E 조기 기폭은 저장된 강화분을 이전하고 원래 지연 폭발을 제거한다.
- [설명 감사](description-audit.log): **37,838개 단언 통과**. 카드 392장·패시브 91종·룬 16종·장비 51종을 검사한다. 연계 카드의 조건·수치·기간·상한은 전체 설명에 각각 한 번 포함하며, 짧은 카드 미리보기의 5줄 예산과 디버프 해설의 마지막 위치를 유지한다.
- [런타임 컴파일](runtime-compile.log)과 [Windows 개발 빌드](development-build.log)가 통과했다. 실제 개발 플레이어의 [121개 화면](native-screens.json)에는 신규 연계 화면 26개가 포함된다. 8종 각각의 준비·발동·전체 설명 및 VF·폭탄 요약을 확인했다. 실제 글꼴로 카드 미리보기 **4,704개 배치**와 연계 화면 **26개의 출처 아이콘·텍스트 높이** 검사가 모두 통과했으며, 실행 오류·본문 넘침은 0개다. [새 연계 화면](native-ui/)과 [소스·빌드 복사본의 일치 해시](build-source-hashes.json)를 보존한다.
- 기존 v0.1.6과 변경 후를 동일한 40개 seed·고정 정책으로 자동 플레이하여 비교했다. 변경 전은 탈출 **1회·패배 39회·정체 0회**, 변경 후는 탈출 **2회·패배 38회·정체 0회**다. 전투 HP·난수·상대 상태를 바꾸지 않는 정책이며 사람의 승률이나 모든 덱 조합의 난도 추정은 아니다. [변경 전 로그](balance-before.log), [변경 후 로그](balance-after.log)를 보존한다.
- 배포 소스·설치 파일 해시, 정상 실행, 개인 이어하기 저장 보존과 ZIP 전 파일의 CRC·SHA-256을 검사한다. 개인 저장 백업과 GitHub 인증·업로드 검증 출력은 추적하지 않는 `Temp/`에만 보관한다.

최종 [배포 빌드](release-build.log)는 오류 0개로 성공했다. 설치한 실행 파일·Unity 런타임·어셈블리·리소스의 [SHA-256](release-hashes.json)은 배포 출력과 모두 같다. 정상 실행과 개인 저장 보존은 [시작 검사](release-startup.json), ZIP 파일 목록·CRC·해시는 [아카이브 검사](archive-validation.json)에 기록한다. 배포 버전은 `v0.1.7`이며 이전 버전의 배포도 유지한다.

검증 플레이어는 전용 저장 슬롯을 사용한다. 일반 플레이의 개인 이어하기 저장은 업데이트에 포함하지 않는다.
