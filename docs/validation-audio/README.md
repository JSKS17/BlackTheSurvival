# v0.1.10 사운드 검증

[사운드 구성과 출처](../AUDIO.md)는 원본 OST·한국어 보이스와 별도 제작 효과음을 구분한다. 총 421클립은 OST 3개, 원본 캐릭터 보이스 349개(기술 339·니아 상황 10), 아나운서 4개, 프로젝트 제작 효과음 65개다.

[파일·출처·라우팅 검사](catalog-audit.json)는 15,780개 검증을 통과했다. 원본 또는 생성기 출처, SHA-256, 가져오기 설정, WAV 전체 샘플의 무음·클리핑과 447개 큐·392개 카드의 명시적 배정을 확인했다. 게임 난수를 소비하지 않는다. [효과음 재생성 검사](designed-check.log)에서 65개 파일 바이트가 모두 일치했고 최대 피크는 0.819977이었다.

[네이티브 오디오 검사](native-audio.json)는 Unity가 가져온 421클립의 형식·디코딩과 실제 AudioListener 믹서 출력을 사용하여 **3,119개 검증·믹서 측정 46개·오류 0개**로 통과했다. 스트리밍 음악 3개는 실제 재생으로 확인하고 나머지 418개는 PCM 디코딩도 확인했다. 10개 화면 음악, 상황 효과음, 플레이어·적 기술, 야생동물 5종, 실제 UI의 구매·제작·요리, 모닥불 반복음, 동시 재생 제한, 중복 억제, 음소거·음량·일시정지와 설정 저장을 검사했다. 측정한 최대 믹서 피크는 0.533174였다. 운영체제 출력 이전의 게임 믹서 검사이며 물리 스피커 청취를 증명하지 않는다. [실행 로그](audio-player.log)에 결과가 있다. `-bts-audio-verify` 전후 개인 원정 저장과 일반 설정도 일치했다.

[런타임 컴파일](runtime-compile.log), [기존 핵심 게임 규칙](core-tests.log)의 56개 시나리오·58,251개 검증, [설명 감사](description-audit.log)의 37,914개 검증도 통과했다. 오디오 작업은 카드 효과·난수·보상 확률을 변경하지 않는다.

[개발 빌드](development-build.log)에서 생성한 Windows 플레이어로 [화면 131개](native-screens.json)와 카드 392종의 4,704개 배치를 검사하여 실행 오류·본문 넘침 0개로 통과했다. [음량 설정 화면](native-ui/audio_settings.png)을 직접 확인했고 카드 내부 스크롤 없음 규칙을 유지했다. [C# 소스](build-source-hashes.json)와 [모든 오디오 입력 파일](build-audio-hashes.json)의 빌드 복사본 SHA-256도 일치했다.

[배포 빌드](release-build.log)는 오류 0개로 성공했다. 설치한 실행 파일·런타임·어셈블리·리소스의 [해시](release-hashes.json)가 빌드 출력과 일치하고 [정상 시작과 개인 저장 보존](release-startup.json)도 통과했다. [ZIP 검사](archive-validation.json)에서 모든 항목의 CRC·SHA-256·필수 런타임 존재를 확인했다. 인증 정보·개인 저장·Unity 캐시·임시 다운로드는 소스나 ZIP에 포함하지 않았다.

배포 ZIP은 런타임 파일 181개·88,146,783바이트이며 SHA-256은 `b5a1f85b9be95dd871f29e3b18d7b44a2d04b53a0ab64dcec43f4cb712f4eb23`이다.
