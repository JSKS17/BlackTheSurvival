# v1.1.0 실험체 역할군 출처와 검증

게임에 구현된 실험체 **91명 전원**을 공식 홈페이지가 연결한 실험체 도감의 역할군과 대응했다. 무기, 기술 효과, 팬 위키의 평가로 역할을 추측하지 않았다. 최종 매핑은 [official-roles.json](official-roles.json)에 있으며 게임에는 이 자료에서 생성한 카탈로그를 내장한다. 플레이 중 외부 도감이나 API에 접속할 필요는 없다.

## 출처

1. [이터널 리턴 공식 홈페이지](https://playeternalreturn.com/main?hl=ko-KR)의 **게임 → 실험체** 메뉴는 [네이버 게임 실험체 도감](https://game.naver.com/lounge/Eternal_Return/db/character)으로 연결된다. 실제 연결 주소와 응답 해시는 [source-discovery.json](source-discovery.json)에 기록했다.
2. 도감이 불러오는 공개 스크립트에서 도감 API 경로를 확인했다. 로그인, API 키, 비공개 서비스는 사용하지 않았다. 탐색용 스크립트는 주소와 SHA-256만 남기고 정리한다.
3. [도감의 역할군 필터 정의](https://comm-api.game.naver.com/nng_main/v1/game/category/GM_670?mid=db&dataType=character)는 **탱커·전사·암살자·스킬 딜러·원거리 딜러·지원가**의 여섯 역할을 제공한다.
4. [전체 실험체 목록](https://comm-api.game.naver.com/nng_main/v1/game/db/character/GM_670/dataType/character?order=ranking&offset=0&limit=200)에서 91명을 확인하고, 여섯 역할별 필터 결과와 각 실험체 상세 응답의 `intro.filters`를 전수 교차 확인했다. 실험체별 페이지와 상세 API 주소는 최종 JSON의 `source`, `apiSource`에 들어 있다.

이 자료의 정확한 범위는 **공식 홈페이지가 안내하는 도감에 명시된 역할군**이다. 원작 클라이언트의 무기별 통계나 현재 메타에서의 역할을 별도로 추정한 자료가 아니다.

| 확인 항목 | 결과 |
| --- | --- |
| 게임 실험체 ID / 이름 | 91개 / 중복 없음 |
| 공식 연결 도감의 실험체 | 91명 |
| 이름 일치 / 누락 / 모호한 대응 | 91명 / 0명 / 0명 |

역할별 인원은 복수 역할을 각각 포함하므로 합계가 91보다 크다.

## 복수 역할 처리

도감이 한 실험체에 두 역할을 표시하면 둘 다 보존한다. 역할과 무기를 일대일로 연결하는 정보는 해당 응답에 없으므로 무기별로 분리하거나 하나의 역할을 임의로 우선하지 않는다.

| 공식 역할 조합 | 해당 실험체 |
| --- | --- |
| 탱커 · 전사 | 가넷, 마커스, 매그너스, 미르카, 에스텔 |
| 탱커 · 지원가 | 마이, 세레스 |
| 전사 · 암살자 | 슈린 |
| 전사 · 스킬 딜러 | 수아, 실비아, 이렘 |
| 스킬 딜러 · 원거리 딜러 | 나딘, 아야, 아이솔, 크레이버 |
| 스킬 딜러 · 지원가 | 아디나, 아르다, 프리야 |
| 원거리 딜러 · 지원가 | 테오도르 |

## 원본 필드 오류 두 건

알론소 상세 응답에는 `역할군`이라는 이름 아래 무기명 **글러브**, 가넷 상세에는 **방망이**가 섞여 있다. 무기명을 역할로 해석하지 않고 공식 카테고리가 제공하는 여섯 역할 값만 추출했다. 알론소의 **탱커**, 가넷의 **탱커·전사**는 각각의 역할 필터 조회 결과와도 일치한다. 원래 필드 값은 상세 검증 증거에 보존했다.

## 보존 자료

- [official-roles.json](official-roles.json): 게임 ID, 실험체명, 역할 배열, 공식 연결 도감과 API 주소.
- [official-db-character-index.json](official-db-character-index.json): 원작 도감의 이름·객체 ID 및 원응답 해시.
- [official-db-role-membership.json](official-db-role-membership.json): 여섯 필터의 대상 목록, 조회 주소, 원응답 해시.
- [official-role-detail-evidence.json](official-role-detail-evidence.json): 91명 상세의 원래 역할·무기 필드와 원응답 해시. 불필요한 소개문·이미지·기술 설명은 저장하지 않았다.
- [validation.json](validation.json): 전수 일치 결과, 게임 로스터 소스 해시, 복수 역할과 원본 필드 오류.
- [FetchOfficialRoles.mjs](FetchOfficialRoles.mjs): 추출과 교차 확인 스크립트. 기존 결과를 덮어쓰지 않도록 구성했다.

조회 시각은 각 JSON의 UTC 기록을 따른다. 향후 원작의 공식 도감 분류가 변경되면 새로운 버전에서 다시 수집·검증해야 한다.
