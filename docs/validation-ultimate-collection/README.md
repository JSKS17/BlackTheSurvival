# 필살기 애니메이션 시안 검증

이 검증은 게임과 별개인 HTML 갤러리와 아트 파일을 대상으로 합니다. Unity 빌드·게임 저장·런타임 스킬 동작은 변경하지 않았습니다.

`collection-validation.json`은 91명의 로스터 일치, 원본·재생 파일 해시, 12프레임과 1.5초 반복, 프레임별 투명도, 새 90종의 생성 원본 보존과 게임 파일 변경 여부를 확인합니다. 실험체별 `Subjects/ID/validation.json`에는 실제 추출 영역, 위치 보정, 원본 RGBA 보존과 WebP 무손실 검증이 있습니다.

`art-boundary-review.json`은 새 90종·1,080프레임의 내부 추출 경계에 불투명 픽셀이 과도하게 닿는지 확인합니다. 초기 고정격자 분할에서는 513개 경계가 후보였고, 셀별 여백 추출과 시트 수정 후 최종 후보는 0입니다. 경계 검사는 잘림을 찾기 위한 보조 검사이며 별도의 시각 검토도 함께 기록했습니다.

`gallery-browser-validation.json`은 실제 Chrome에서 모든 실험체 선택과 12프레임 표시, 원본 이미지 로딩, 다운로드 링크, 이름·영문 ID·R 검색, 빈 검색 결과, 재생·정지·이전·다음·속도, 직접 링크와 375px 모바일 배치를 검사한 결과입니다. `gallery-*.png`는 브라우저에서 직접 저장한 화면입니다.

원본 시트는 제작 시 실험체별로 얼굴·복장·소품·R 모션을 검토했습니다. 프레임 경계가 복잡한 아비게일·비형·라우라·매그너스·켈네스·이스토반·실비아는 추출 후 추가 검토했습니다. 라우라·비형·가넷·나딘은 내장 이미지 생성 도구로 효과가 셀 안에 들어오도록 수정했습니다. 기계 검증은 그림의 모든 해석이나 취향을 보증하지 않으며, 이 자료는 게임 적용 전 확인용 시안입니다.
