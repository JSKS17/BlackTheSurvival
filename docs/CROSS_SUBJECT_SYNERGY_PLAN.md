# 다른 실험체 카드 간 연계

v0.1.7부터 전투에 적용한 8종 연계다. 기존 설계안의 VF 조합은 **에키온·블레어**, 폭탄 조합은 **아이솔·로지·셀린·테오도르**로 수정했다. 니아와 엠마의 고유 스킬은 그대로 유지한다. 아래 수치는 이 팬 게임의 턴제 전투용 수치이며 원작 피해량을 의미하지 않는다.

## 적용 조합

| 연계 | 준비 | 소비와 효과 |
|---|---|---|
| VF 공명 | 코스트를 지불한 에키온 카드가 VF를 실제로 얻거나, 블레어 카드가 VF 추적력을 얻거나 형태를 전환하면 각자의 공명을 준비한다. | 두 실험체의 공명을 모두 준비한 뒤 에키온·블레어 W를 사용하면 방어도 3을 더한다. 에키온 R 적중은 피해 4, 블레어 R 적중은 피해 6을 더한다. 두 공명을 소모한다. |
| 폭파 연계 | 아이솔 Q/R, 로지 R의 새 폭탄 설치, 셀린 Q의 실제 플라즈마 폭탄 획득, 테오도르 Q의 새 에너지 포·E의 적중·W의 새 증폭 스크린을 코스트를 지불해 사용한다. | 다른 실험체의 준비를 소모한다. 아이솔 Q/R·로지 R·테오도르 Q의 지연 폭발 피해는 2 증가한다. 증폭 스크린에서 얻은 준비라면 3 증가한다. 셀린 Q는 플라즈마 폭탄을 추가로 1 얻는다. 아이솔 W·로지 Q/W/E·셀린 W·테오도르 E/R은 첫 적중 피해가 2 증가한다. 같은 폭탄을 다시 사용해 갱신해도 외부 강화는 최초 1회만 적용한다. |
| 기름 점화 | 아드리아나가 코스트를 지불해 실제 기름을 얻는다. | 케네스 W/R 또는 비형 W가 화염 효과를 만들 때 기름 1을 소모한다. 연계 기름 화재는 시전자의 턴 종료마다 방어도를 무시하는 피해 3을 2회 준다. 아드리아나의 고유 점화와 구분한다. |
| 상처 연계 | 캐시 외의 실험체가 코스트를 지불한 출혈 카드로 출혈을 남긴다. | 그 출혈이 남아 있는 동안 캐시의 Q/W가 적중하면 카드 처리가 끝난 뒤 상처를 추가로 1 얻는다. 현재 카드의 중상 조건에는 소급 적용하지 않는다. 기존 상처 상한 3을 유지한다. |
| 밀려난 위치 | 코스트를 지불한 다른 실험체의 넉백이 적중한다. | 매그너스 E 적중에 피해 4를 더한다. 매그너스 자신의 벽 압박이 있다면 외부 준비를 소비하거나 중복 적용하지 않는다. 외부 연계는 기절을 추가하지 않는다. |
| 기동 연계 | 라우라·레온·로지·실비아의 이동 카드를 코스트를 지불해 사용한다. | 이 네 실험체 중 다른 실험체의 공격 기술이 적중하면 첫 적중 피해를 2 더한다. 기본 공격은 준비를 소비하지 않는다. |
| 꽃과 나비 | 코스트를 지불해 프리야의 꽃 또는 바냐의 꿈을 실제로 증가시킨다. | 상대 실험체의 공격 기술 적중은 피해 2, W는 방어도 2, 프리야 R은 회복 2를 더한다. 원래 꽃·꿈은 소모하거나 공유하지 않는다. |
| 보호 지원 | 수아 W, 요한 W/R, 레니 Q/E, 샬럿 W/E를 코스트를 지불해 사용한다. | 다른 실험체의 해당 지원 카드가 준비를 소모한다. 회복 카드에는 회복 2, 방어 카드에는 방어도 2를 더한다. |

## 공통 제한

- 각 계열의 외부 효과는 **자신의 턴당 1회**, 준비 생성은 **계열별 턴당 2회**까지다. 준비는 생성한 턴과 다음 자신의 턴에 사용할 수 있고, 자신의 턴 시작을 두 번 지나면 사라진다.
- 외부 준비는 같은 소유자끼리 소비하지 않는다. VF 공명은 에키온과 블레어가 각각 준비해야 한다. 준비는 소유자별 1이며 기름은 최대 3이다.
- 외부 연계의 **즉시 추가 피해는 자신의 턴당 합계 6**, 추가 방어도는 6, 추가 회복은 4까지다. 원래 카드의 피해·회복 및 고유 자원은 이 추가량에 포함하지 않는다. 기존 기술 보너스 상한도 함께 적용한다.
- 폭탄 강화와 연계 기름 화재는 기존 **턴 종료 피해 합계 40**의 제한 안에서 처리한다. 같은 지연 폭탄의 외부 강화는 중복 누적하지 않는다.
- 로지의 강화된 부착 폭탄을 Q/W/E로 조기 기폭하면 저장된 강화분도 첫 적중 피해로 옮긴다. 이 강화분은 이번 턴의 즉시 추가 피해 예산 6을 사용하며, 별도의 준비나 계열 발동을 다시 소비하지 않는다. 원래 지연 폭발은 제거되어 나중에 재폭발하지 않는다.
- 설치 효과의 조건을 충족하지 못하거나 효과 공간이 가득 차 설치할 수 없으면 해당 준비를 소비하지 않는다. 지연 폭탄의 갱신은 새 준비를 만들지 않지만, 아직 외부 강화를 받지 않은 폭탄에는 최초 강화를 받을 수 있다.
- 실제로 코스트를 지불한 카드만 새 외부 준비를 만든다. 할인 후 0코스트 또는 무료 사용권을 쓴 카드는 원래 스킬의 자원·효과를 정상 처리하며, 이미 준비한 외부 효과는 소비할 수 있다.
- 다중 적중도 카드 사용 1회로 판정한다. 출혈·화상·설치물의 틱, 반격, 패시브가 대신 처리한 기술은 새 외부 준비를 만들지 않는다. 신규 연계에는 코스트 환급·추가 드로우·무료 사용권을 부여하지 않는다.
- 기존 실험체별 자원은 계속 별도로 저장한다. 예를 들어 니아의 아케이드 블록, 로지의 부착 폭탄, 셀린의 폭탄·융합, 에키온의 VF와 블레어의 추적력·형태는 합치지 않는다.

## 화면과 저장

카드의 짧은 미리보기는 기존 요약을 유지하며 공간이 허용될 때 해당 카드의 연계를 한 문장으로 덧붙인다. 연계 카드의 하단에는 상세 보기 안내가 표시된다. 상세 창의 요약·전체 설명에서 조건·효과·제한을 확인할 수 있으며 전체 설명의 디버프 해설은 계속 마지막에 표시한다.

전투의 **필드 효과**에서 양측의 준비 출처, 남은 지속 시간, 이번 턴 사용·생성 횟수, 추가 피해·방어·회복 예산을 확인한다. 출처 아이콘은 해당 카드의 상세 설명을 연다. 별도 분류 탭이나 장비 태그는 추가하지 않았다.

플레이어와 적의 실제 처리, 적 행동 계획·피해 예고에는 같은 연계 판정을 사용한다. 미리보기는 상태를 소비하지 않으며 저장·불러오기에는 준비와 제한을 함께 보존한다. 이전 버전의 저장에 새 연계 상태가 없으면 빈 상태로 시작한다.

## 검증

순수 규칙과 실제 전투 API로 8종 발동, 고유 자원 보존, 한국어 소유자 구분, 무료 소비·유료 생성, 턴 제한·만료, 다중 적중·반복 설치, 상태 복사, 양측 전투와 적 피해 예고를 검사한다. 설명 감사와 실제 Windows 실행 화면도 함께 확인한다. 결과와 재현 로그는 [연계 검증 기록](validation-cross-synergies/README.md)에 보관한다.
