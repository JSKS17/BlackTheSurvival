# 다른 실험체 카드 간 시너지 설계안

검토용 제안이다. v0.1.6에는 지도 보스 사전 표시만 적용하며, 아래 신규 시너지는 아직 구현하지 않는다. 모든 제안 수치는 첫 밸런스 시험값이다.

## 현재 구조와 목표

`SkillMechanics`는 자원을 실험체와 자원 키의 조합으로 보관한다. 니아의 VF 배터리와 에키온의 VF 게이지는 서로 다른 자원이다. 패시브 자원도 `trait:` 소유자로 분리된다. 현재도 다음 기본 공격 강화는 다른 실험체 카드에 적용되고, 아이솔 패시브는 다른 실험체의 설치 공격으로 발동한다. 다만 고유 자원을 쌓고 소비하는 카드 상당수는 같은 실험체의 카드만 요구하여 혼합 덱의 선택이 좁다.

고유 자원은 유지하면서 비슷한 성격의 행동이 다른 실험체의 연계를 조금 앞당기거나 보조하도록 만든다. 제작용 내부 분류에는 설치·VF 충전·점화·상처·밀치기 등을 사용하되, 게임에 분류 탭이나 태그 목록은 추가하지 않는다. 카드 설명에 실제로 생기는 연계만 적는다.

단순히 이름이나 키가 같은 자원을 합치지는 않는다. 예를 들어 아이솔의 `semtex`는 지연 폭발 설치물이고, 로지의 `semtex`는 자신의 기술로 기폭하는 부착 폭탄 상태다. 같은 키여도 적용 방식은 다르다. 변신 상태와 패시브 고유 자원도 기존 의미를 유지한다.

## 대표 연계

| 내부 성격 | 실제 카드 예시 | 제안 효과 | 고유 연계와 제한 |
| --- | --- | --- | --- |
| 설치 협력 | 아이솔 Q **셈텍스 폭탄** → 엠마 W **폭죽 모자** | 다른 실험체의 설치물을 새로 설치하면 기존 설치물 하나의 첫 폭발 피해가 2 증가한다. 반대 순서도 지원한다. | 설치물당 1회, 턴당 1회. 기존 설치물 갱신과 반복 타격은 발동하지 않는다. 지연 단축까지 동시에 주지 않는다. 실제 설치물인 카드만 명시적으로 지원한다. |
| VF 부분 호환 | 니아 Q **아케이드 드롭** → 에키온 Q **독사의 칼날** → 에키온 W **뒤집힌 비늘** | 서로 다른 실험체의 카드로 실제 VF 자원을 얻을 때 공명을 1씩 준비한다. 공명 2를 소모하면 다음 VF 소비 카드에 고유 자원 1에 해당하는 보조 효과를 더한다. 예시에서는 에키온의 자체 VF 1이 주는 방어도 3에 보조 방어도 3이 더해진다. | 소비자와 다른 실험체의 기여가 포함되어야 한다. 니아의 배터리는 그대로 남고 에키온의 실제 VF가 늘지는 않는다. 외부 기여 최대 1, 공명 생성 턴당 2, 소비 턴당 1. 지불 코스트가 있는 직접 사용만 생성한다. 이바 R 같은 0코스트 카드와 무료 재사용은 생성하지 않는다. |
| 기름 점화 | 아드리아나 W **기름 뿌리기** → 케네스 W **업화** | 다른 실험체의 지정된 점화 카드가 기름 1을 소모하여 피해 3을 2회 주는 기름 화재를 남긴다. | 턴당 1회. 아드리아나 자신의 기름 화재 피해 5×2회보다 낮게 설정한다. 추가 화재·화상 틱은 다시 점화하지 않는다. 모든 불꽃 연출 카드를 자동 지원하지 않는다. |
| 상처 연계 | 재키 Q **연참** → 캐시 W **앰퓨테이션** → 캐시 Q **동맥절제술** | 다른 실험체의 출혈이 남은 적에게 캐시 Q/W가 적중하면 카드 처리 후 상처를 추가로 1 얻는다. 재키 Q 뒤 캐시 W로 상처 2를 준비하고 다음 캐시 Q의 중상 연계를 앞당긴다. | 턴당 1회. 재키의 출혈과 캐시의 상처·중상은 각각 유지한다. 추가 상처는 현재 카드의 조건을 소급하여 충족시키지 않는다. 출혈 틱으로 상처를 생성하지 않는다. |
| 밀치기 후 압박 | 현우 E **선빵필승** → 매그너스 E **강타** | 다른 실험체의 넉백 적중이 1턴 동안 보조 위치 상태를 남긴다. 강타는 이 상태를 소모해 추가 피해 4를 준다. | 턴당 1회. 매그너스 Q **파쇄탄**의 자체 벽 압박 연계는 기존 추가 피해 7과 기절을 유지한다. 외부 연계에는 추가 기절을 주지 않는다. 둔화·공포를 넉백으로 간주하지 않는다. |

VF 계열은 이바 E의 생명력, 유스티나 W의 아스트라 등에도 확장할 수 있지만, 지원 생성 카드와 소비 카드를 각각 선언한다. 소환·반격·장판도 실제 설치 성격을 검토한 뒤 설치 협력에 포함한다. 각 계열의 모든 카드에 자동으로 연계를 부여하지 않는다.

## 구현 방식

1. 카드 정의에 내부 연계 역할을 선언한다. 자원을 생성하는 카드, 소비하는 카드, 설치를 새로 만드는 카드 등을 구분한다. 기존 `owner|key` 저장 규칙을 유지한다.
2. 한 번의 직접 카드 사용에서 사건을 한 번만 만든다. 사용 실험체, 실제 지불 코스트, 적중 여부, 설치물의 신규 생성 여부와 원본/파생 효과 여부를 기록한다.
3. 다른 실험체가 만든 조건만 보조에 사용한다. 소비 카드는 자신에게 허용된 외부 보조값만 읽고, 원래 조건과 원래 자원 소모를 정상적으로 처리한다. 같은 실험체의 효과와 외부 보조를 중복하여 완성된 고유 연계를 두 번 발동하지 않는다.
4. 추가 피해·회복·자원 지급 등 파생 효과에는 재발동 금지를 표시한다. 다중 적중, 설치물의 반복 공격, 화상·출혈 틱은 새 카드 사용으로 세지 않는다.
5. 상태와 연계 준비는 저장·불러오기로 복원하고 양측에 같은 판정 함수를 사용한다. 카드 요약·전체 설명·필드 효과에 실제 적용 내용과 제한을 표시한다. 별도 태그 분류 UI는 만들지 않는다. 적 행동 예고도 이 판정과 같은 계산을 사용한다.

## 밸런스와 적용 순서

외부 보조 피해는 자신의 턴당 합계 6, 외부 보조 방어도는 합계 6을 초기 상한으로 둔다. 기존 추가 피해와 턴 종료 효과의 제한에도 포함한다. 외부 연계의 피해는 고유 연계보다 낮게 두고, 고유 자원을 얻는 카드의 기본 효과는 혼합 덱에서도 사용할 만한 수준을 유지한다.

첫 적용은 **기름 점화·상처·밀치기**처럼 원본 효과와 조건이 명확한 3종이 적합하다. 설치 협력은 설치물 생명주기와 반복 타격을 확인한 뒤 추가하고, VF 부분 호환은 할인·무료 사용과 함께 별도로 검증한다. 0코스트 이바 R, 에키온 E의 큰 할인 같은 조합이 있어 VF 계열 전체 공유는 무한 연계 위험이 크다. 첫 연계에는 추가 카드 뽑기·코스트 환급·무료 사용권을 보상으로 넣지 않는다.

검증에서는 각 실험체 단독 덱, 두 실험체 혼합 덱, 여러 계열을 모은 혼합 덱을 동일 조건으로 비교한다. 혼합 덱은 새로운 선택지가 생겨야 하며 고유 연계를 완전히 대체해서는 안 된다. 특히 0코스트·무료 사용·다중 적중·중복 설치·동일 턴 반복·저장 복원·양측 필드 분리·조건 판정 순서·적 피해 예고를 검사한다. 이런 기능 구현 후의 수치 검증을 거쳐 최종 계수를 정한다.
