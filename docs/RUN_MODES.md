# 원정 모드

로비의 **새로운 실험**에서 모드를 고르고 **모드로 시작**을 누르면 새 원정을 만듭니다. 취소하면 현재 원정과 저장 기록을 유지합니다. 시작을 확정하면 기존 단일 원정 슬롯을 교체하므로 무한 원정의 연구 성과를 정산하려면 먼저 원정 메뉴에서 정산하고 종료하세요.

## 선택과 해금

| 모드 | 해금 조건 | 진행 |
|---|---|---|
| 노말 | 처음부터 가능 | 기존 규칙으로 3막을 탐사하고 니아를 이긴 뒤 탈출 |
| 하드 | 노말 탈출 성공 | 적 체력 25%·직접 공격 피해 10% 증가, 3막 탈출 성공 시 무한 해금 |
| 무한 | 하드 탈출 성공 | 하드 규칙으로 시작해 3막 주기를 계속 반복 |

모드 선택 화면은 잠긴 모드의 요구 조건을 표시합니다. 보고서나 레어 조우 해금은 모드의 요구 조건을 대신하지 않습니다. 시작 룬·패시브·카드 준비는 기존 방식으로 진행합니다.

이전 버전의 연구 프로필에 탈출 횟수(`totalWins`)가 있으면 노말 클리어로 인정하여 하드를 엽니다. 이 이전 과정에서 데이터나 정산 보상을 다시 지급하지 않으며 무한을 자동으로 열지도 않습니다. 이전 원정 저장에 모드 필드가 없으면 노말로 이어갑니다.

승리 해금은 원정 종료 정산과 함께 영구 연구 프로필에 저장합니다. 파일 잠금이나 저장 오류가 있으면 해금과 정산을 보류하며 재시도할 수 있습니다. 미정산 종료 기록은 새 원정을 만들기 전에 별도로 보관하고 다음 실행 또는 연구 기록을 열 때 재시도합니다. 같은 종료 기록을 다시 불러와도 보상과 승리 횟수를 중복 적용하지 않습니다.

## 난이도

하드의 체력 배율은 장비까지 반영한 새 상대의 최대 체력에 적용합니다. 직접 공격 피해는 타격마다 올림하여 계산하고 방어로 흡수합니다. 중독·출혈의 지속 피해는 이 직접 공격 배율로 늘리지 않습니다. 전투 도중 저장을 불러와도 체력 배율을 다시 적용하지 않습니다. 카드와 크레딧 보상의 기본 규칙은 유지합니다.

무한은 주기가 늘 때마다 노말 대비 적 체력 배율에 **20%p**, 직접 공격 피해 배율에 **5%p**를 더합니다.

| 무한 주기 | 적 체력 | 직접 공격 피해 | 적 레벨 |
|---|---|---|---|
| 1 | 125% | 110% | 기존 지도 진행에 따라 1~20 |
| 2 | 145% | 115% | 20 |
| 3 | 165% | 120% | 20 |

이후 주기도 같은 간격으로 강해집니다. 플레이어와 적의 레벨 상한은 20입니다. 무한에서 보스를 처치해 얻는 최대 코스트는 첫 여섯 번의 승리까지 **총 +6**이며, 조우로 얻는 최대 코스트는 이 상한과 별도로 유지됩니다.

## 무한 주기와 정산

3막 니아를 이긴 직후에는 카드 보상을 확정하고 필요한 패시브 획득·교체·포기를 마칩니다. 그 뒤 새 지도로 넘어갑니다. 새 주기도 1·2막의 경로별 보스는 서로 다르고 3막의 세 경로는 니아입니다.

덱·강화·장비·패시브·룬·음식·오브젝트·크레딧·체력과 연구 원정 ID를 유지합니다. 새 주기 진입만으로 체력을 추가 회복하거나 승리 보상을 다시 지급하지 않습니다. 미완료 조우 약속도 이어지며 보안 콘솔·하이퍼루프와 지도 공개 상태는 새 지도를 기준으로 초기화합니다. 레어 조우는 주기마다 다시 열리는 것이 아니라 원정 전체에서 해당 사건을 한 번 완료할 수 있습니다.

방문한 이전 지도는 고유 구역 ID와 함께 보관하여 이전 주기의 구역·전투·보스 처치·보스 공략 연구를 마지막 정산까지 유지합니다. 이어하기는 현재 주기·지도·전투·난수와 이 보관 기록을 복원합니다.

원정 중 **메뉴 → 무한 원정 정산 → 정산하고 종료**를 선택하면 자발 종료로 표시하고 누적 관측 데이터와 연구 진척을 정산합니다. 확인 창에서 취소하면 원정을 계속합니다. 시작 준비 중에는 정산할 수 없습니다. **저장하고 로비로**는 종료 정산 없이 이어하기를 위해 원정을 보존합니다.

자발 종료와 전투 패배는 모두 탈출 성공으로 계산하지 않으므로 탈출 보너스와 상위 모드 해금을 주지 않습니다. 정산한 원정은 다시 진행할 수 없고, 종료 기록을 다시 열어도 보상은 한 번만 받습니다.
