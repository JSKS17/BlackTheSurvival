# 원작 전술 스킬 자료

2026-10-19 조사. 팬 게임 구현 범위는 **초월을 뺀 원작 명명 전술 26종**입니다. 원작에서 삭제되거나 교체된 기술도 포함하며, 현재 원작 선택 목록 26종이라는 뜻은 아닙니다.

- `tactical-original-catalog.json`: 원작 한국어 이름, 원작 ID, 출신 모드, 현재/과거 구분, 핵심 효과, 모듈 효과, 버전별 쿨다운 근거, 턴제 대응 제안입니다.
- `original-tactical-skills-12.6.0-ko.json`: 원작 게임 데이터 API의 한국어 카탈로그 응답입니다. 삭제된 항목과 빈 임시 항목도 들어 있어 그대로 획득 풀로 사용하면 안 됩니다.
- `original-icons-manifest.json`: 참고용으로 보존한 원작 아이콘 27개(전술 26종과 전술강화 모듈)의 URL, 원작 ID, 원본 SHA-256·크기·참조 경로입니다. 원본 해시는 런타임 도트 그림의 해시와 별개입니다.
- `../art-tactical-pixel/output-manifest.json`: 원작 참고 그림 → 새로 생성한 그림 → 최종 런타임 도트 PNG의 경로·각 SHA-256·처리 기록입니다.
- `icon-validation.json`: 원작 참고 그림의 원본 해시, 생성 그림과 최종 PNG의 독립 해시, 크기, 고유 GUID, Point 필터/Texture2D/밉맵 없음 검증 결과입니다. 최종 재작화가 준비된 뒤 미리보기 생성기가 갱신합니다.

원작 참고 그림은 dak.gg의 Eternal Return 게임 리소스 CDN 미러에서 받은 원본 PNG이며, `../art-tactical-pixel/references/`에 원본 바이트를 보존합니다. 게임과 미리보기에서는 이 참고 그림의 형태·방향·주요 색을 유지하면서 기존 아이콘 스타일로 새로 그린 도트 그림을 사용합니다. 블링크·치유의 바람·플라즈마를 포함한 F 26종과 모듈이 대상입니다. 원작 참고 PNG가 게임에 그대로 표시된다는 뜻은 아닙니다. 이터널 리턴의 IP와 원작 시각 자료의 권리는 님블뉴런에 귀속됩니다.

스킬 아이콘은 기존 카드 아이콘과 같은 96×96 규격이며, 모듈은 시스템 아이콘과 같은 64×64 규격입니다. 정확한 생성 프롬프트, 참조 경로, 생성 원본, 픽셀 처리 방식과 최종 해시는 `../art-tactical-pixel/`에 보관합니다. 이 변경은 그림에만 적용하며 카드 효과·수치·획득 조건을 바꾸지 않습니다.

## 해석 주의

원작 쿨다운 자료는 출처 패치와 일반/코발트 모드를 함께 기록했습니다. 최신 패치 전체를 역산해 확정한 실시간 스탯표가 아닙니다. 팬 게임에서는 이에 비례한 카드 코스트를 별도로 조절합니다.

코발트 전용 기술에는 원작 전술 강화 모듈 효과가 확인되지 않는 경우가 있습니다. 해당 카드의 팬 게임 모듈 효과는 원작 효과라는 표현 대신 턴제 확장임을 구분해야 합니다.

[8.2 코발트 개편](https://playeternalreturn.com/posts/news/2885?hl=ko-KR)에서 제외한 세 전술은 치유의 바람·프로토콜 위반·강한 결속입니다. 강한 결속의 영문 데이터명은 Soul Stealer이지만 원작 한국어 이름은 영혼 흡수가 아닙니다. [12.1 패치](https://playeternalreturn.com/posts/news/3769?hl=ko-KR)에서는 라이트 윙의 기본 공격 둔화 효과를 삭제했습니다. 강화 시 기본 공격 적중으로 지속 시간을 연장하는 효과와 혼동하면 안 됩니다.
