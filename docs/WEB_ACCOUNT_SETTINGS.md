# 웹 계정 환경설정

로그인한 상태에서 환경 설정의 **설정 저장 / 닫기**를 누르면 전체 음량, 배경음악 음량, 효과음·보이스 음량, 전체 소리, 움직임 최소화, 화면 모드 선호값을 해당 계정에 저장한다. 진행 중인 원정이 없어도 설정만 저장할 수 있다. 상단의 `계정에 저장됨`은 클라우드 저장과 브라우저 저장이 완료된 상태다.

다시 로그인하면 같은 계정의 설정을 불러와 UI와 오디오에 즉시 적용한다. 다른 계정은 별도 설정을 사용한다. 설정이 없는 계정은 기본값(전체 40%, 음악 65%, 효과음 80%, 소리 켜짐, 움직임 최소화 꺼짐, 창 모드 선호)으로 시작하며, 다른 계정의 전역 PlayerPrefs를 가져오지 않는다.

전체화면은 브라우저의 직접 사용자 입력이 필요하다. 저장된 화면 모드 선호와 실제 화면 모드가 다르면 환경 설정 버튼에 `클릭하여 적용`을 표시한다. 해당 버튼을 누르면 선호 모드를 적용하고, 두 상태가 같으면 버튼으로 모드를 전환한다. 로그인만으로 전체화면을 강제 전환하지 않는다.

저장 묶음은 schemaVersion 1을 유지하고 선택적인 `settings` 객체를 사용한다. 필드는 `volume`, `musicVolume`, `effectsVolume`(유한한 0~1 숫자)과 `sound`, `reduceMotion`, `fullScreen`(불리언)이다. 설정을 한 번도 저장하지 않은 계정은 이 필드를 생략해 기존 직렬화와 해시를 보존한다. 설정이 없는 예전 클라우드 기록을 가져올 때는 해당 계정의 기존 로컬 설정만 유지하고 다음 동기화에서 함께 저장한다.

로컬 설정과 백업은 계정별 저장 디렉터리의 `browser-settings-v1.json`에 저장하며, 원정·연구 기록과 같은 가져오기 트랜잭션에 포함한다. 가져오기 실패 시 기존 설정 파일과 백업도 복구한다. Windows 실행판과 오디오 검증용 PlayerPrefs는 기존 저장 경로를 유지한다.

검증 기록: `Build/WebVerification/settings-compile-targets.json`, `settings-web-local.json`, 최종 배포 및 실제 브라우저 검증 기록.
