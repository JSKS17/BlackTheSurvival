**레어 조우에 덱과 능력을 직접 바꾸는 보상을 추가한 Windows 업데이트입니다.**

- 91개 레어 조우의 세 선택지를 전용 **++ 카드 구매**, 해당 실험체 패시브 또는 R, 카드 최대 2장 제거·나머지 보조 룬·저비용 일반 카드 사본 2장·무작위 F로 재구성했습니다. 기존 일괄 크레딧 보너스는 제거했습니다.
- ++ 카드는 일반 +보다 강한 별도 강화 사본입니다. 구매한 한 장에만 적용되며 손패·덱·상세·사용 전 정보·전투 기록에서 구분합니다. 구매 전에 실제 효과와 가격을 확인할 수 있습니다.
- 패시브가 가득 찼을 때 교체하고, 제거·복제할 카드를 직접 선택합니다. 보조 룬은 현재 메인 계열의 나머지를 얻으며 모든 보유 보조 룬이 실제 전투에 적용됩니다.
- 일반 조우가 레어 조우로 바뀌는 픽셀 연출을 추가했습니다. 후보별 변환 확률은 1막 12%, 2막 18%, 3막 이후 25%이며 한 막에 한 번만 레어 후보가 나타납니다. 무한 모드의 새 막에서도 출현 한도가 새로 열립니다.
- 연구 과제 세 개를 완료한 뒤 보고서를 완성하는 비용을 **관측 데이터 500**으로 올렸습니다. 이미 완성한 보고서와 연구 기록, 진행 중 원정은 보존합니다.
