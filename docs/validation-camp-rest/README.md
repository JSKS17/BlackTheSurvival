# v0.1.13 모닥불 휴식과 카드 제거

모닥불에 들어갈 때는 체력을 회복하지 않는다. 제작·요리는 자동 회복 없이 기존의 합산 3회 제한을 유지한다. 체력 장비의 능력치와 직접 사용하는 회복 음식은 기존 규칙을 따른다.

휴식을 선택하면 즉시 체력을 모두 회복하고 만년 스프 1개를 받는다. 이후 덱에서 원하는 카드 사본을 최대 2장까지 영구 제거할 수 있다. 재선택·선택 취소로 확정 전 결정을 바꿀 수 있으며, 아무 카드도 제거하지 않고 떠날 수도 있다. 선택만 한 채 떠나면 덱은 변경되지 않는다. 장비가 자동 부여한 D 스킬은 장비와 함께 유지하며, 별도로 얻은 같은 D 카드 사본은 제거할 수 있다.

남은 제거 수는 `RunState.campRemovalsRemaining`에 저장한다. 저장을 다시 읽어도 회복·스프·제거 수가 다시 지급되지 않으며, 다음 모닥불에서는 새 선택을 제공한다. 잘못된 인덱스·중복 인덱스·한도를 넘은 선택은 전체 요청을 거절하여 덱이나 제거 수를 일부만 변경하지 않는다. 기존 버전의 휴식은 바로 지도로 이동했으므로 이전 저장에 남은 제거 수가 없으면 0으로 처리한다.

수정한 모닥불 동작을 중심으로 검증했다. 기존 음악·스프라이트 자산을 다시 제작하거나 전체 난이도 통계를 다시 산출하지 않았다.
