# 코어 실험체의 기술과 패시브 개성

기준 자료는 `art-chibi/reference-skills.json`에 저장한 12.5.0의 T/Q/W/E/R 툴팁이다. 실시간 이동, 범위와 공격 속도를 단일 상대 턴제 전투의 설치물, 다음 공격 강화, 회피와 연계로 변환한다. 아래 수치는 팬 게임의 수치이며 원본 게임의 피해량을 그대로 가져온 값이 아니다.

| 실험체 | 카드 운용 |
|---|---|
| 니아 | Q로 아케이드 블록을 최대 3개 남긴다. W는 기존 블록당 추가 피해 4를 주고 블록을 소비하며 다음 Q를 1코스트 할인한다. Q/W 적중은 배터리를 충전하고 R은 배터리를 방어도로 바꾸며 게임월드를 유지한다. E는 일정 시간 치명상을 한 번 막는 1UP이다. |
| 재키 | Q는 출혈과 표식을 쌓고 적중 재사용을 제공한다. W는 다음 기본 공격을 강화한다. 최대 출혈일 때 Q/E가 강해지며 R은 전기톱 공격과 지연된 학살로 나눈다. |
| 아야 | Q 적중으로 연발을 준비한 뒤 W의 다단 사격을 강화한다. E로 Q/W의 다음 사용 코스트를 줄인다. R의 공포는 약화와 다음 사격의 추가 피해로 바꾼다. |
| 현우 | Q 적중으로 돌진 기세를 쌓고 E로 소비한다. W는 방어와 반격을 제공하며 R의 충격파는 타격과 턴 종료 폭발로 나눈다. |
| 유키 | W로 단추를 보충하고 E의 재사용을 준비한다. Q 적중은 단추 하나를 소비해 강화한다. R은 검흔을 남겨 턴 종료에 폭발시킨다. |
| 혜진 | Q는 흉조를 축적하고 W는 지연 부적이다. E는 이동 부적을 설치한 뒤 재사용하여 회수한다. R은 축적한 흉조와 궤도 명왕으로 피해를 준다. |
| 수아 | Q/E가 기존 책갈피를 폭발시키고 새 책갈피를 남긴다. W는 즉시 방어도 10과 턴 종료 2회의 방어도 2 보충, 적 공격 약화로 파랑새의 보호를 표현한다. R은 마지막으로 사용한 수아 Q/W/E를 다시 사용하는 기억이다. |
| 아이솔 | Q는 부착 폭탄을 남긴다. W는 연속 사격과 폭탄 공격 준비를 쌓는다. E는 은신 후 다음 기본 공격을 강화한다. R은 적 행동에 반응하는 지뢰와 지연 폭발을 설치한다. |
| 나딘 | Q를 이어 사용하면 조준 피해가 높아진다. W는 반응형 덫이며 E는 조준과 다음 기본 공격을 준비한다. R의 늑대는 3턴 동안 추격한다. |
| 엠마 | Q의 비둘기, W의 폭발 모자, E의 토끼를 각각 남긴다. R은 직전 자신의 마술에 따라 해당 소품을 회수하며 비둘기 추가 피해, 모자 폭발 또는 토끼 방어를 얻는다. |

니아의 블록·싱크 연계는 [공식 1.47 출시 설명](https://playeternalreturn.com/posts/news/2702?hl=ko-KR)과도 대조했다. 모자 잔상, 벽 충돌의 돌진 기세, 은신의 회피율 등은 단일 상대 전투에서 선택을 만들기 위한 추상화다. 소환물은 별도 HP를 가진 캐릭터 대신 제한된 턴 종료 효과로 표현한다.

스킬의 자원은 카드 주인별로, 패시브와 룬의 자원은 해당 능력 ID별로 분리한다. 따라서 니아 카드의 배터리와 다른 패시브의 충전이 섞이지 않는다. 패시브의 전투 효과는 주인의 카드가 없어도 발동하고, 주인의 무작위 스킬 등장 가중치 1.5배는 별도로 유지한다.

이전 버전의 진행 중 전투를 불러오면 기존 체력·난수·사용 기록을 보존한다. 로드할 때 전투 시작 효과를 다시 지급하지 않으므로 새로 도입된 시작 단추·부활 준비 등은 다음 전투부터 적용한다. 공격·기술 사용·피격에 반응하는 새 효과는 이어 하는 전투에서도 발동한다.
