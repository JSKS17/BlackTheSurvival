# 1.0.3 아트 수정

## 프롤로그 2페이지 니아의 눈

차분한 반쯤 감긴 무표정과 포즈를 유지하며 양쪽 윗눈꺼풀을 같은 짙은 흑자주색으로 정리했습니다. 원본은 한쪽 눈꺼풀의 검은 줄이 1254픽셀 PNG의 y542~554에 놓여 있었고, 게임의 기존 80픽셀 Point 표시가 읽는 y540과 y556 사이에 끼어 한쪽만 회색처럼 보였습니다.

내장 `image_gen.imagegen` 정밀 편집으로 검은 눈꺼풀의 굵은 도트를 표시 격자에 맞췄습니다. 표시 코드, 논리 도트 크기, 캐릭터 표시 크기는 바꾸지 않았습니다. 최종 PNG를 도구 출력 그대로 복사했으며 별도의 래스터 편집은 없습니다.

읽기 전용 RGB 검사에서 80 Point 격자 y34의 양쪽 눈꺼풀 4지점을 각각 확인했습니다. 왼쪽 평균 RGB는 (27.75, 6, 18.75), 오른쪽은 (27.5, 5.5, 18)이며 평균 색 거리 0.94입니다. 모두 어두운 흑자주색으로 표시됩니다. 전체 실루엣은 이전 파일과 IoU 98.66%이며 캐릭터·큐브 배치와 무표정을 유지합니다.

- 최종 파일: `Assets/Resources/Lumia/Story/Characters/nia_overload.png` (1254×1254 RGBA).

- [80픽셀 표시 격자를 고려한 최종 프롬프트](nia-face-grid-prompt.txt).
- [파일 해시, 투명 여백, 눈 RGB 검사](manifest.json).

`Tools/BuildStoryGeometry.py`에 1.0.3 해시를 추가하고 새 투명 여백을 `geometry.json`에 반영했습니다. 다른 컷신 캐릭터 11종은 바꾸지 않았습니다.
