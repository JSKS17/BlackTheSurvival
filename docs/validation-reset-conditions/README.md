# v0.1.9 조건부 기술 재사용 검증

[변경 규칙](../CONDITIONAL_RECASTS.md)에 7개 조건부 무료권과 6개 즉시 무료권 제거, 관련 소량 할인·강화 자원 소비를 기록한다. 이번 카드 사용 직전 자원과 실제 적중으로 판정하며, 시전 뒤 상처가 소비되어도 이미 획득한 캐시 Q 사용권은 유지한다. 외부 연계가 뒤늦게 추가한 상처는 현재 무료권의 조건으로 계산하지 않는다.

실제 양측 `PlayCard`·적 행동·계획·예고가 같은 조건을 사용하는지, 사용 전 준비 없음·부족함·준비 완료·빗나감·무료권 1회 소비·같은 턴 재충전 차단을 검사한다. 기존 준비가 없는 캐시 Q, W 두 번으로 준비한 Q, 획득한 무료 Q를 남은 코스트 0에서 사용한 상황을 Windows 화면에서도 재현한다. 셀린·쇼이치·얀의 추가 화면도 실제 기술로 준비한 뒤 조건부 연계를 실행한다.

개인 저장과 분리된 `-lumia-verify` 슬롯을 사용한다. Windows 빌드 출력과 소스의 SHA-256 일치, 설치된 런타임 실행, 개인 이어하기 저장 보존, 배포 ZIP의 모든 파일 CRC·SHA-256을 검사한다. 개인 저장 백업·인증·업로드 기록은 추적하지 않는 `Temp/`에만 보관한다.

[게임 규칙](core-tests.log)은 56개 시나리오·58,251개 검증, [설명 감사](description-audit.log)는 37,914개 검증을 통과했다. 카드 392종·패시브 91종·룬 16종·장비 51종과 디버프 설명이 필요한 카드 225종을 확인했다. [런타임 컴파일](runtime-compile.log)과 [개발 빌드](development-build.log)도 통과했다.

[40개 고정 시드 비교](balance-comparison.json)는 동일한 정책과 실제 공개 행동을 사용하며, 엔진 상태나 난수를 유리하게 편집하지 않는다. v0.1.8과 v0.1.9 모두 탈출 2회·패배 38회·정체 0회였다. 이 표본은 특정 자동 행동 방식의 회귀 검사이며 일반 플레이어 승률이나 최적 밸런스를 입증하지 않는다. [변경 전](balance-before.log)·[변경 후](balance-after.log) 로그와 정책 해시를 보존한다.

[실제 Windows 화면](native-screens.json) 130개와 카드 미리보기 4,704개 배치에서 실행 오류·본문 넘침은 0개였다. 글꼴 11과 카드 내부 스크롤 없음 규칙을 유지했다. 신규 [조건부 연계 화면 9개](native-ui/)는 실제 기술 사용으로 준비·미획득·획득·남은 코스트 0 재사용·1회 소모를 검사한다. 캐시의 손패·사용권 필드·전체 설명, 쇼이치 W·셀린 W·얀 E 전체 설명을 직접 검토했다. [소스·개발 빌드 해시](build-source-hashes.json)도 일치했다.

[Windows 배포 빌드](release-build.log)는 오류 0개로 성공했다. 설치된 실행 파일·Unity 런타임·게임 어셈블리·리소스 [해시](release-hashes.json)가 빌드 출력과 일치한다. [정상 시작과 개인 저장 보존](release-startup.json), [ZIP 전 파일 검사](archive-validation.json)도 통과했다. ZIP은 런타임 파일 180개·68,905,806바이트이며 SHA-256은 `139513f76c8e7259a32cc46d78d9cfdf0079acac2edb5cd3c28bc6dd4a05aa76`이다.
