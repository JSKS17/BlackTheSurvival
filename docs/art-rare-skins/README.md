# 레어 조우 스킨 자료

2026년 10월 12일 한국 시각 기준으로 현재 게임에 출시된 외형을 조사했다. 캐릭터 일지를 통해 해금하는 레어 조우의 스토리와 신규 도트 스프라이트를 위한 자료이며, 공식 스킨의 설정이나 대사를 그대로 옮긴 것이 아니다.

- `skin-manifest.json`: 91명 전체의 선택된 외형, 출시 근거 링크, 공식 참고 이미지 경로, 얼굴·머리·복장·소품의 개별 관찰 기록.
- `release-evidence.json`: 공식 공지에서 확인한 출시일과 예외에 대한 짧은 요약. 공지 전문과 긴 인용은 포함하지 않는다.
- `characters-ko.json`: 공개 12.5.0 클라이언트 데이터에서 이름·코드·이미지 식별자만 추린 스냅샷. 캐릭터 능력치, 상품 정보, 대사와 스킨 배경 설명은 제거했다.
- `visual-notes.json`: 공식 이미지를 육안으로 확인한 제작 메모. 캐릭터마다 얼굴과 의상이 달라야 하며 기본 복장이나 공통 얼굴을 일괄 적용하지 않는다.
- `references/`: 공식 이미지의 반신 초상 참고 자료. 게임에서 표시하는 완성 도트 스프라이트는 별도로 새로 만든다. 이미지에 보이지 않는 하의는 확인된 색과 형태를 해치지 않는 범위에서 보수적으로 이어 그린다.
- `contact-sheets/`: 참고 자료를 대조하기 위한 축소판.

## 최신 출시 기준

현재 공개 클라이언트 데이터의 가장 뒤쪽 스킨 코드를 후보로 삼은 뒤, [공식 새소식](https://playeternalreturn.com/posts/news)과 시즌별 출시 일정을 대조했다. 코드가 높다는 이유만으로 미출시 스킨을 선택하지 않는다. 시즌팩으로 패스를 먼저 이용할 수 있었으면 개별 패스 판매일보다 앞선 실제 이용 가능일을 기록했다.

리오 `Dolce`와 하트 `Vivace`는 기본 3주년 스킨보다 늦은 2026년 7월 23일에 추가된 외형이다. 이바 `Blossom`도 기본 2주년 스킨 이후 2025년 8월 7일에 추가됐다. 따라서 색변형을 포함한 최신 출시 외형을 채택했다. [11.7 패치](https://playeternalreturn.com/posts/news/3713?hl=ko-KR), [8.3 패치](https://playeternalreturn.com/posts/news/2916?hl=ko-KR)

블레어 `포디엄 피니시`는 예정된 패치일 뒤로 지연되어 실제 2026년 2월 20일에 제공됐다. [공식 출시 일정 안내](https://playeternalreturn.com/posts/news/3389?hl=ko-KR)

요한 `악마사냥꾼`은 현재 데이터에 남은 최신 외형이지만 판매가 중단된 기존 스킨이다. 기존 보유자가 있던 출시 스킨이라는 점은 확인했으나 최초 출시 날짜를 복구하지 못해 날짜를 비워 두었다. 현재 상점에서 구매할 수 있다는 뜻으로 표기하지 않는다. [공식 기존 보유 스킨 환불 안내](https://playeternalreturn.com/posts/news/1593?hl=ko-KR)

루치아·세레스·크레이버는 현재 스냅샷에 기본 외형만 있어 사용자가 요청한 팬 창작 사복으로 디자인했다. 크레이버 등 앞으로 출시할 것으로 예고된 외형은 현재 출시된 스킨에 포함하지 않았다. [현재 캐릭터 데이터](https://er.dakgg.io/api/v1/data/characters?hl=ko), [12.0 시즌 안내](https://playeternalreturn.com/posts/news/3742?hl=ko-KR)

## 창작 및 게임용 에셋

스토리는 `RareSkinStories.cs`에서 91명 모두 별도로 작성한다. 각 선택지의 효과·가격·보상 수치는 게임 로직의 실제 값이 설명에 추가되므로 창작 문장에 고정 수치를 중복 기재하지 않는다. 원작의 공식 대사를 복사하지 않았다.

스프라이트의 얼굴은 머리 크기를 확보하고 캐릭터별 눈매·표정·수염·피부색을 구분한다. 공식 참고 이미지가 식별 근거이고, 제공된 도트 레퍼런스는 비율과 픽셀 표현 방식만 참고한다. 카티야·비형에게 안경을 덧붙이지 않으며 크레이버의 원래 붉은 안경은 유지한다. 완성 게임 리소스는 `Assets/Resources/Lumia/PortraitsRare/`에 둔다.

공식 원본 이미지와 이터널 리턴 IP의 권리는 님블뉴런에 있다. 여기 포함된 참고 파일은 팬 게임 제작의 출처 기록이며 런타임 스프라이트를 대체하지 않는다.

## 생성 결과와 검증

91명 모두 built-in imagegen으로 개별 생성했다. [전체 자산 목록](asset-index.json)은 실제 사용한 프롬프트, 생성 원본, 입력 참고 자료, 런타임 이미지와 각 파일의 SHA-256을 연결한다. [prompts/](prompts/)에는 도구에 전달한 프롬프트를, [generated/](generated/)에는 생성 원본과 교정 전 버전을 보관한다. 제공된 팬 도트 레퍼런스 자체는 재배포하지 않는다.

게임용 이미지는 생성 원본의 투명도를 유지한 채 알파 영역 자르기, 최근접 축소, 80×80 투명 여백과 정확한 2배 확대만 적용했다. 색칠·얼굴 재조합이나 공통 템플릿 합성은 하지 않았다. 에이든은 최근접 표본에서 완전 불투명 픽셀이 빠져 최대 알파가 254이며, 생성 원본의 알파를 임의로 바꾸지 않았다. 검증은 배경 알파 0과 최대 알파 250 이상을 허용한다.

[집계 검증](validation.json)과 [런타임 자산 검증](runtime-validation.json)은 91/91 자산·중복 없는 생성·160×160 크기·2배 도트 격자·Point 필터·압축 없음·고유 Unity GUID·기본 스프라이트 보존을 확인했다. [여섯 장의 기본/레어 대조표](sprite-comparisons/)에서 얼굴, 선택 스킨의 주요 의상·소품, 잘림과 배경도 육안으로 확인했다. 사복 세 종은 [별도 디자인 기록](custom-outfits.json)에 남겼다.
