# v0.1.15 키오스크 배지와 실험체별 보스

Windows, Unity 6000.3.11f1에서 검증했다. 모든 실험체 91명에게 2페이즈, 니아에게는 3페이즈를 부여해 총 183개 페이즈를 구성했다. 전투 조건·효과·출처와 인물별 설계는 [보스 기믹 문서](../BOSS_MECHANICS.md)에 기록한다.

- [코어 검증](core-tests.log)은 68개 시나리오·68,649개 단언을 통과했다. 기존 61개 규칙에 보스 프로필 전수, 실제 지도 입장과 조회 비변이, 7종 대응과 범용 대안, 50%·25% 전환, 11종 실패 효과, 지연 피해·반격·상한·원본 자원 상태, 실제 기술 우선 계획과 피해 예고, 저장과 이전 저장 이관을 추가했다.
- 방어도에 흡수된 공격은 피해 대응에 포함하고 회피된 공격은 제외한다. 저지 보상은 늦게 방어로 달성해도 다음 플레이어 턴까지 유지된다. 아야의 피격 전 보호막·경계의 방어·불괴의 보호막 파괴 정화가 보스 특수 공격과 반격에도 적용됨을 검사했다. 91명의 특수 행동과 일반 카드 계획을 합친 피해 예고도 회피·치명타가 없는 수치 조건에서 실제 피해와 일치했다.
- [화면 준비 사전 검증](native-fixture-preflight.log)은 91명의 실제 보스 입장·공략 조회와 24개 화면 준비 과정 × 5개 시드, 120개 시나리오를 통과했다. 이 검사는 Unity JSON과 글꼴을 대체하지 않으므로 실제 Windows 검증 결과를 함께 보관한다.
- [40개 시드 자동 플레이](balance.log)는 탈출 1회·패배 39회·정체 0회였다. [v0.1.14 기준](baseline-balance.log)은 탈출 3회·패배 37회·정체 0회이며 양측 3막 도달은 17회였다. 기준 소스는 `b462ede84f42ddf375aa41aacb57989440d9db4a`이고 [정책 파일 해시가 같다](balance-comparison.json). 체력·적 상태·난수를 수정하지 않는 고정 정책이며, 보스의 대응 조건을 우선하지 않는다. 추가 회피 판정이 이후 난수 경로도 바꾸므로 같은 시드의 결과를 기믹만의 독립 효과나 사람의 승률 추정으로 해석하지 않는다.

- [런타임 컴파일](runtime-compile.log)과 [개발 빌드](development-build.log)를 통과했다. [25개 실제 화면](native-screens.json), [실행 로그](ui-player.log), [개발 실행본과 소스의 일치 해시](build-source-hashes.json)를 보관한다. 실험체·야생동물의 배지, 7종 대응 공략과 긴 설명의 스크롤 하단, 실제 공격에 따른 50%·25% 전환 대기·적용, 진척·중단·Unity JSON 복원, 특수 효과와 처리 완료, 도움말을 확인했다. 모든 화면은 1280×720이며 비어 있는 프레임과 실행 오류가 없다.
- 실제 한글 도트 글꼴에서 183개 페이즈 × 제목·진척·조건·행동, 732개 배치를 측정했다. 제목 최대 너비 251.01/375, 본문 최대 높이 27.51/28로 모두 범위 안에 있다. 중앙 보스 패널은 필드·상대 행동·손패를 가리지 않는다. 배지·공략·전환·저지·예약 효과 화면을 직접 검토했다.
- [개인 저장 보존](save-preservation.json)을 확인했다. 개발 검증은 개인 이어하기와 분리한 저장 슬롯에서 실행한다. [배포 빌드](release-build.log)는 오류 0개로 성공했고 개발용 연결 옵션이 없는 실행 파일을 설치했다. [4개 주요 설치 파일의 해시](release-hashes.json)가 빌드 출력과 모두 같다. [시작 검증](release-startup.json)은 창 제목 `Black The Survival`, 정상 응답·시작 오류 0개·개인 저장 보존을 확인했다. [ZIP 검증](archive-validation.json)은 실행 파일과 전체 런타임을 CRC·SHA-256으로 대조하며 개발 캐시·개인 저장을 제외한다.
