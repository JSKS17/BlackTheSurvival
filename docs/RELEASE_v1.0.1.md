# Black The Survival v1.0.1

## 아트와 전투 표시

- 로비 연구소를 굵은 도트로 다시 만들고 니아와 어울리는 픽셀 크기로 표시합니다. 로비 니아의 기존 모습과 자세는 유지했습니다.
- 프롤로그 두 번째 컷의 니아를 반쯤 감긴 수평 눈매와 작은 닫힌 입의 무표정으로 교정했습니다.
- R 애니메이션은 배경 패널 없이 시전자 쪽에 더 크게 표시하고, 중앙의 사용 카드와 동시에 재생합니다. 카드·손패와 겹치지 않으며 마지막 R을 마친 뒤 결과 화면으로 넘어갑니다.
- 피해·보호막·회복·패시브 등의 전투 문구에 어두운 테두리를 추가하고 표시 시간을 늘렸습니다. 연속 효과도 서로 다른 줄에 표시합니다.

## 음식과 무료 연계

- 전투 중 **만년 스프는 2코스트, 다른 음식은 1코스트**를 사용합니다. 코스트 부족·적 턴에는 먹을 수 없으며, 전투 밖에서는 비용이 없습니다.
- **바냐 Q·비앙카 W·클로에 E·매그너스 W**의 무료 연계는 다음 자기 턴에 열립니다. 원작의 귀환·지속·후속 공격 대기를 반영한 구분입니다. 기존 적중·자원 조건은 유지하고 즉시 할인으로 대기를 우회하지 않도록 했습니다.
- 카드 설명과 필드 정보에서 예약을 확인할 수 있으며 이어하기에도 보존됩니다. 실제 보유 카드만 회수하고 소멸 카드는 복구하지 않습니다. 자세한 규칙은 [음식과 지연 연계](https://github.com/JSKS17/BlackTheSurvival/blob/main/docs/FOOD_AND_DELAYED_RECASTS.md)에 있습니다.

## 장비

- 인터벤션·주와이외즈·쿼드 아이·미스릴 완장·레이싱 부츠·운명의 주사위를 추가해 총 **57종**입니다. 원작 아이콘을 참고한 새 도트와 원작 특성을 반영한 옵션을 사용합니다.
- 지원하는 **23개 무기군** 모두 무기를 제작할 수 있고 해당 D 카드가 자동 지급됩니다.
- 치명타 확률·피해 장비를 늘렸습니다. 치명타 피해 보너스는 일반 공격의 기본150%에 합산하며, 무한 모드의 늘어난 장비 슬롯으로 성장할 수 있습니다. 확률 상한은 기존 노말·하드30%, 무한100%입니다.
- 제작 검색에 치명타 확률·치명타 피해 태그를 추가했습니다. [장비와 원작 자료](https://github.com/JSKS17/BlackTheSurvival/blob/main/docs/EQUIPMENT_EXPANSION_v1.0.1.md)를 참고하세요.

## 실행과 검증

**BlackTheSurvival-v1.0.1-Windows-x64.zip 전체를 한 폴더에 압축 해제한 뒤 BlackTheSurvival.exe를 실행하세요.** 기존 원정·연구 기록과 환경 설정을 유지합니다.

게임 규칙 **105,151개 / 127개 시나리오**, 설명 감사 **39,923개**를 통과했습니다. 실제 Windows 게임에서도 R 양측 사용182회·배치5,460회와 전투20개·로비/컷신23개 화면을 검사했습니다. 개인 저장 보존과 배포 ZIP의 검사 결과는 [검증 기록](https://github.com/JSKS17/BlackTheSurvival/tree/main/docs/validation-v1.0.1)에 있습니다.
