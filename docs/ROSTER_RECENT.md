## 변형과 자원 제한의 변환

- 데비&마를렌과 블레어의 형태별 Q/W/E는 같은 카드에 두 실제 이름을 병기했다. 데비&마를렌 Q/W는 데비의 4초/10초를, 블레어 W는 긴 형태인 칼날폭풍의 20초를 대표값으로 사용한다.
- 미르카 Q는 충전 사이 2초 간격보다 새로운 충전 획득에 걸리는 10초가 덱의 반복 사용 비용을 더 잘 나타내므로 10초를 대표값으로 사용한다.
- 츠바메 R은 원본 쿨다운이 0.5초이지만 최대 표식을 요구한다. 원본의 쿨다운을 보존하면서 카드 비용을 3으로 정한다.
- 유스티나 Q는 원본 쿨다운이 0.8초이지만 별도의 아스트라 에너지를 소모한다. 카드 비용을 2로 정한다.
- 히스이 W는 일반적인 쿨다운 대신 거합 중첩을 요구한다. 쿨다운 필드는 0으로 보존하고 카드 비용을 3으로 정한다.
- 실시간의 이동 속도 증가·은신·대상 지정 불가는 제한된 턴 동안의 회피율 증가로, 속박·기절·넉백은 약화나 취약으로 옮겼다. 회피는 무적과 동일한 효과가 아니다.
- 팀원 보호/회복 능력은 하나 자신에게 적용한다. 부활을 지원하는 펜리르 P는 1인 전투에서 최대 체력 증가로 옮겼다.

## 대상 지정 무료 사용권

실시간 쿨다운 감소·초기화·좌표 연계를 이번 턴에 해당 카드 1회를 비용 없이 사용하는 효과로 옮겼다. 대상 카드를 실제로 소유해야 하며, 전투 엔진의 동일 출처·동일 대상 턴별 제한을 적용한다.

| 사용 카드 | 무료 사용 대상 | 원본 근거와 변환 |
|---|---|---|
| 아비게일 W/R | 워프 슬래시(E) | 해당 공격이 좌표를 남겨 E의 쿨다운 초기화를 가능하게 한다. 적중 시 E 1회권을 바로 제공하는 형태로 옮겼다. |

| 코렐라인 Q | 진실의 거울 / 거짓의 거울(W) | 거울을 통과한 Q가 적중하면 W의 쿨다운이 감소한다. |

피해 적중을 요구하는 무료 사용권에는 `freeCastOnHit`를 사용한다. 가넷 W의 중첩 소비, 헨리 E의 순간 이동 시작, 크레이버 R의 쿨다운 초기화는 스킬 사용 시 적용한다. 자기 자신을 대상으로 하는 초기화도 무한 반복이 되지 않도록 전투 엔진에서 동일 출처의 사용권을 턴당 한 번만 부여한다.

## 출처 수치 재검증

최근 26명의 QWER 104개를 각 스킬 원문에서 `쿨다운:` 또는 `충전 시간:`으로 표시된 값과 다시 대조했다. 위에 설명한 형태 선택·중첩 제한·루치아 변경 예외를 적용하면 104개 모두 일치한다. 쿨다운 감소율, 공격력 계수, 이동 속도 증가율 같은 `%` 수치를 초 단위로 잘못 읽어 등록한 항목은 없다.

아르다 W의 공식 HTML에는 첫 쿨다운 숫자가 `1 4`로 띄어져 있어 숫자 추출기를 그대로 적용하면 1초로 오독할 수 있다. 등록값은 처음부터 14초이며, 재검증에서는 이 숫자 내부 공백을 정규화했다. 대조 결과는 `docs/research/recent/CooldownAudit.json`에 기록했다.
