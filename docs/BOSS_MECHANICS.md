# 실험체별 보스 기믹과 대응

전투 가능한 실험체 91명 모두에게 고유 보스 프로필을 부여했다. 각 실험체는 자신의 Q/W/E/R, 기존 패시브와 장비를 사용하는 전투에 **예고 → 플레이어의 대응 → 실패 시 특수행동**을 더한다. 아래 183개 페이즈의 이름과 대응 과제, 피해·회복·방어·간격은 이 팬 게임을 위해 만든 턴제 설계다. 원본 이터널 리턴의 보스 기믹이나 실시간 수치를 그대로 옮긴 것이 아니다.

## 공통 진행과 공략 확인

- 지도에서 보스 실험체의 이름과 공략을 미리 확인할 수 있다. 전투에서는 현재 페이즈, 이번 턴의 대응 조건과 진척, 다음 특수효과를 표시하며 상세 창에서 모든 페이즈를 볼 수 있다.
- 최초 특수행동은 2턴에 예고한다. 1페이즈는 이후 3턴 간격, 2·3페이즈는 2턴 간격이다. 조건은 예고된 **그 플레이어 턴 안에서** 누적하며 다음 예고에는 초기화한다. 일반 턴의 행동을 미리 적립하지 않는다.
- 모든 보스는 체력 **50% 이하**에서 2페이즈를 예약한다. 니아만 **25% 이하**에서 3페이즈를 추가로 예약한다. 새 페이즈는 다음 플레이어 턴에 적용하며 그 턴 전체가 대응 시간이다. 전환 자체로 즉시 공격하거나 무적이 되지 않는다. 한 번에 두 경계를 넘으면 도달한 페이즈로 넘어가며, 쓰러뜨릴 만큼 피해를 주면 그대로 승리한다.
- 사용·피해·방어 목표는 표의 주목표와 대체목표 중 **하나**만 달성하면 된다. 디버프 기술 사용을 포함한 이 목표들은 누적 피해 또는 방어도 획득으로도 대응할 수 있다. 반면 세 금지형 목표에는 피해로 우회하는 대체 조건이 없다. 필요한 손패가 없거나 덱의 전략과 맞지 않으면 실패 효과를 보고 방어·회복·다음 턴 준비를 선택할 수 있다.
- 금지형은 예고 턴에 **수동으로 카드를 2장 이상 사용하고, 턴을 마칠 때까지 금지 조건을 한 번도 위반하지 않아야** 성공한다. 아무 카드 없이 넘기거나 한 장만 사용하면 실패한다. 두 장을 사용한 직후에도 아직 성공이 확정되지 않으며, 그 뒤 금지 카드를 쓰거나 기준 이상의 피해를 주면 실패한다. 금지된 카드 자체의 사용을 막지는 않는다.
- 대응에 성공하면 이번에 준비하는 특수행동을 중단한다. 보스는 성공한 시점부터 **다음 플레이어 턴 종료까지 공격으로 받는 피해가 1.5배**가 된다. 일반 취약과는 중첩하지 않는다. 이전 실패로 이미 예약한 폭발, 자원·코스트 준비, 반격 등은 소급해서 취소하지 않는다.
- 대응에 실패하면 특수행동이 그 적 턴의 **첫 행동**으로 실행된다. 이후 적은 자신의 정상 카드 계획을 진행한다. 표의 우선 기술은 덱에 있고 해금되어 사용 코스트를 지불할 수 있을 때 정상 계획에서 우선한다. 별도의 무료 기술 사용이나 추가 카드 지급이 아니다.

주목표가 누적 피해일 때 대체목표는 방어도 획득이다. 다른 사용형 목표의 대체목표는 누적 피해이며, 디버프 기술 사용은 1회 또는 누적 피해 18/26으로 대응한다. 세 금지형에는 대체목표가 없다. 수치는 보스 레벨에 따라 추가 증가하지 않는다. 니아 3페이즈는 서로 다른 카드 키 3종 또는 누적 피해 30을 사용한다.

수동 사용은 플레이어가 손패에서 낸 카드 한 장을 뜻한다. 무료 사용권으로 직접 낸 카드도 한 장으로 세며, 패시브·설치물·지속 피해·자동으로 재현한 기술은 추가 사용으로 세지 않는다. 기본 공격과 경계도 수동 사용 두 장에 포함한다.

디버프 기술의 사용·금지는 같은 카드 분류를 공유한다. 상대에게 해로운 효과를 포함한 실험체 기술 Q/W/E/R, 무기 기술 D, 전술 기술 F가 대상이다. 회피되거나 자원 조건이 충족되지 않아 해로운 효과가 실제 적용되지 않아도 기술 사용으로 판정한다. 기본 공격과 경계는 패시브가 디버프를 부여하더라도 디버프 기술로 분류하지 않으며, 별도로 자동 발동한 패시브의 해로운 효과도 금지 위반이 아니다.

강한 공격 금지는 **카드 한 장을 한 번 사용해 준 직접 체력 피해와 방어도에 준 피해의 합계**를 검사한다. 다단 공격의 타격들을 합치고 카드 자체의 추가 피해·공격력·치명타 등 실제 피해 보정을 반영한다. 회피한 타격의 피해는 0이다. 별도로 발동한 패시브 피해, 설치물·소환물·지속 피해와 예약된 자동 피해는 이 합계에서 제외한다. 1페이즈는 24 이상, 2페이즈는 32 이상이면 위반이며, 다른 카드로 방어하거나 이후에 피해를 줄여도 그 턴의 위반 기록은 지워지지 않는다.

이번 변경은 기존 일곱 대응 종류를 유지하면서 15명의 16개 페이즈에 네 종류를 추가했다. 강한 공격 금지는 니키1·현우1·마이1·다니엘1·알론소1·클로에2, 디버프 기술 금지는 마이2·하트2, 이동 카드 금지는 카티야1·나타폰2·아델라1·헨리2, 디버프 기술 사용은 캐시1·비앙카2·요한2·엘레나2다. 각자의 가드·영감·장막·생명 공유·사선·촬영·기물·시간 장치·치유·냉기 원형을 대응 과제로 바꿨으며, 이 금지·사용 규칙이 원본 게임에 존재한다고 주장하지 않는다. 기존 시그니처, 실패 효과와 예고 간격은 유지했다.

## 실패 효과의 범위

| 효과 | 적용 시점과 제한 |
|---|---|
| 즉시 공격 | 예고 턴의 적 첫 행동에 기본 피해를 준다. 개별 최대 20이며 방어·회피가 가능하다. |
| 지연 공격 | 다음 플레이어 턴 전체가 지난 뒤 적 첫 행동에 폭발한다. 개별 최대 16이며 방어·회피가 가능하다. 새 특수행동을 중단해도 이미 예약된 폭발은 유지한다. |
| 방어 | 보스가 방어도를 얻는다. 개별 최대 18이다. |
| 회복 | 보스가 체력을 회복한다. 개별 최대 12이며 최대 체력을 넘지 않는다. |
| 코스트 준비 | 다음 적 턴의 사용 가능한 코스트를 1 늘리고 한 번만 소비한다. 영구 최대 코스트를 바꾸지 않는다. |
| 상태이상 | 플레이어에게 기존 상태이상을 1턴 부여한다. 이번 카탈로그에는 둔화·실명·방어 감소·치유 감소·속박·무장 해제·침묵·공포·공격력 감소·끌어당김을 사용한다. 보스 특수행동에 턴 전체를 빼앗는 강제 기절은 추가하지 않는다. |
| 반격 | 다음 플레이어 턴 첫 공격 적중에 한 번 반격한다. 기본 피해 최대 6, 방어 가능이며 이후 공격에 반복하지 않는다. |
| 행동 코스트 압박 | 다음 플레이어 턴의 사용 가능한 코스트를 1 낮춘다. 최소 1을 남기며 영구 최대치를 바꾸지 않는다. |
| 회피 | 다음 플레이어 턴 동안 보스의 회피 보너스를 최대 20%p 준비한다. 다른 회피 보너스와는 큰 값만 적용하며 총 회피율 상한은 65%다. |
| 기술 자원 준비 | 다음 플레이어 턴 시작에 해당 실험체가 실제로 사용하는 자원을 최대 2 준비한다. 원래 상한을 유지한다. 상태 자원은 수치 합산 대신 활성화한다. 변경 후의 자원으로 정상 적 계획과 예상 행동을 계산한다. |
| 정화 | 보스의 중독·약화·취약과 해로운 상태이상을 해제한다. 보스가 대응 성공으로 받는 별도 취약 보상은 정화하지 않는다. |

하나의 실패는 최대 두 효과를 조합한다. 같은 적 턴에 도래한 직접·지연 공격의 **기본 피해 합계 상한은 20**, 방어·회복 합계 상한은 **24**다. 약화·취약·상태이상에 의한 피해 보정과 기존 카드·패시브·장비의 정상 효과는 별도로 적용된다. 표의 피해는 고정 체력 손실이 아닌 기본 피해다.

## 저장 호환과 검증 범위

현재 보스 전투의 페이즈와 대기 중 전환, 이번 턴의 대응 진척·사용 키·수동 카드 사용 수·금지 위반 여부, 이미 중단한 행동, 예약된 지연 공격·자원·코스트·반격은 저장 데이터에 포함한다. 새 규칙 이전 저장에 보스 상태가 없으면 기존 체력·카드·난수 진행을 유지하고 다음 플레이어 턴부터 예고를 시작한다. 이미 진행 중인 적 턴에 예고 없이 특수행동을 추가하지 않는다. 보스 구역이 아닌 일반 실험체와 야생동물 전투에는 이 규칙을 적용하지 않는다.

구현은 `BossMechanics.cs`의 공통 판정, `BossProfiles.cs`의 코어 10명과 생성 함수, `BossProfilesClassic.cs`의 55명, `BossProfilesRecent.cs`의 26명으로 나눈다. 이 문서의 실험체별 조건·효과 표는 프로필 정의와 `BossMechanics.ResponseText`·`EffectsText`의 판정 기준에 맞춰 정리했다. UI도 같은 엔진 값을 읽어 진척과 공략을 표시한다.

`Tools/BossSmokeTests.cs`는 전체 91명·183페이즈와 소유 기술, 열한 대응 종류와 열한 실패 효과, 실제 카드 사용에 따른 판정, 금지형의 최소 행동 수·턴 종료 판정·피해 임계값·위반 기록, 디버프 기술 분류, 체력 경계 전환, 예약 효과와 상한, 계획·예상 피해, 저장·이전 저장 이관을 검증한다. 네이티브 화면 검증은 지도 공략, 예고·진척·중단·위반·전환·지연 효과와 긴 문구 표시를 확인한다. 최종 실행 결과와 화면 증거는 [VALIDATION.md](VALIDATION.md)에 기록하며, 여기의 범위 설명 자체를 완료 결과로 간주하지 않는다.
