# 최근 실험체 26명의 스킬 카드 개성

`SkillIdentityRecent.Populate(Dictionary<string, SkillMechanicProfile>)`는 `RecentRoster`의 26명, Q/W/E/R 104개 ID를 등록한다. `CardPresentation.Configure`가 쿨다운에 따른 기본 코스트와 수치를 계산한 **뒤에** 프로필을 적용한다. 카드 ID, 이름, 아이콘, 기존 쿨다운과 코스트는 바꾸지 않는다. 기존의 독·영구 힘·일률적인 무료 재사용은 초기화하고, 아래 상태와 조건부 할인으로 대체한다.

근거는 [reference-skills.json](art-chibi/reference-skills.json)의 T/Q/W/E/R 전체 `tooltip` 및 `original_number`이다. 이 파일은 원작 **12.5.0 스냅샷**이며 현재 라이브 패치의 수치라고 주장하지 않는다. `reference_path`와 `image_url`도 같은 원본을 가리킨다. 일부 원작 스킬의 영문 이름, 한국어 카드 이름, 기존 카드의 출시 당시 쿨다운은 다르므로 기존 ID와 표기는 그대로 사용한다.

자원은 실험체별로 분리되며 전투 안에서 소모될 때까지 남는다. 상한은 1~4이다. 설치물·지속 피해·지속 회복·보호막은 보통 2~3회 발동한다. `delay:1`은 현재 시전자 턴 종료부터 계산하는 지연 발동이며 실제 시간의 1초를 뜻하지 않는다. 조건과 보너스는 사용 직전 상태를 읽는다. 적중 조건이 있는 표식·소모·할인은 모든 공격이 회피되면 적용되지 않는다. 피해 보너스는 다단 공격의 매 타격이 아닌 첫 적중 한 번에만 추가된다.

## 턴제에서 바뀐 부분

- 단일 적 전투에는 원작의 방향·거리·범위·다수 아군이 없다. 밀치기·둔화·스턴은 약화/회피/방어와 지연으로 압축한다. 카티야의 거리와 코렐라인의 거울 방향은 상태 자원으로 표현한다. 백/흑 광선의 현재/잃은 체력 비례 수치는 고정 보너스로 압축했다.
- T 원문이 설명하는 기본 공격 연계 일부는 스킬 카드의 다음 기본 공격 강화로도 제공한다. 별도로 보유한 패시브의 전역 동작은 이 파일의 조건이 아니다. 원작의 모든 실시간 기본 공격 카운터를 이 파일에서 자동 추적한다고 주장하지 않는다. 츠바메 W의 각인, 미르카 W의 충전, 유스티나 W의 에너지 준비 등은 카드만으로 상태 흐름을 만들기 위한 명시적 재해석이다.
- 일부 사용 금지/채널링/이동 중 입력 조건은 구현하지 않는다. 검기 없는 히스이 W는 작은 방어만 제공하고, 에너지가 없는 유스티나도 약한 기본 Q 또는 E 재충전을 사용할 수 있다. 크레이버 6발은 세 번의 카드 사격 단계로 압축했고 재장전 중 강제 행동 잠금은 두지 않았다.
- 가넷·히스이의 저체력 즉사, 샬럿의 팀 전체 무적, 슈린의 정확한 다섯 번째 낙검, 비형의 실제 최대 체력 증가, 케네스 업화의 매 기본 공격 지속시간 연장, 세레스의 방패가 살아남았을 때만 폭발하는 실시간 조건은 그대로 복제하지 않았다. 대신 제한된 표식 마무리·치명상 1회 보호·검진 3회·방어/반격·고정 지속시간·지연 폭발로 표현했다.
- 블레어의 원작 형태 변경에 필요한 별도 Shift Rush 입력은 E의 형태 전환으로 통합했다. 코렐라인·루치아의 자원 표식은 스킬 조건 판정용으로 유지되며 기본 공격 후속 피해 자체는 별도의 1회 강화 효과가 소비된다. 루치아 E/R이 자원 표식을 소비/재부착한다.
- 모든 강력한 새 상태 효과는 기존에 커졌던 즉시 피해·회복·독·힘을 대체한다. 무조건적인 다중 무료 재사용을 남겨 둔 채 상태 보너스를 더하지 않는다. 할인은 다음 해당 카드 한 번에 적용되며 실제 가능한 코스트는 공유 전투 엔진이 계산한다.

## 연결과 범위 확인

루트의 공유 `SkillMechanics`가 프로필 적용, 상태 저장, 설명, 플레이어/적의 대칭 처리 및 원본 카드 이펙트를 담당한다. 이 작업은 프로필 파일과 이 문서만 소유한다. `RecentRoster`의 각 실험체마다 `_q`, `_w`, `_e`, `_r`를 정확히 한 번 등록하며 104개 모두 원본 툴팁 레코드가 존재해야 한다. 카드 등록/아이콘 인덱스/기존 런의 데이터 형식은 여기서 변경하지 않는다.
