# v0.1.8 제니 패시브 이름 표시 수정

`PassiveDef.name`과 효과의 `label`은 이미 **죽음의 연기**였다. 전투 필드의 공통 제목 함수 `TokenShort`가 영구 치명상 방지 효과에 `사용될 때까지`를 붙여 이름처럼 표시한 것이 원인이었다. 제니 패시브 도감 화면만 확인했던 이전 검증으로는 이 경로를 발견하지 못했다.

필드의 짧은 표시와 상세 제목에는 **죽음의 연기**만 표시한다. 유지 기간 문장은 상세 본문으로 옮겨 `치명상을 한 번 막고 체력을 18 회복합니다. 효과가 발동할 때까지 유지됩니다.`로 안내한다. 같은 공통 경로를 쓰는 펜리르의 라스트 디치도 이름과 유지 기간을 구분한다. 남은 턴이 있는 치명상 방지 효과는 기존 턴 표시를 사용한다.

이번 변경은 UI 문자열에 한정된다. 기존 게임 규칙 검증은 [v0.1.7 기록](../validation-cross-synergies/README.md)에 있으며, 이번에는 런타임 컴파일과 실제 Windows 화면으로 표시를 확인한다. `trait_revive`는 제니 패시브를 가진 실제 전투의 필드 상세를 열어 문제의 경로를 재현하고, `jenny_passive_full`은 패시브 상세 이름을 확인한다. 두 캡처와 전체 121개 화면·카드 미리보기 4,704개 배치 결과를 보존한다.

[런타임 컴파일](runtime-compile.log)과 [개발 빌드](development-build.log)가 통과했다. [화면 검사](native-screens.json)는 실제 121개 화면에서 실행 오류 0개·카드 미리보기 넘침 0개를 확인했다. [제니 필드](native-ui/trait_revive.png)와 [패시브 전체 설명](native-ui/jenny_passive_full.png)을 직접 검토했으며, 제목은 `죽음의 연기`이고 유지 기간은 본문에 표시된다. [소스·빌드 해시](build-source-hashes.json)도 일치한다.

Windows 개발·배포 빌드, 소스와 빌드 복사본의 해시, 설치된 런타임의 정상 실행·개인 저장 보존, ZIP 전 파일의 CRC·SHA-256도 확인한다. 개인 저장 백업과 GitHub 인증·업로드 결과는 추적하지 않는 `Temp/`에 보관한다.

[배포 빌드](release-build.log)는 오류 0개로 성공했다. 설치된 실행 파일·Unity 런타임·게임 어셈블리·리소스의 [해시](release-hashes.json)가 배포 출력과 모두 일치한다. [정상 시작과 저장 보존](release-startup.json), [ZIP 전 파일 검사](archive-validation.json)를 확인하며 v0.1.8로 배포한다.
