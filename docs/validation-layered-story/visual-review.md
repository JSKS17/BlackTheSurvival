# v0.1.26 레이어 컷신 시각 검토

개발 Windows 빌드가 실제로 캡처한 1280×720 화면 중 스토리 12컷과 다시보기 메뉴 1장, 총 13장을 각각 직접 열어 검토했습니다. 검토 과정에서는 소스·이미지·메타데이터를 수정하지 않았습니다. 배경·투명 캐릭터·말풍선·텍스트의 독립 합성이 정상이며, 얼굴·표정·포즈와 내비게이션을 읽는 데 문제가 없는지 확인했습니다.

## 공통 판정

- 캐릭터의 머리색·복장·눈과 입 및 컷별 표정·포즈가 구분됩니다. 기존 통합 일러스트 속 캐릭터를 배경에 남겨 중복 표시하는 문제는 없습니다.
- 배경과 캐릭터의 색이 지나치게 어둡거나 바래지지 않았으며, 투명 캐릭터 주변에 불투명 사각 배경이 나타나지 않습니다. 상하 뒤집힘이나 좌우 반전의 비정상적인 잘림도 보이지 않습니다.
- 상단 제목·내레이션, 하단 안내·이전·다음·종료 버튼 사이에 침범이 없습니다. 얼굴을 가리는 말풍선은 없습니다.
- `normal_3`의 오른쪽 니아 하체 가림은 유지합니다. `hard_2`는 침대 앞에 서서 기지개를 켜는 장면으로 유지합니다. 이 두 항목은 발견 후 검토해 허용한 연출입니다.

스토리 13화면의 수동 시각 검토 결론은 **PASS**입니다. 치명타 관련 8화면도 별도로 직접 열어 확인했습니다. 노말·하드 상세의 30%, 무한 상세·필드·사용 전 정보의 100%, 장비 설명의 모드별 상한, 도움말 03의 두 상한, 실제 공격의 치명타 표시가 모두 읽힙니다. 도움말은 최종 스크롤 위치 100에서 검토했습니다. 전체 21화면·텍스트 24건 및 저장/렌더 타깃 복원 등의 자동 검증 결과는 [README](README.md)와 `native-results.json`에 기록합니다.
