# v0.1.26 컷신 레이어와 무한 모드 치명타 검증

컷신은 배경 6종·전용 투명 캐릭터 12종·말풍선 프레임·텍스트로 구성합니다. 니아 8종과 하나 4종은 실제 게임의 원본 스프라이트를 참고해 컷별 표정·포즈를 새로 생성했습니다. 생성된 PNG 원본은 바꾸지 않고 Unity에서 80×80 논리 픽셀과 Point 필터로 표시합니다. 알파 경계 메타데이터는 이미지 읽기만으로 생성하며, 렌더 타깃이 소실되면 원본에서 복원합니다.

무한 모드는 플레이어와 상대 실험체의 치명타 확률 상한을 100%로 사용합니다. 노말·하드는 30%를 유지합니다. 치명타는 일반 공격의 직접 피해에만 1.5배 적용되며 회피·추가 피해 규칙은 유지합니다. 상세·필드·카드 사용 전 정보·장비·도움말에도 현재 모드의 상한을 표시합니다.

- `core-tests.log`: 121개 규칙 시나리오, 104070개 검증 통과.
- `native-results.json`: 개발 Windows 빌드의 실제 1280×720 화면 21장. 프롤로그·노말·하드 각 4컷, 다시보기 1장, 치명타 화면 8장.
- `release-startup.json`: 배포 빌드 시작·응답·정상 종료와 개인 저장 보존.
- `archive-validation.json`: ZIP 구조·CRC·전체 파일 SHA-256 및 개인 저장 제외 검사.
- 릴리스 게시 후 커밋·한글 본문·ZIP digest를 GitHub API로 확인합니다. 로컬 결과 `Temp/github-layered-story-publication.json`은 소스에서 제외합니다.

스토리 ID·컷 번호를 보존해 v0.1.25의 진행 중 컷을 복원합니다. 다시보기는 원정·연구·저장 파일을 바꾸지 않습니다. 개발 검증은 전용 저장 파일을 사용하고 개인 저장 4개의 SHA-256을 전후 비교합니다. 개발 검증 플래그는 배포 빌드에서 활성화되지 않습니다.

v0.1.25의 통합 컷 일러스트는 런타임 Resources에서 제외했고, 2026-10-14 저장공간 정리로 이전 합성본을 제거했습니다. 현재 `Assets/Resources/Lumia/Story/Backgrounds/`와 `Characters/` 레이어 및 이 폴더의 검증 자료는 유지합니다. 컷별 레이어 구성은 `StoryComposition.cs`, 표시 및 말풍선은 `LumiaStoryUI.cs`에서 관리합니다.
