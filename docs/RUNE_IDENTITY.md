# 룬의 턴제 변환

선택 구조는 메인 룬 1개와 같은 계열의 보조 룬 1개다. 특정 조우로 변경하기 전에는 고정된다. 피해·회복은 작은 고정 수치로 제한하고 재발동 대기 시간과 턴당 상한을 둔다. 증폭드론의 피해 보너스는 다단 공격의 매 타격 대신 **카드의 첫 적중 한 번**에 적용한다.

| 메인 룬 | 전투 행동 |
|---|---|
| 흡혈마 | 기술 적중으로 흡혈을 4중첩까지 쌓는다. 공격 적중 시 소량 회복하고 최대 중첩에서 피해가 조금 높아진다. |
| 취약 | 세 번의 공격 적중마다 집중 타격과 1턴 노출을 준다. 노출은 받는 공격 피해를 10% 높인다. |
| 벽력 | 기술 적중 후 턴 종료에 번개 피해를 준다. 재발동에는 대기 시간이 있다. |
| 와류 | 기술 사용을 이어 갈 때 전투 중 회복이 발동한다. |
| 금강 | 기절·속박·침묵 등 군중 제어를 부여하면 방어도를 얻으며 턴 종료에 파동을 만든다. |
| 빛의 수호 | 전투 시작 보호막과 첫 방어도 파괴 시 해로운 상태 해제를 제공한다. |
| 치유 드론 | 피해를 받아 체력이 최대 체력의 1/3 이하가 되면 2턴 동안 턴 종료에 체력을 2씩 회복한다. 재발동 대기 시간은 3턴이며 같은 효과는 중첩되지 않는다. R 사용으로 발동하지 않는다. |
| 증폭 드론 | R을 사용한 이번 턴과 다음 턴의 최대 코스트가 1 증가하고 각 공격 카드의 첫 적중 피해가 1 증가한다. 같은 효과는 중첩되지 않으며 재발동 대기 시간은 3턴이다. |

취약의 적중 누적, 금강의 제어 후 방어·폭발, 빛의 수호의 보호막 파괴와 해제, 쿠폰의 상점 효과는 [공식 1.0 특성 설명](https://playeternalreturn.com/posts/news/1283?hl=ko-KR)을 참고했다. 치유 드론은 요청한 저체력 조건으로 수정했으며 `체력 × 3 ≤ 최대 체력`을 정수로 비교하여 정확히 1/3일 때도 발동한다. 원본 수치와 범위·아군 효과는 팬 게임에 맞게 조정했다. 단일 적만 있는 전투에서 와류의 공간 조건은 연속 기술 사용으로 단순화했다.

| 보조 룬 | 전투 행동 |
|---|---|
| 들개 탈 | 승리로 사냥을 축적하고 이후 전투에서 제한된 적중 회복을 얻는다. |
| 상흔 | 적중으로 표식을 쌓고 적의 치유를 줄인다. 최대 중첩에서는 주기적인 추가 피해가 발생한다. |
| 속사 | 기술 뒤 기본 공격 적중으로 같은 턴 후속 공격을 강화한다. |
| 서큘러 시스템 | 기술 사용에 반응해 천천히 회복한다. |
| 경계심 | 체력 80% 이하에서 공격받으면 작은 방어막으로 피해를 줄인다. |
| 담금질 | 전투 시간이 흐르면 최대 2단계까지 단련이 쌓여 작은 방어도를 제공한다. |
| 할인 쿠폰 | 키오스크 오브젝트·음식 구매 비용을 10% 낮춘다. |
| 사냥의 전율 | 야생동물을 공격할 때 추가 피해와 제한된 적중 회복을 제공한다. |

새 보조 룬의 조건은 [공식 10.0 패치](https://playeternalreturn.com/posts/news/3305?hl=ko-KR)를 참고했다. 서큘러 시스템은 [공식 1.22 설명](https://playeternalreturn.com/posts/news/1920?hl=ko-KR), 사냥의 전율은 [공식 1.24 변경](https://playeternalreturn.com/posts/news/1983?hl=ko-KR)과 대조했다. 할인 쿠폰은 원본의 고정 크레딧 할인 대신 구매 가격에 비례한 작은 할인으로 변환했다.

누적 회복과 추가 피해는 턴당 횟수 제한을 따르고, 드론은 무한 코스트 회복이나 다단 공격 폭증을 만들지 않는다. 실제 수치·조건·대기 시간은 선택 화면과 가방의 룬 탭에서 상세 설명을 열어 확인할 수 있다.

패시브와 룬이 한 카드에 직접 더하는 피해·방어도는 각각 합계 10, 회복은 합계 12를 상한으로 둔다. 지속 버프의 전체 합은 피해 +6, 최대 코스트 +2, 회피율 +15%까지다. 증폭 드론 자체는 이 중 피해 +1·최대 코스트 +1만 제공한다. 시전자 한 명의 기술·패시브·룬이 턴 종료에 발생시키는 지속 피해는 합계 40, 회복과 방어도는 둘을 합쳐 25까지다. 같은 설치물이나 버프를 다시 부여하면 수치와 남은 기간의 큰 값을 유지한다.
