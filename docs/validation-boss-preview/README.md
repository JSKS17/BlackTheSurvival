# v0.1.6 보스 사전 표시 검증

원정 시작 시 각 막의 보스를 별도 seed RNG로 확정해 `RunState.actBosses`에 저장한다. `BossForAct` 조회는 난수를 소모하지 않는다. 지도 하단에 1~3막 보스의 이름·스프라이트·진행 상태를 표시하며, 보스 노드와 실제 전투도 같은 실험체를 사용한다. 3막은 니아다. 구세이브는 이미 처치한 보스와 진행 중인 보스 실험체를 먼저 보존하고 나머지를 보완한다.

- 게임 규칙 **52개 시나리오·56,541개 검증 통과**. 새 원정의 보스 공개, 동일 seed 재현, 각 막의 3개 경로와 실제 보스 일치, 불러오기 및 지도 조회의 난수 보존, 구세이브의 보스 이력·진행 중 전투 복원을 검사한다.
- 설명 감사 **35,565개 검증 통과**. 카드 392장·패시브 91종·룬 16종·장비 51종을 검사한다. 이번 변경에는 전투 카드나 신규 시너지 규칙을 추가하지 않았다.
- Unity 런타임 컴파일과 Windows 개발·배포 빌드를 검사한다. 개발 플레이어의 **95개 화면**과 카드 미리보기 **4,704개 배치**를 확인한다. 새 원정·구세이브·2막의 보스 지도·보스 노드와 제니 패시브 전체 설명 화면 5개를 보관한다.
- 제니 패시브의 현재 이름·소유자는 `죽음의 연기`·`제니`다. [공식 11.3 패치노트](https://playeternalreturn.com/posts/news/3606?hl=ko-KR)와 일치하며, 이번 검증 화면에서도 확인한다. 현재 소스에서 바꿀 오타는 발견되지 않았다.
- 배포 런타임의 소스·설치 해시, 기존 개인 저장 보존과 정상 시작, ZIP 전 파일의 CRC·SHA-256을 확인한다. GitHub 업로드 검증 기록과 개인 저장 백업은 `Temp/`에만 보관한다.

[교차 시너지 설계안](../CROSS_SUBJECT_SYNERGY_PLAN.md)은 검토용 제안이다. 보스 표시 업데이트에 새로운 시너지 판정을 섞지 않았다.
