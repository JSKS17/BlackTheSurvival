# 사운드 구성

v0.1.10은 공개된 이터널 리턴 원본 OST와 한국어 보이스에 이 프로젝트의 보완 효과음을 함께 사용한다. 실제 게임의 전체 오디오 묶음을 추출한 것이 아니다. 원본이 없는 소리를 원본이라고 표시하지 않는다. 원본 IP와 음원의 권리는 님블뉴런 및 해당 권리자에게 있다.

## 원본 음원

- **Summertime**: 로비·카드 준비·키오스크·탈출.
- **Golden Willow**: 지도·모닥불·실험체 조우·실험 종료.
- **Red Heart**: 일반 전투·보스전.

세 곡은 공식 이벤트 페이지에 공개된 OST MP3다. 기본 게임의 로비 테마를 복제한 것은 아니며 보컬이 포함된 공개 OST를 사용한다. 원본 MP3 바이트는 변경하지 않고 Unity에서 스트리밍 압축 음원으로 가져온다. [음악 출처·공식 페이지·SHA-256](audio/music-sources.json)을 보존한다.

공식 팬키트의 한국어 WAV 353개를 사용한다. 91명 중 87명의 Q/W/E/R에 정확히 대응하는 스킬 보이스 339개, 니아의 상황 보이스 10개, 아나운서 보이스 4개다. 팬키트에 해당 이름의 기술 보이스가 없는 25개 스킬에는 억지로 다른 기술의 대사를 붙이지 않는다. 루시아·세레스의 비어 있는 폴더, 쇼이치·시셀라의 기술 이름에 맞는 WAV 부재 등을 [원본 보이스 목록과 미제공 항목](../Assets/Resources/Lumia/Audio/voice-sources.json)에 기록했다. 공개 팬키트에 BGM·야생동물·제작 같은 일반 효과음은 없고, 현재 PC에 남은 이터널 리턴 설치 폴더에도 실제 게임 오디오 데이터가 없었다.

## 보완 효과음

매칭 시작, UI 선택·취소·리롤·실패, 지도 이동, 전투 시작·승리·패배·레벨 상승, 키오스크 진입·구매, 장비 제작, 요리, 회복, 보상 선택·확정, 턴 종료에 소리를 연결한다. 닭·들개·늑대·멧돼지·곰에는 각각 진입·공격 소리를 적용한다. 카드에는 베기·투사체·폭발·전격·불·얼음·아케이드·방어·치유·이동·설치·마법 등의 성격에 맞는 소리를 사용하며 가능한 경우 원본 스킬 대사를 함께 재생한다. D와 F도 무기·전술 효과에 맞춰 구분한다.

총 65개이며 NumPy로 합성한 프로젝트 제작 효과음이다. 원본 야생동물 녹음이나 원본 매칭 효과음으로 표시하지 않는다. [재현 가능한 제작 도구](../Tools/GenerateSupplementalAudio.py)와 [효과음 출처·파일 해시·음량 측정](audio/designed-sources.json)을 함께 보관한다. 모닥불의 불소리는 체류 중 반복하고 화면을 벗어나면 멈춘다.

## 재생과 설정

환경 설정의 전체 음량은 기존 `lumia.volume` 설정을 그대로 사용한다. 음악과 효과음 및 보이스는 별도 음량을 저장한다. 기존 소리 끄기 설정도 유지한다. 원정 저장 데이터와 게임의 난수는 오디오 재생이 변경하지 않는다.

음악은 두 AudioSource로 0.9초 동안 전환한다. 같은 음원을 쓰는 화면 이동은 재생 위치를 유지한다. 효과음은 최대 10개, 보이스는 최대 2개가 동시에 재생된다. 짧은 UI 소리와 같은 스킬 보이스의 반복에는 간격을 둔다. 상태이상·연계·패시브로 생성되는 부가 피해 기록은 기본 기술음을 또 내지 않는다. 부활·일반 공격 치명타는 별도의 작은 강조음을 쓴다. 보이스가 나오는 동안 음악을 조금 낮춘다.

`GameAudioCatalog`는 카드·상황의 소리와 출처를 결정하고 `GameAudio`가 실제 재생을 담당한다. [통합 카탈로그](../Assets/Resources/Lumia/Audio/catalog.json)는 원본 음악, 원본 보이스, 프로젝트 제작 효과음을 구분한다. `Tools/AssembleAudioCatalog.py`로 다시 만들 수 있다. 특정 기술의 원본 대사가 없는 경우에도 해당 기술의 효과음은 재생한다.

## 검증

`Tools/RunAudioAudit.ps1`은 실제 파일·해시·출처·Unity 가져오기 설정·WAV 전체 샘플과 모든 카드의 결정적 라우팅을 검사한다. 개발 빌드의 `-bts-audio-verify`는 Unity가 가져온 파일과 실제 AudioListener 믹서 출력을 측정하며 음악 전환·상황 소리·양측 기술·겹침 제한·음량·음소거·일시정지·설정 저장을 검사한다. 이 측정은 운영체제 스피커 이전의 게임 믹서 검사이며 물리 스피커의 청취를 증명하지 않는다. 개인 저장과 일반 설정의 전후 일치도 확인한다. [검증 결과](validation-audio/README.md)에 실행 기록을 보존한다.
