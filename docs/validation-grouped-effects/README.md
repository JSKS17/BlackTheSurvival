# v0.1.5 같은 조건의 효과 설명 검증

같은 발동 조건의 효과는 연결된 문장으로 표시한다. 같은 제한은 한 번 표시하고, 다른 쿨다운·턴당·전투당 제한은 해당 효과 옆에 붙인다. 피오라의 기술 적중 후 회복·코스트 회복·뚜셰 소모도 한 문장에 모으되 회복의 턴당 제한과 코스트 회복의 2턴 쿨다운이 소모까지 제한하지 않도록 표시한다.

카드의 기술·상태이상·무료 사용권은 자원 조건·보조 조건·이전 기술·적중·시점의 실제 데이터를 기준으로 묶는다. 두 자원 조건의 순서만 다른 경우는 같은 조건이다. 첫 번째 조건이나 문구만 같고 다른 조건이 있는 효과는 합치지 않는다. 현재 공격의 적중을 요구하는 준비 효과와 다음 공격·설치물의 적중은 구분한다. 이렘의 변신 분기는 부연 설명으로 분리하여 생선 표식 소모가 고양이 상태 해제에만 적용된다고 읽히지 않도록 한다.

반격·지속 피해·회복·치명상 방지는 미래 효과를 얻거나 설치하는 문장으로 표시한다. 연결된 즉시 자원 획득이 반격 시점이나 턴 종료에만 발생하는 것처럼 읽히지 않도록 미래 조건의 범위를 효과 안에 닫는다. 요약 카드의 너비와 5줄 제한, 디버프 설명의 마지막 위치는 유지한다.

- 설명 감사 **35,565개 검증 통과**: 동일·다른 조건, 조건 순서, 적중·이전 기술, 발동 시점, 효과별 제한, 이렘의 분기 및 미래 반격의 조건 범위, 실제 피오라의 독립적인 발동 제한을 검사한다.
- 순수 규칙 **51개 시나리오·56,106개 검증 통과**. 데이터 392장·패시브 91종·룬 16종·장비 51종은 설명과 요약 필드만 제외한 SHA-256 지문이 이전 커밋과 완전히 동일하다. 수치·조건·타이밍·발동 제한과 게임 진행을 바꾸지 않았다.
- 현재 데이터에서 카드 274종(명시적인 조건이 있는 묶음 171종), 패시브 38종, 룬 4종에 여러 효과를 묶는 설명이 적용된다. 장비에도 같은 표현 규칙을 적용하지만 현재 장비 데이터는 동일 조건으로 묶을 복수 효과가 없다.
- Unity 런타임 컴파일·Windows 개발 및 배포 빌드를 검사한다. 개발 플레이어에서 **91개 화면**과 카드 요약 **4,704개 배치**를 확인하며, 피오라 요약·전체, 니아·로지·니키 카드 전체, 증폭 드론 전체 화면 6개를 보관한다.
- 배포 런타임의 소스·설치 해시, 기존 개인 저장 보존과 시작 창·런타임 오류, ZIP 전 파일의 CRC·SHA-256을 확인한다. GitHub 검증의 임시 기록은 `Temp/`에만 보관한다. 설명만 바뀌므로 전투 밸런스 자동 플레이는 다시 실행하지 않았다.
