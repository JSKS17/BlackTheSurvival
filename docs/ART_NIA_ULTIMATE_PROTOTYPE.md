## 원작에서 가져온 정체성

[공식 니아 공개 패치노트](https://playeternalreturn.com/posts/news/2702?hl=ko-KR)의 R은 배터리를 소모해 보호막을 얻고, 전방에 게임월드를 펼쳐 정신을 집중하며, 게임월드 안에서 아케이드 드롭으로 연속 공격한 뒤 추가 피해를 주는 기술입니다. 이를 게임패드 입력, 작은 보호막, 전방 직사각형 게임월드, 블록 낙하와 마지막 픽셀 타격으로 해석했습니다. 시안의 프레임 시간은 게임의 실제 스킬 수치나 지속 시간을 변경하지 않습니다.

## 제작 방식과 보존 조건

- **내장 `image_gen.imagegen`**으로 투명 애니메이션 시트 한 장을 생성했습니다. CLI/API 대체 생성은 사용하지 않았습니다.
- 직접 확인한 입력은 `Assets/Resources/Lumia/PortraitsReference/nia.png`, `Assets/Resources/Lumia/Story/Characters/nia_cast.png`, `nia_challenge.png`입니다. 첫 자산은 게임 내 정체성·도트 스타일, 나머지는 시전 자세·컨트롤러 참고 자료로 사용했습니다.
- 좁고 피곤한 반눈, 작은 닫힌 입, 보라색 짧은 웨이브 머리, 헤드폰, 검정·분홍 게이머 의상을 유지했습니다. 프레임별로 손·팔·몸의 기울기·무릎·옷자락·컨트롤러 자세와 블록·게임월드 효과가 달라집니다. 단일 스프라이트의 확대·흔들기만으로 구성하지 않았습니다.
- 최종 원본은 `C:/Users/azxar/.codex/generated_images/01a134e4-5e63-7a92-88e5-9e83aff9e3db/exec-af7392f0-ec61-42e6-9e56-2614dc339a32.png`의 **바이트 그대로** 프로젝트에 복사했습니다.
- 두 번째 내장 편집 호출에서 정렬을 강하게 요청한 후보(`exec-fcef0761-ada0-40f3-bc7d-4e48740c013d.png`)도 검토했으나 셀 경계를 넘는 문제가 있어 선택하지 않았습니다. 최종 이미지에 합성하거나 부분적으로 사용하지 않았습니다.
- `frames/`의 12개 PNG는 FFmpeg로 원본의 정확한 사각 셀만 분리했습니다. 각 파일의 RGBA가 원본 셀과 완전히 같은지 검증했습니다.
- 생성 원본의 행마다 발 기준이 다른 부분은 **재생 위치를 조립**하여 해결했습니다. `aligned-frames/`는 원본 셀을 투명 480×480 캔버스에 **정수 좌표로만 옮겨** 발 중심이 (170,400)에 오도록 배치한 프레임입니다. 캐릭터나 효과 픽셀을 그리거나 교체하지 않았고, 크기·회전·리샘플링·색 보정·알파 보정도 하지 않았습니다. HTML은 원본 아틀라스를 같은 표시 오프셋으로 재생합니다.
- WebP는 lossless 형식으로 인코딩했습니다. 투명도가 0인 보이지 않는 RGB는 포맷 변환에서 정규화될 수 있으므로, 검증에서는 모든 알파 값과 **알파가 0보다 큰 모든 RGBA 픽셀의 완전 일치**를 확인했습니다.
- GIF는 256색과 1비트 투명도의 포맷 제약이 있습니다. 반투명 VF 효과 확인에는 WebP 또는 HTML이 더 정확합니다. GIF는 움직임을 간편하게 보여주기 위한 미리보기입니다.

## 검증

- 원본 투명 알파, 셀 크기, 12개 프레임의 서로 다른 RGBA 해시를 확인했습니다.
- 셀 분리와 정수 좌표 배치 후 원래 셀의 모든 RGBA 픽셀이 동일함을 확인했습니다.
- WebP·GIF 모두 12프레임이며 GIF 시간의 합이 1500ms임을 확인했습니다. WebP의 보이는 RGBA 픽셀은 정렬된 프레임과 완전히 같습니다.
- Chrome의 실제 HTML 렌더링에서 자동 재생, 일시 정지, 프레임 이동, 속도 선택, 폭 375px에서의 가로 넘침 없음을 확인했습니다.
- [브라우저 검증 결과](validation-nia-ultimate-prototype/browser-validation.json)와 전체 12프레임 캡처, 데스크톱·모바일 전체 화면 캡처를 저장했습니다. 캡처에서 얼굴이 효과에 가려지지 않고 발 기준이 일정한 것을 확인했습니다.
- 미리보기에서 셀 순서·레이아웃·발 정렬·마지막 타격과 대기 복귀를 검토했습니다. 원본 이미지가 가진 약간의 머리·의상 디테일 변화는 남아 있으며, 정식 전투 적용 전에는 실제 화면 크기와 타격 시점에 맞춘 추가 검토가 필요합니다.
