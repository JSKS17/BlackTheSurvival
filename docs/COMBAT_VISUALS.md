# 카드 사용 연출과 원작 기술의 시각적 개성

`CombatVisualProfiles.For(CardDef)`는 실제 카드 392종 각각에 짧은 시각 효과 프로필을 제공합니다. 캐릭터 91명의 Q·W·E·R은 명시적인 기술별 형태 표를 사용하고, 기본 카드·무기 기술·전술 기술은 개별 매핑을 사용합니다. 피해 수치나 카드 코스트로 실험체의 원작 기술을 추측하지 않습니다.

## 원작 참고와 도트 화면에 맞춘 해석

- [공식 니아 출시 소개](https://playeternalreturn.com/posts/news/2702?hl=en-US): Q의 아케이드 블록, W의 흡인 지점, E의 1UP, R의 사각 게임 공간을 서로 다른 연출로 구분합니다. 니아의 원작 기술 아이콘은 자홍색 계열입니다.
- [공식 블레어 기술 소개](https://event.playeternalreturn.com/S9/Blair): 쌍검·양날검의 휘두르기와 강화 상태를 청록색 칼날로 표현합니다. 에키온의 붉은 VF 방출과 색·형태를 구분합니다.
- [공식 캐릭터 기술 자료](https://playeternalreturn.com/posts/news/1280?hl=en-US): 리오의 화살, 혜진의 부적, 아델라의 체스, 셀린의 폭탄 등 기술이 실제로 사용하는 물체를 우선합니다.
- 전체 원작 기술 이름·설명·아이콘의 기존 참고 자료: [reference-skills.json](art-chibi/reference-skills.json), [기술 아이콘 참고 이미지](art-chibi/skill-references/). 이 자료의 각 기본 스킨 기술 아이콘에서 주색·강조색을 따왔습니다. 작은 전투 효과에서도 읽히도록 주색의 밝기를 보정했습니다. 신규로 만든 효과의 형태·타이밍은 이 팬 게임 화면에 맞춘 해석입니다.

기술의 원작 3D 파티클을 그대로 사용하는 방식이 아니라 사각 픽셀, 짧은 궤적, 충돌점과 고유 물체를 조합합니다. 스프라이트 원본, 얼굴 픽셀, 이미지 크기와 UI의 기본 표시 크기를 변경하지 않습니다. 시각 효과의 입자 수는 타격 횟수나 스택을 추가하지 않습니다.

## 타이밍과 이동 판정

- 일반 기술은 약 0.76초, 이동 기술은 약 0.86초, 다단 기술은 약 0.94초, R은 약 1.04초입니다. 적·플레이어에 같은 프로필을 사용합니다.
- 충돌 시점은 전체 진행의 38%가 기본입니다. 폭탄·함정은 46%, 저격은 50%입니다.
- 이동은 실제 `CardDef.movement` 판정이 있는 카드에만 적용합니다. 이동 기술의 돌진·후퇴·도약·순간이동·회전은 원작 기술의 이동 방식에 맞춰 따로 지정합니다. 일반 근접 기술은 짧은 공격 동작, 나머지는 시전 동작을 사용합니다.
- 기본 방어는 스프라이트를 움직이지 않습니다. 화면에서 원래 위치로 돌아오는 동작은 전투 배치를 유지하기 위한 연출입니다.
- `seed`는 카드 ID의 고정 해시입니다. 입자 배치의 작은 변주에만 사용하고 형태·색·이동 유형은 해시로 선택하지 않습니다.
- 프로필 조회는 카드 객체별로 캐시됩니다. 게임의 난수, 행동 결과, 덱, 카드 정의와 저장 데이터를 수정하지 않습니다.

## 검증

[CombatVisualSmokeTests.cs](../Tools/CombatVisualSmokeTests.cs)는 전체 392종의 유효한 프로필·팔레트·짧은 타이밍·이동 판정 일치·캐시 안정성과 대표 원작 기술의 형태를 검사합니다. 원정·준비 난수를 소비하지 않고 카드 정의가 바뀌지 않는지도 검사합니다. 실제 Unity 전투 화면의 검증 결과는 별도 화면 검증 자료에서 확인합니다.
