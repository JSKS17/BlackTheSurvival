준비 단계에서 룬을 바꾸면 같은 추첨 시드에 새 가중치를 적용하고 이미 선택한 패시브·카드를 유지합니다. 색상을 바꿨다가 되돌려도 새 추첨을 만들지 않습니다. 기존 저장의 표시된 선택지는 로드만으로 재추첨하지 않으며, 명시적인 룬 변경이나 리롤부터 새 규칙을 적용합니다. 실험체·보스·지정 조우의 고정 보상은 해당 실험체의 보상을 유지합니다.

룬 선택 화면의 계열 색상과 역할군 안내, 룬 상세 설명을 보강했습니다. 보조 룬의 상세는 역할군 보정이 메인 룬 색상으로 결정됨을 안내합니다.
