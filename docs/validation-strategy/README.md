# v0.1.14 카드·손패·경로·조우 전략

검증 환경은 Windows, Unity 6000.3.11f1이다. 선택형 카드 강화, 제한적인 손패 보관, 보안 콘솔·하이퍼루프와 8명의 후속 조우를 구현했다. 수치·인물별 비용·보상·저장 호환은 [전략 시스템 설명](../STRATEGY_SYSTEMS.md)에 기록한다.

- [코어 검증](core-tests.log): 61개 시나리오, 61,852개 단언을 통과했다. 강화 대상·방향 선택, 사본 전체 적용과 원본 데이터 보존, 니아 Q/W의 강화 요약, 기존 강화 저장, 보관의 정확한 사본·취소·두 번 제한·드로우 감소·손패 상한, 정찰의 비용·실제 상대·난수 보존, 하이퍼루프의 유효 경로·막별 제한을 검사했다.
- 후속 조우는 새 약속 뒤의 실제 다음 조우 500회 중 396회에 등장했다. 이전 약속이 남은 상태에서 새 약속을 수락한 표본은 500회 중 새 약속 407회, 이전 약속 4회였다. 새 약속의 80% 우선 추첨과 이전 약속의 일반 추첨 참여·후속 우선권 순환을 확인한다. 한 표본에서 세 후보의 실험체는 중복되지 않는다.
- 후속 이야기 8종의 24개 행동을 모두 실행하여 카드·음식·회복·최대 능력치·강화·제거 보상, 비용 차감, 완료 후 지도 복귀와 재지급 차단을 검사했다. 강화 선택을 기다리는 후속 조우에서 저장·복원 후 강화를 포기하는 경로도 포함한다.
- [런타임 컴파일](runtime-compile.log), [개발 빌드](development-build.log), [배포 빌드](release-build.log)를 보관한다. 두 Windows 빌드는 오류 0개로 완료했다.
- `-bts-strategy-verify`는 개인 저장과 분리한 Windows 개발 실행본에서 실제 노드 입장·공개 엔진 API·Unity JSON 복원을 검증한다. [26개 화면 결과](native-screens.json), [실행 로그](ui-player.log), [개발 실행본과 현재 소스의 일치 해시](build-source-hashes.json)를 보관한다. 강화 후보·방향·반영·복원 6화면, 보관 선택·해제·복원·다음 턴 5화면, 정찰·재고·하이퍼루프 7화면, 약속·비용 부족·후속 후보·재회·완료 7화면과 도움말이다. 모두 1280×720이며 비어 있는 화면과 런타임 오류는 없다.
- 강화된 카드 요약·전체 설명, 보관 표시·버튼, 정찰 지도·재고 팝업, 하이퍼루프 목적지, 약속의 비용·확률·후속 보상 화면을 직접 검토했다. 니아 Q의 요약과 실제 블록 생성량은 2이며, 니아 W의 전용 강화 요약은 블록당 추가 피해 6을 표시한다.
- [개인 저장 보존](save-preservation.json), [설치 파일 해시](release-hashes.json), [배포 실행](release-startup.json), [ZIP 검사](archive-validation.json)를 보관한다. 개인 이어하기의 검증 전후 해시가 같으며 ZIP의 모든 런타임 파일은 설치 출력과 CRC·SHA-256 검사를 통과했다. 개인 저장과 개발 캐시는 배포하지 않는다.

검증은 이번 기능의 규칙과 실제 Windows UI·저장·배포를 중심으로 수행했다. 전체 난이도나 사람의 장기 플레이 승률을 추정하는 결과는 아니다.
