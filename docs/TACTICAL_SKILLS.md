# 전술 스킬과 전술강화 모듈

원작 이름이 있는 전술 26종(기존 3종 + 추가 23종)을 지원합니다. 초월은 제외합니다.
과거에 삭제된 전술과 코발트의 전술 교체 인퓨전도 포함하며, 현재 원작에서 모두 선택 가능하다는 뜻은 아닙니다.
아래 코스트와 효과는 실제 게임 코드에서 내보낸 턴제 밸런스입니다. 일반 +·레어 ++와 전술 강화는 각각 별도로 적용됩니다.
